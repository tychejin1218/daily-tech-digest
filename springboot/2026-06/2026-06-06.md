### `@Observed` 어노테이션으로 Micrometer 관찰성(Observability) 자동 계측하기

Spring Boot 3.0+에서 `@Observed`를 메서드나 클래스에 붙이면 Micrometer Observation API가 자동으로 메트릭, 트레이싱, 로깅을 통합 계측해 줍니다. `ObservedAspect` 빈을 등록하고 `management.observations.annotations.enabled=true`를 설정하면 별도의 수동 계측 코드 없이 비즈니스 메서드의 실행 시간, 에러율, 트레이스 스팬이 자동으로 수집됩니다.

> 💡 **왜 중요한가**: 메트릭/트레이싱 코드를 비즈니스 로직에 흩뿌리지 않고 어노테이션 한 줄로 일관된 관찰성을 확보할 수 있습니다.

### `JdbcClient`로 `JdbcTemplate`의 Fluent 후속 API 사용하기

Spring Framework 6.1+에서 추가된 `JdbcClient`는 `JdbcTemplate`과 `NamedParameterJdbcTemplate`을 통합한 Fluent 스타일 API로, `sql().param().query().single()`처럼 메서드 체이닝으로 쿼리·파라미터 바인딩·결과 매핑을 한 흐름에 작성합니다. 명명 파라미터와 인덱스 파라미터를 동시에 지원하면서도 `RowMapper` 람다 또는 `mappedTo(Class)`로 자동 매핑을 간결하게 처리할 수 있습니다.

> 💡 **왜 중요한가**: 가독성이 떨어지던 전통적인 `JdbcTemplate` 호출을 선언적이고 타입 안전한 형태로 바꿔, JPA를 쓰지 않는 경량 데이터 접근 계층의 유지보수성을 끌어올립니다.
