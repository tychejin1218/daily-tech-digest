### 1. `Math.clamp(value, min, max)` (Java 21 정식, JEP 405)로 `Math.min(max, Math.max(min, value))` 중첩 호출 관성 벗어나기

값을 특정 범위에 가둘 때 `Math.min()`과 `Math.max()`를 중첩 호출하는 패턴은 min/max 순서를 뒤바꿔도 컴파일러가 못 잡고, 범위를 "가둔다"는 의도가 코드에 드러나지 않는다. Java 21부터 정식 도입된 `Math.clamp(value, min, max)`는 int/long/float/double 네 오버로드를 제공하며, `min > max`일 때 `IllegalArgumentException`을 던져 로직 버그를 호출 즉시 터뜨린다. 볼륨·좌표 바운딩, 백오프 지연 상한, 재시도 횟수 제한 등 실무에서 극도로 자주 등장하는 패턴이다.

> 💡 **왜 중요한가**: `clamp(input, 0, 255)`는 인자 순서가 자연어 그대로("입력을 0과 255 사이로")라 리뷰어가 중첩 괄호를 역추적할 필요가 없다.

### 2. `SequencedCollection.getFirst() / getLast() / reversed()` (Java 21 정식, JEP 431)로 `list.get(0) / list.get(list.size()-1)` 인덱스 산술 관성 벗어나기

Java 21부터 `List`, `Deque`, `LinkedHashSet`, `LinkedHashMap` 등 삽입/정렬 순서가 있는 컬렉션들이 `SequencedCollection` 공통 인터페이스를 구현한다. 이제 첫/마지막 원소를 꺼낼 때 인덱스를 계산하는 대신 `getFirst()`, `getLast()`를 쓰면 되고, `reversed()`는 복사 없이 역순 뷰(view)를 돌려준다. 특히 `LinkedHashSet`에서 마지막 삽입 원소를 꺼내려고 `new ArrayList<>(set).get(set.size()-1)` 같은 O(n) 복사 안티패턴을 썼다면 바로 폐기할 수 있다.

> 💡 **왜 중요한가**: 빈 컬렉션에서 `NoSuchElementException`을 명시적으로 던져 "0번 인덱스 IndexOutOfBounds"보다 원인이 즉시 읽히고, `reversed()`는 뷰라서 메모리 복사 없이 역방향 순회가 가능하다.
