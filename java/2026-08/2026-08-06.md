### 1. `Math.clamp(value, min, max)`로 값을 범위 안에 가두는 반복 코드 제거하기 (Java 21 정식)
값을 특정 최소·최대 사이로 제한할 때 흔히 쓰던 `Math.max(min, Math.min(max, value))` 이중 호출을 표준 API 하나로 대체할 수 있습니다. `int`, `long`, `float`, `double` 오버로드가 모두 제공되며, `min > max`이면 즉시 `IllegalArgumentException`을 던져 잘못된 범위 지정을 컴파일 이후에도 방어합니다.

> 💡 **왜 중요한가**: UI 좌표 보정, 볼륨/투명도 조절, 재시도 간격 상한 계산 같은 "범위 안에 가두기" 로직을 라이브러리 도움 없이 표준 API로 명확히 표현할 수 있습니다.

---

### 2. `Stream.mapMulti(BiConsumer)`로 flatMap의 스트림 생성 오버헤드 없이 1:N 변환하기 (Java 16 정식)
`flatMap`은 요소마다 새로운 `Stream` 인스턴스를 만들지만, `mapMulti`는 `Consumer`에 결과를 직접 넣는 방식이라 중간 스트림 없이 요소를 0개 이상 방출할 수 있습니다. 특히 방출 개수가 적거나 조건부로 값을 흘려보내야 할 때 GC 부담과 파이프라인 오버헤드를 줄일 수 있습니다.

> 💡 **왜 중요한가**: 대량 요소를 필터링+변환하는 배치 처리나 파싱 파이프라인에서 `flatMap` 대신 `mapMulti`로 바꾸기만 해도 스트림 인스턴스 생성 비용을 줄여 처리량을 끌어올릴 수 있습니다.
