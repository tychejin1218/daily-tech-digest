### 1. OpenAI 'Pando' Git 백엔드 공개 — Codex 러시에 Git이 무릎 꿇기 직전, '에이전트 전용 모노레포 저장소'가 태어났다

OpenAI가 기존 Git 인프라로 감당 못 할 만큼 폭증한 Codex 에이전트의 커밋·브랜치·CI 트래픽을 수용하기 위해 자체 Git 호환 백엔드 'Pando'를 공개했다. 2024년 Q1 대비 2026년 Q4 master 커밋이 **2,442%** 증가, 미디언 push 레이턴시 **~80% 감소**, 하루 **1 PB 가까운** Git 데이터 처리. Pando는 리포지토리 단위 강한 일관성을 포기하고 ref별 causal consistency + immutable packfile + 리전 캐시로 쓰기/읽기를 수평 분리했다. Codex로 **10주 만에** 킥오프→프로덕션까지 끝낸 자가 발전식 사례이기도 하다.

> 💡 **왜 중요한가**: '사람 커밋'을 기준으로 설계된 VCS가 처음으로 '에이전트 커밋'의 하중을 못 버텨 아키텍처를 바꾼 첫 공개 사례 — 모노레포·CI·브랜치 전략의 설계 상수가 리셋된다.

### 2. Google Workspace 'MCP 의무화' 발표 — 2027년 2월 1일부터 AI 에이전트의 Gmail·Drive·Calendar REST 직접 호출이 사실상 '2등 시민' 된다

Google이 2027-02-01부로 Workspace AI Tools Addendum을 발효, AI 에이전트가 Gmail·Drive·Docs·Calendar·Chat에 접근할 때 **Workspace MCP 서버 또는 Workspace CLI를 통해서만** 'Scaled tier' 쿼터를 받을 수 있게 한다. REST API 직접 호출은 과금 등급과 무관하게 **Standard tier 쿼터로 강제 다운그레이드**되며, OAuth 2.0 클라이언트에서 "Use this client for an AI-powered agent" 플래그를 명시적으로 켜야 한다. 외부 어시스턴트가 사내 Gmail 계정에 붙는 케이스까지 모두 포함.

> 💡 **왜 중요한가**: 하이퍼스케일러가 처음으로 MCP를 'SDK 선택지'가 아니라 **쿼터·과금·감사 로그가 묶인 1급 엔터프라이즈 프로토콜**로 못박았다 — Microsoft·AWS가 뒤따를 때 레거시 REST 통합은 기술 부채가 아니라 '컴플라이언스 부채'가 된다.

### 3. Vercel 'Workflow SDK 5.8' + 실험판 'Board' 동시 공개 — 에이전트 런타임이 '사람 PM 없는 칸반 보드'를 코어 프리미티브로 들어 올렸다

Workflow SDK 5.8이 새 실행 엔진으로 전환, **스텝 간 레이턴시 12배 단축**, 256 스텝 병렬 팬아웃에서 **함수 시간 14배 절감** — durable 에이전트 턴 타임이 실측으로 꺾였다. 같은 날 공개된 실험판 'Board'는 Claude Code·Codex·OpenCode·Mastra·LangChain 같은 **이종 하네스의 에이전트들이 공용 메시지 보드에서 태스크를 lease(최대 5분) 모델로 집고 반납**하게 한다. `vercel board` CLI와 `@vercel/board` SDK로 조직 단위 'General' 보드가 디폴트로 꽂힌다.

> 💡 **왜 중요한가**: 에이전트 멀티플렉싱의 다음 병목은 '모델 성능'이 아니라 '**누가 어떤 태스크를 잡고 있는가**'의 조정 문제 — Board는 이걸 DB도 큐도 아닌 '리스 가능한 공용 스레드'로 1급 인프라화해, 'AutoGen/Semantic Kernel 내부에서 돌던 오케스트레이션'을 조직 바깥 계층으로 꺼냈다.
