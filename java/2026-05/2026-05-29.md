### `Duration.toDaysPart()` 계열 메서드로 기간을 단위별로 분해하기 (Java 9 정식)

`Duration`을 시/분/초로 나눠 표시할 때 예전에는 `toHours()`, `toMinutes() % 60` 같은 나머지 계산을 직접 해야 했다. Java 9부터는 `toDaysPart()`, `toHoursPart()`, `toMinutesPart()`, `toSecondsPart()`, `toMillisPart()`, `toNanosPart()`가 추가되어 각 단위의 "부분 값"을 바로 얻을 수 있다.

```java
Duration d = Duration.ofSeconds(3745); // 1시간 2분 25초
String formatted = String.format("%d:%02d:%02d",
    d.toHoursPart(), d.toMinutesPart(), d.toSecondsPart());
// "1:02:25"

Duration elapsed = Duration.between(start, Instant.now());
System.out.printf("경과: %d일 %d시간 %d분%n",
    elapsed.toDaysPart(), elapsed.toHoursPart(), elapsed.toMinutesPart());
```

> 💡 **왜 중요한가**: 나머지 연산으로 시분초를 쪼개는 실수 잦은 로직을 표준 API로 대체해 가독성과 정확성을 동시에 얻는다.

### `Math.floorDiv()` / `Math.floorMod()`로 음수에서도 안전한 나눗셈·나머지 하기 (Java 8 정식)

Java의 `/`와 `%` 연산자는 음수 피연산자에서 0 방향으로 절삭(truncation)되기 때문에 `-7 / 3 == -2`, `-7 % 3 == -1`이 된다. 반면 `Math.floorDiv(-7, 3) == -3`, `Math.floorMod(-7, 3) == 2`로 항상 아래쪽(floor)으로 내림하며, 나머지는 항상 제수(divisor)의 부호를 따른다.

```java
// 순환 인덱스, 시간대·각도 계산에서 특히 유용
int index = Math.floorMod(-1, list.size()); // 항상 [0, size) 범위
int hour  = Math.floorMod(currentHour - 3, 24); // 3시간 전, 음수 안전

// 자정 넘김 계산
int minutesSinceMidnight = Math.floorMod(nowMin - 30, 24 * 60);
```

> 💡 **왜 중요한가**: 순환 배열 인덱스나 시각 롤오버 같은 흔한 상황에서 `%` 연산자의 음수 결과 버그를 근본적으로 예방한다.
