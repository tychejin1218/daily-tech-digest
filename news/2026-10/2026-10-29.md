### 1. OpenAI 'GPT-6.1 Terra' 공개 — 코딩·컴퓨터 사용 가격을 반으로 깎았다, '에이전트당 비용'이 Astra의 1/3이 됐다

OpenAI가 10/26 ChatGPT Work·Codex·API에 `gpt-6.1-terra`를 롤아웃했다. 입력 $1/M·출력 $5/M으로 GPT-5.6 Terra 대비 가격을 절반으로 끊었고, max effort에서 평균 과제당 비용이 $1.40 → $0.40으로 떨어졌다. 롱호라이즌 에이전트 벤치에서는 GPT-6 Astra와 동률을 찍었다 — '싸게 돌리는 Astra'가 나온 셈이다.

> 💡 **왜 중요한가**: 에이전트 하네스에서 모델을 고르는 기준이 '성능'에서 '성능/달러'로 완전히 넘어갔다. Codex·Cursor·GitHub 에이전트 셋 다 디폴트 모델을 Terra로 스왑하는 중이고, Astra를 유지하는 쪽은 '왜 3배 더 쓰는가'를 설명해야 하는 입장이 됐다.

### 2. GitHub Copilot 'Assisted Permissions' GA — LLM이 '안전한 커맨드'를 자동 승인한다, 사람은 위험한 것만 보게 됐다

10/26 Copilot CLI·앱·VS Code 세 곳에서 동시에 GA로 승격됐다. 에이전트가 명령을 돌리거나 파일을 열거나 URL을 때릴 때마다 LLM 저지(judge)가 선분류해서, 명백히 안전한 건 통과시키고 애매한 것만 사람 확인으로 올린다. 엔터프라이즈 관리자는 'Allow All' 모드 자체를 차단하거나, Assisted를 꺼서 모든 호출을 수동 승인으로 강제할 수 있다.

> 💡 **왜 중요한가**: 에이전트 승인 UX의 피로("매번 Y/n")가 생산성 상한이었는데, '모델이 모델을 심사'하는 2단 아키텍처가 1급 패턴으로 공식화됐다. 이제 승인 로그 자체가 감사 대상이 된다 — 어떤 커맨드를 LLM이 자동 승인했는지, 그 저지의 결정 근거는 뭔지가 SOC 2 증거로 요구되기 시작한다.

### 3. Cloudflare 'Basin' GA — Iceberg + R2가 '에그레스 $0' 분석 플랫폼으로 묶였다, Snowflake의 TB당 가격을 절반으로 끊었다

Birthday Week에 Basin(Pipelines + Catalog + SQL)이 GA에 올랐다. 데이터는 Apache Iceberg 오픈 포맷으로 R2에 쌓이고, 그 자리에서 Snowflake·Spark·DuckDB가 그대로 읽는다. 핵심은 'R2 에그레스 $0' — 멀티클라우드에서 쿼리를 돌려도 데이터 이동 비용이 0이고, 스토리지는 TB당 $2.50 선으로 AWS S3 + Athena 조합을 절반 가격으로 끊어버렸다.

> 💡 **왜 중요한가**: '데이터는 어느 클라우드에 둘 것인가'라는 10년짜리 질문이 '어느 Iceberg 카탈로그를 쓸 것인가'로 바뀐다. 백엔드 아키텍트는 이제 Postgres → Kafka → Snowflake 파이프라인 대신, Workers → Basin Pipelines → Iceberg 테이블 하나로 OLTP·스트리밍·분석을 묶는 설계를 선택지로 올려야 한다.
