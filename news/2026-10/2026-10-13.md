### Vercel AI SDK 6.0 정식 출시 — 'Agent Primitives' 가 프레임워크의 1급 시민이 됐다

Vercel이 AI SDK 6.0을 정식 공개하면서 `Agent`, `Step`, `Handoff` 를 라이브러리 코어 API로 승격했다. 이전까지는 `streamText` 위에 사용자가 직접 루프를 짜야 했지만, 이제 멀티스텝 툴콜·서브에이전트 핸드오프·중단/재개(resumable streams)가 SDK 레벨에서 표준화되어 Next.js·Nuxt·SvelteKit 어디서든 동일 코드로 돈다. OpenAI·Anthropic·Google·xAI 어댑터 모두 `providerOptions` 로 캐싱·추론 토큰·웹 서치를 통일된 인터페이스로 노출한다.

> 💡 **왜 중요한가**: '에이전트 런타임을 직접 짜지 말라'는 신호 — 프레임워크가 루프를 소유하기 시작하면, 커스텀 오케스트레이터는 유지보수 부채가 된다.

### Supabase 'Edge Agents' GA — Postgres 트리거가 바로 LLM 에이전트를 깨운다

Supabase가 Edge Functions 위에 올린 `Edge Agents` 를 GA로 전환했다. `pg_net` 과 `pg_cron` 이 Deno 런타임의 에이전트 엔드포인트를 직접 호출해, Row 삽입·크론·웹훅 세 가지 트리거가 Postgres 안에서 LLM 호출로 접힌다. 핵심은 `pgvector` + `pg_graphql` + Edge Agent 가 한 트랜잭션 컨텍스트에서 묶여, "DB에 insert → 벡터 임베딩 → 에이전트가 요약 → 다시 테이블에 write" 가 외부 큐 없이 한 SQL 세션에서 끝난다는 것.

> 💡 **왜 중요한가**: '애플리케이션 서버 없는 AI 백엔드'가 Postgres 안에서 완결된다 — Lambda·SQS·워커 큐를 거쳐야 했던 비동기 AI 파이프라인의 재료가 하나 사라졌다.

### LangChain 1.0 LTS 공개 — `langchain-core` 가 '에이전트 프로토콜'로 재정의됐다

LangChain이 베타 꼬리표를 떼고 1.0 LTS를 공개하면서, 패키지 구조를 `langchain-core` / `langchain-agents` / `langchain-integrations` 세 축으로 재편했다. 가장 큰 변화는 `Runnable` 을 폐기하고 `Agent Protocol` 을 1급으로 올린 것 — MCP, A2A(Agent-to-Agent), OpenAI Responses API 를 같은 인터페이스로 받아들이는 어댑터 레이어가 생겼고, 2년 LTS 를 보장하면서 "체인 라이브러리"에서 "에이전트 상호운용 계층"으로 포지션을 바꿨다.

> 💡 **왜 중요한가**: LangChain 을 "체인 DSL" 로 쓰던 코드는 전부 레거시가 됐다 — 1.0 은 자기 프레임워크를 숨기고 'MCP·A2A 어댑터' 로만 존재하려 한다는 선언이다.
