### 1. Cursor Self-Hosted Machines, 'Dynamic Pools' 정식 확장 — 클라우드 에이전트가 드디어 사내 VPC 안에서 오토스케일·하이버네이션까지 지원한다
9월 2일 Cursor가 Self-Hosted Machines를 확장해 팀 단위 워커 풀, 오토스케일링, 유휴 시 하이버네이션, 그리고 AWS Lambda·Vercel·Modal·Coder·Cloudflare·Daytona·Namespace·E2B 등 8개 샌드박스 프로바이더 위에서 실행하는 옵션을 열었다. 코드베이스·빌드 산출물·시크릿은 사내망에 그대로 두고, 계획·오케스트레이션만 Cursor 컨트롤 플레인이 담당하는 구조로 완전 분리됐다.

> 💡 **왜 중요한가**: '코딩 에이전트=SaaS'라는 전제가 무너졌다 — 이제 조달·컴플라이언스 팀 승인 없이도 엔터프라이즈에 에이전트를 넣을 수 있는 첫 상용 경로가 열렸다.

### 2. OpenAI GPT-6 Astra 정식 공개 — 1M 컨텍스트·$10/$50 가격에 '사이버 보안 전용 Daybreak 티어'까지 함께 나왔다
9월 3일 OpenAI가 gpt-6-astra 모델을 API·ChatGPT·AWS Bedrock에 동시 출시했다. 1,050K 컨텍스트, 128K 최대 출력, 캐시 리드 $1, Fast 모드 2배 요금이라는 GPT-5.6 대비 2.5배 가격 정책과 함께, 애플리케이션 심사 기반의 'Daybreak' 사이버보안 프로그램 참여사에만 먼저 열리는 게이트드 롤아웃을 채택한 것이 특징이다.

> 💡 **왜 중요한가**: 프론티어 모델 배포가 처음으로 '심사 기반 화이트리스트'로 시작한다 — 오픈 API 우선 공개 관행이 깨지고, 모델 액세스 자체가 컴플라이언스 상품이 되기 시작했다.

### 3. GitHub Copilot 'Agent Merge' 퍼블릭 프리뷰 공개 — PR 리뷰 피드백·CI 실패·머지 컨플릭트를 에이전트가 알아서 해결한다
9월 첫 주 GitHub이 Agent Merge를 퍼블릭 프리뷰로 공개하고, 동시에 Multi-root 워크스페이스에서 Copilot·Claude 에이전트 세션을 폴더별로 병렬 실행하는 실험 기능, Chat Sessions 계층 관리, JetBrains Copilot 하네스 GA를 함께 릴리스했다. Agent Merge는 리뷰어 코멘트·실패한 체크·컨플릭트 세 가지를 한 번의 에이전트 루프로 처리해 PR을 머지 가능 상태로 되돌린다.

> 💡 **왜 중요한가**: 코딩 병목이 '생성'에서 '리뷰·머지'로 이동했다는 진단이 실제 제품으로 넘어온 첫 사례다 — PR 통과 자체를 에이전트가 책임지는 시대의 시작이다.
