### 1. `Stream.mapMulti((element, downstream) -> ...)` (Java 16 정식, JEP 395)로 1→소수(少數) 변환하기 — `flatMap`이 원소마다 중간 Stream을 새로 깔던 관성 벗어나기

`flatMap`은 각 원소마다 `Stream.of(a, b)` 같은 작은 스트림 객체를 생성해 파이프라인에 합치는 반면, `mapMulti`는 `Consumer`로 직접 다운스트림에 값을 밀어넣기 때문에 "원소 한 개당 0~몇 개"를 쏟아내는 패턴에서 중간 스트림 할당을 제거한다. 특히 조건부 분기(`if`로 값을 넣거나 말거나)나 instanceof 패턴 매칭과 결합할 때 코드 가독성도 `flatMap(e -> cond ? Stream.of(x) : Stream.empty())`보다 훨씬 깔끔하다.

```java
// Before: 매 원소마다 Stream.of/empty 객체 생성
numbers.stream()
    .flatMap(n -> n % 2 == 0 ? Stream.of(n, n * n) : Stream.empty())
    .toList();

// After: Consumer로 바로 push, 중간 Stream 없음
numbers.stream()
    .<Integer>mapMulti((n, downstream) -> {
        if (n % 2 == 0) {
            downstream.accept(n);
            downstream.accept(n * n);
        }
    })
    .toList();
```

> 💡 **왜 중요한가**: 수백만 건 스트리밍에서 `flatMap`의 "원소당 Stream 객체 할당"은 GC 압박의 숨은 원인인데, `mapMulti`는 같은 로직을 할당 없이 돌려 핫 패스의 레이턴시와 할당률을 동시에 줄여준다.

### 2. `CompletableFuture.orTimeout(timeout, unit)` / `completeOnTimeout(value, timeout, unit)` (Java 9 정식)로 비동기 타임아웃 적용하기 — `ScheduledExecutorService`로 cancel 레이스 손수 제어하던 관성 벗어나기

Java 8까지는 `CompletableFuture`에 타임아웃이 없어 별도의 `ScheduledExecutorService`를 띄워 `schedule(() -> future.completeExceptionally(new TimeoutException()))` 하고 cancel 타이밍을 직접 챙겨야 했다. Java 9부터 `orTimeout`은 지정 시간 내 완료되지 않으면 `TimeoutException`으로 완료시키고, `completeOnTimeout`은 폴백 값으로 정상 완료시킨다. 둘 다 내부 공용 스케줄러를 쓰므로 추가 스레드풀 관리가 필요 없고, 당연히 "원 future가 먼저 끝나면 타임아웃은 자동 무효화"되어 레이스를 신경 쓸 필요가 없다.

```java
// 폴백 값으로 완료 (장애 시 캐시값 반환)
CompletableFuture<Price> price = fetchPriceAsync(itemId)
    .completeOnTimeout(Price.CACHED_DEFAULT, 500, TimeUnit.MILLISECONDS);

// 타임아웃 시 예외 발생 + exceptionally로 복구
CompletableFuture<Order> order = createOrderAsync(req)
    .orTimeout(2, TimeUnit.SECONDS)
    .exceptionally(ex -> ex.getCause() instanceof TimeoutException
        ? Order.pendingRetry(req)
        : Order.failed(ex));
```

> 💡 **왜 중요한가**: 외부 API 호출을 `CompletableFuture`로 묶어두고 타임아웃을 안 걸면 커넥션 풀 포화 → 전파되는 전형적인 장애 체인이 생기는데, 이 두 메서드는 "스케줄러 수명 관리 + cancel 레이스"라는 보일러플레이트 없이 한 줄로 서킷 브레이킹 기반을 깔아준다.
