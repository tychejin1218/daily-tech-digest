### `Math.clamp(value, min, max)`로 값을 범위 안으로 가두기 (Java 21 정식)

값을 특정 최솟값과 최댓값 사이로 제한할 때 흔히 `Math.max(min, Math.min(max, value))`처럼 중첩 호출을 쓰는데, 이 방식은 읽기 어렵고 인자 순서를 헷갈리기 쉽습니다. Java 21부터는 `Math.clamp(value, min, max)` 한 줄로 의도가 명확하게 드러나며, `int`/`long`/`float`/`double` 오버로드를 모두 제공하고 `min > max`일 때는 예외를 던져 잘못된 범위도 잡아줍니다.

```java
int volume = 130;
int safe = Math.clamp(volume, 0, 100);   // 100
int low  = Math.clamp(-5, 0, 100);        // 0

// 기존 방식 (가독성·실수 위험)
int legacy = Math.max(0, Math.min(100, volume));
```

> 💡 **왜 중요한가**: 범위 제한 로직을 표준 API로 표현해 중첩 `min/max`의 인자 순서 실수와 가독성 저하를 동시에 없앨 수 있습니다.

### `Collectors.teeing()`으로 스트림을 한 번만 순회해 두 결과를 합치기 (Java 12 정식)

같은 데이터로 합계와 개수, 최솟값과 최댓값처럼 두 가지 집계를 동시에 구할 때 스트림을 두 번 돌리거나 중간 리스트를 만들기 쉽습니다. `Collectors.teeing(downstream1, downstream2, merger)`는 두 컬렉터에 각 원소를 동시에 흘려보낸 뒤 두 결과를 병합 함수로 합쳐, 단 한 번의 순회로 결합된 값을 만들어 줍니다.

```java
record Stats(long count, double sum, double average) {}

Stats result = Stream.of(10, 20, 30, 40)
    .collect(Collectors.teeing(
        Collectors.counting(),                       // 1번째 집계
        Collectors.summingDouble(Integer::doubleValue), // 2번째 집계
        (count, sum) -> new Stats(count, sum, sum / count)
    ));
// Stats[count=4, sum=100.0, average=25.0]
```

> 💡 **왜 중요한가**: 두 개의 독립적인 집계를 단일 패스로 묶어내 스트림 중복 순회나 임시 컬렉션 없이 깔끔하게 결합 결과를 얻습니다.
