### 1. Apple Safari 27, 네이티브 MCP 서버 정식 탑재 — 브라우저가 AI 에이전트의 프로그래밍 가능한 인터페이스가 됐다

Safari 27.0이 2026년 9월 17일 출시되면서 소비자용 메이저 브라우저 최초로 네이티브 MCP(Model Context Protocol) 서버를 탑재했다. Settings > Developer에서 "Allow remote automation and external agents"를 켜면 Claude·Codex 등 MCP 지원 에이전트가 DOM 접근·네트워크 요청·스크린샷·콘솔 출력을 라이브 브라우저 창에서 가져올 수 있다. `/usr/bin/safaridriver --mcp`로 실행되며 모든 호출이 로컬에서만 처리된다는 게 Apple의 설명이지만, 엔터프라이즈용 오프 스위치가 없어 논란이 되고 있다.

> 💡 **왜 중요한가**: 브라우저 자동화가 벤더별 확장 프로그램이나 Playwright 같은 헤드리스 도구가 아니라 OS 기본 브라우저의 표준 인터페이스로 열렸다 — 백엔드 개발자 입장에서 "웹 자동화 파이프라인을 에이전트가 직접 구동한다"는 시나리오가 현실화됐다.

### 2. Plugin4Shell 공개 — AI 코딩 에이전트의 SHA 핀 무력화, Claude Code·Codex·Copilot·Gemini CLI 동시 타격

AIR Security가 2026년 9월 17일 공개한 Plugin4Shell은 AI 에이전트 생태계 최초의 공급망 취약점이다. 플러그인의 SHA 핀 메커니즘을 우회해, 승인된 정상 플러그인이 자동 업데이트 경로로 악성 브랜치를 끌어다 붙일 수 있다 — 사용자 상호작용 없는 완전한 zero-click RCE. Anthropic은 Claude Code 2.1.179로, OpenAI는 Codex 0.146.0으로 패치를 밀어냈지만 Microsoft Copilot은 아직 패치 없음, Google은 Gemini CLI를 그대로 deprecate하고 Antigravity로 이관을 강권했다.

> 💡 **왜 중요한가**: "AI 에이전트에 관리자 권한을 위임한다"는 실무의 암묵적 전제를 처음으로 흔든 사건 — 사내에서 어떤 코딩 에이전트의 어떤 버전이 돌고 있는지, 플러그인 자동 업데이트 정책이 뭔지 지금 당장 감사할 근거가 생겼다.

### 3. Backstage 1.54, MCP + AiResource 엔티티 정식 — 사내 개발자 포털이 AI 에이전트의 '지도'가 됐다

Spotify가 오픈소스로 밀고 있는 Backstage가 2026년 들어 순수 서비스 카탈로그에서 'AI 허브'로 무게중심을 옮겼다. 4월 BackstageCon(암스테르담)에서 발표한 Actions Registry + MCP 서버 지원이 실제 릴리스로 굳어졌고, v1.54부터는 카탈로그에 `AiResource` 엔티티 타입이 정식 등재됐다 — 플러그인·허용 툴·라이선스·호환성 정보를 필드로 관리한다. Claude Code, Cursor 같은 코딩 에이전트가 사내 Software Catalog·Templates·TechDocs를 MCP로 직접 조회하는 게 표준 시나리오가 됐다.

> 💡 **왜 중요한가**: "우리 사내에 어떤 서비스가 있고, 어느 팀이 오너고, 어떤 스펙인가"를 사람이 위키에서 찾던 시대가 끝났다 — 에이전트가 카탈로그를 프로토콜 수준에서 읽으므로, 백엔드 아키텍트의 다음 숙제는 코드가 아니라 '내 서비스 메타데이터가 MCP-ready인가'다.
