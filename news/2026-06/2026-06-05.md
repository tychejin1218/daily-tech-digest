## 2026년 6월 5일 — 백엔드 / 클라우드 / AI 최신 뉴스

### 1. Microsoft, OS급 AI 에이전트 샌드박스 'MXC' 공개 — Windows 커널 차원의 격리, OpenAI·NVIDIA 합류
Microsoft Build 2026(6/2~6/4)에서 발표된 'Microsoft Execution Containers(MXC)'는 Windows·WSL 전반에 적용되는 정책 기반 에이전트 실행 레이어로, OS 커널이 런타임에 AI 에이전트의 접근 권한을 직접 강제합니다. 단일 SDK·정책 모델로 프로세스/세션 격리를 구성해 UI 스푸핑, 입력 인젝션, 크로스 세션 데이터 유출을 차단하며, OpenAI와 NVIDIA가 초기 파트너로 합류했습니다.

> 💡 **왜 중요한가**: 에이전트 보안이 SDK 단이 아니라 OS 커널 단의 표준 인프라로 내려오는 첫 시도 — 'Windows = 에이전트 런타임'을 실제 코드로 구현한 사건입니다.

### 2. Cisco 'Cloud Control' 발표 — AI 에이전트가 직접 운영·방어하는 인프라 통합 플랫폼 (6/3 CA 개시)
Cisco Live US 2026(라스베이거스)에서 공개된 Cloud Control은 네트워킹·보안·컴퓨트·관측성·협업을 단일 로그인·단일 데이터 레이어로 통합한 에이전틱 운영 플랫폼입니다. 인간 운영자와 AI 에이전트가 동일한 컨텍스트에서 작업하되 의사결정 권한은 사람에게 남기는 구조이며, 자연어로 앱·에이전트 생성이 가능하고 무중단 취약점 차단 기능인 Live Protect도 Nexus 9000 등으로 확장됩니다. 미국 Controlled Availability는 2026년 6월 3일 시작됐습니다.

> 💡 **왜 중요한가**: '에이전트가 인프라를 운영한다'는 명제를 풀스택 벤더가 정식 제품으로 묶어 출시한 첫 사례 — 운영툴이 단편적 SaaS가 아닌 통합 OS로 재편되는 신호탄입니다.

### 3. Microsoft 'Project Solara' 공개 — Android 기반 '에이전트 전용 디바이스' 플랫폼, chip-to-cloud 일관 스택
같은 Build 2026에서 공개된 Project Solara는 Windows가 아닌 Android(AOSP) 위에서 동작하는, 앱 대신 AI 에이전트를 실행하기 위해 설계된 새 디바이스 플랫폼입니다. 음성·얼굴 인식 기반 데스크톱 허브(모니터 연결 시 클라우드 Windows로 전환), 지문 터치로 회의 녹취·전사 및 카메라 액션을 수행하는 웨어러블 직원 배지 등 헬스케어·리테일·금융용 콘셉트 디바이스가 시연됐고, 실리콘 파트너와의 OEM 모델로 확장됩니다.

> 💡 **왜 중요한가**: 'AI 에이전트가 PC라는 폼팩터를 넘어 실세계 업무 디바이스로 직접 침투'하는 첫 본격 플랫폼 — 모바일 시대의 안드로이드 생태계와 유사한 OEM 파편화/확산이 예상됩니다.
