### 1. Mistral, Medium 3.5 + 'Vibe Remote Agents' 동시 공개 — 128B Dense에 256k 컨텍스트, SWE-Bench 77.6%로 클라우드 코딩 에이전트 경쟁 본격 진입 (5/2~3)
Mistral AI가 5월 초 플래그십 모델 **Medium 3.5**(128B Dense, 256k 컨텍스트)와 함께 클라우드 기반 비동기 코딩 에이전트인 **Vibe Remote Agents**를 출시했다. 모델은 채팅·추론·코드를 단일 모델로 통합했고 SWE-Bench Verified에서 **77.6%**를 기록했으며, 수정 MIT 라이선스로 Hugging Face에 오픈웨이트로 공개됐다. Vibe 세션은 CLI 또는 Le Chat에서 스폰 가능하며, 로컬 세션을 히스토리·상태 손실 없이 클라우드 격리 샌드박스로 'teleport'할 수 있다.

> 💡 **왜 중요한가**: 유럽 진영이 GPT-5.5 / Claude / Kimi K2.6에 맞서 '오픈웨이트 + 클라우드 에이전트'라는 차별 포지션을 명확히 했으며, 로컬↔클라우드 세션 이전(teleport) 패턴은 IDE-퍼스트가 아닌 'CLI-퍼스트 비동기 코딩'의 새 디자인 표준이 될 가능성이 크다.

### 2. DigitalOcean, 'AI-Native Cloud' 정식 공개 — 추론·에이전트 시대 전용 5-레이어 스택, AgentCore 대비 약 39% 저렴 (Deploy 2026)
DigitalOcean이 자사 컨퍼런스 Deploy 2026에서 **인프라·코어 클라우드·인퍼런스·데이터·관리형 에이전트**의 5계층으로 구성된 AI-Native Cloud를 출시했다. 핵심은 자연어로 모델 풀과 우선순위를 정의해 비용·지연을 최적화하는 **Inference Router**, 그리고 vLLM 포크·튜닝된 KV-cache·speculative decoding·GPU-aware 스케줄링을 탑재한 **Inference Engine**이다. H100/H200/HGX B300, AMD MI300X/MI350X/MI355X GPU를 400G RoCE RDMA 패브릭에 묶은 20개 글로벌 데이터센터로 운영되며, 1M 예약/월 트래블 에이전트 워크로드 기준 월 $67,727로 AWS AgentCore($110,337) 대비 약 39% 저렴하다고 공시했다.

> 💡 **왜 중요한가**: 'AWS Bedrock / Google Vertex / Azure Foundry' 빅3 아래 가격대를 정조준한 '추론 전용 클라우드' 카테고리의 첫 정식 진입 사례로, 중·소규모 팀이 에이전트 워크로드를 풀스택으로 운영할 때 코스트 벤치마크가 새로 형성된다.

### 3. Cloudflare 'Project Think' — Agents SDK 차세대 프리미티브, Durable Execution·Sub-Agents·Sessions·Codemode 통합
Cloudflare가 Agents SDK의 차세대 격인 **Project Think**(`@cloudflare/think`)를 공개했다. 핵심 프리미티브는 ① 크래시 복구·체크포인팅·자동 keepalive를 갖춘 **fiber 기반 durable execution**, ② 자체 SQLite와 typed RPC를 가진 **격리형 sub-agents**, ③ 트리 구조 메시지·포킹·풀텍스트 검색·**비파괴 컴팩션**(요약 기반)을 지원하는 **persistent sessions**, ④ Dynamic Workers·codemode·런타임 npm 해석을 활용한 **샌드박스 코드 실행**이다. 컨텍스트가 한도를 넘어도 원본은 SQLite에 보존된 채 요약본만 활성 컨텍스트에 들어가는 구조가 특징이다.

> 💡 **왜 중요한가**: 'LangGraph / OpenAI Agents SDK / Bedrock Agent Registry'와 달리, **에이전트 런타임 자체가 서버리스 플랫폼의 1급 객체**가 되는 모델을 제시했다. 컴팩션이 비파괴라는 점은 장기 실행 에이전트의 감사·재현성 문제를 인프라 레벨에서 해결하려는 시도로, MCP·Bedrock과 함께 '에이전트 런타임 표준 경쟁'의 또 다른 축이 된다.
