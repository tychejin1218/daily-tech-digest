### `String.repeat(int)`로 문자열 반복을 표준 API 한 줄로 처리하기 (Java 11 정식)

Java 11부터 `String` 클래스에 `repeat(int count)` 메서드가 추가되어 문자열을 지정한 횟수만큼 반복한 결과를 얻을 수 있습니다. 기존에는 `StringBuilder`로 루프를 돌리거나 `String.join()`, `Collections.nCopies()` 같은 우회 방법을 써야 했지만, 이제는 `"-".repeat(50)` 처럼 자연스럽게 표현할 수 있습니다. 내부적으로는 배열 복사를 지수적으로 확장하는 방식으로 최적화되어 있어 순진한 루프보다 빠릅니다.

```java
String divider = "=".repeat(80);
String indent = " ".repeat(depth * 2);
String csv = ",".repeat(columns - 1);
```

> 💡 **왜 중요한가**: 로그 구분선, 들여쓰기, 패딩 같은 일상적인 문자열 조작을 표준 API로 명확하게 표현할 수 있어 가독성과 성능을 동시에 얻을 수 있습니다.

### `Map.entry()`로 불변 엔트리를 즉석에서 만들기 (Java 9 정식)

Java 9부터 제공되는 `Map.entry(K, V)` 정적 팩토리는 불변 `Map.Entry` 인스턴스를 손쉽게 생성해줍니다. `AbstractMap.SimpleImmutableEntry`를 직접 인스턴스화하거나 임시 `Map`을 만들어 `entrySet()`을 꺼내는 번거로운 방법을 대체할 수 있습니다. 특히 `Map.ofEntries()`와 함께 쓰면 10개를 초과하는 큰 불변 맵도 깔끔하게 정의할 수 있고, 스트림에서 키-값 쌍을 만들어 `Collectors.toMap()`으로 수집할 때도 유용합니다.

```java
Map<String, Integer> statusCodes = Map.ofEntries(
    Map.entry("OK", 200),
    Map.entry("CREATED", 201),
    Map.entry("NOT_FOUND", 404),
    Map.entry("SERVER_ERROR", 500)
);

var pairs = users.stream()
    .map(u -> Map.entry(u.id(), u.name()))
    .toList();
```

> 💡 **왜 중요한가**: 키-값 쌍이라는 매우 흔한 데이터 구조를 별도 클래스 정의 없이 표준 API로 표현할 수 있어, 튜플이 없는 Java에서 임시 페어를 다루는 가장 관용적인 방법이 됩니다.
