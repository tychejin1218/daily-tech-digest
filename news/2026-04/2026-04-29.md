### OpenAI-Microsoft 독점 파트너십 종료 — AWS·Oracle·Google Cloud로 모델 전면 개방

OpenAI와 Microsoft가 2026년 4월 28일 파트너십 조건을 개정하면서 Azure 독점 조항을 해제했다. GPT-5.5와 Codex 계열이 AWS Bedrock, Oracle Cloud, Google Cloud Vertex AI에서 순차적으로 서빙되며, 엔터프라이즈 고객은 이제 하나의 API 계약으로 멀티클라우드 배포·리전 이중화가 가능해졌다.

> 💡 **왜 중요한가**: 5년간 Azure에 묶여 있던 GPT 계열이 풀리면서 "OpenAI 쓰려면 Azure"라는 아키텍처 제약이 사라졌고, 백엔드 팀은 이제 데이터 잔류·레이턴시·비용만으로 클라우드를 고를 수 있다.

### Kubernetes v1.36 'Nebula' 정식 릴리스 — In-Place VPA·SidecarContainers GA, PodSecurityPolicy 완전 제거

2026년 4월 22일 공개된 Kubernetes 1.36은 신기능보다 "프로덕션 신뢰성"에 초점을 맞춰 In-Place Pod Vertical Scaling과 SidecarContainers를 GA로 승격했고, 2019년부터 유예됐던 PodSecurityPolicy API를 완전히 제거했다. 또한 Structured Authentication Config가 GA로 올라 OIDC 다중 발급자를 kube-apiserver 재시작 없이 리로드할 수 있게 됐다.

```yaml
resizePolicy:
  - resourceName: cpu
    restartPolicy: NotRequired  # Pod 재시작 없이 CPU/메모리 조정
  - resourceName: memory
    restartPolicy: RestartContainer
```

> 💡 **왜 중요한가**: In-Place VPA GA로 Java/Spring 워크로드가 GC 튜닝 실패 시 재시작 없이 힙을 늘릴 수 있어, HPA·VPA 조합의 오랜 장애 패턴이었던 "리사이즈 = 롤링 재배포"가 드디어 사라졌다.

### Google Cloud, 8세대 TPU를 훈련용 'TPU 8t'와 인퍼런스용 'TPU 8i' 두 종으로 분리 출시

Cloud Next '26에서 공개된 TPU 8세대는 처음으로 단일 SKU를 포기하고 훈련 특화 8t(HBM4 384GB, ICI 4.8Tbps)와 인퍼런스 특화 8i(저정밀 FP4 우선, per-chip 소비전력 40% 감소)로 분리됐다. 8i는 이전 세대 대비 달러당 성능이 80% 개선됐으며, Vertex AI Prediction과 GKE 모두에서 4월 29일부터 GA 워크로드에 편성 가능하다.

> 💡 **왜 중요한가**: LLM 트래픽 90% 이상이 인퍼런스로 쏠린 현실을 반영해 하드웨어 자체가 이원화된 첫 사례로, 서빙 비용 구조 재설계가 강제되고 프리필/디코드 분리 아키텍처가 사실상 표준이 됐다.
