### `Collectors.teeing()`로 스트림을 한 번만 순회해서 두 가지 결과 동시에 얻기 (Java 12 정식)

평균과 합계, 최댓값과 최솟값처럼 같은 데이터에서 두 가지 집계 결과가 필요할 때 보통 스트림을 두 번 돌리거나 별도 변수를 두게 됩니다. `Collectors.teeing()`은 두 개의 다운스트림 collector를 동시에 적용하고 마지막 BiFunction으로 결과를 합쳐주기 때문에, 한 번의 순회로 두 결과를 묶어 반환할 수 있습니다.

```java
record Stats(double avg, long count) {}

Stats stats = numbers.stream()
    .collect(Collectors.teeing(
        Collectors.averagingInt(Integer::intValue),
        Collectors.counting(),
        Stats::new
    ));
```

> 💡 **왜 중요한가**: 단일 패스로 다중 집계를 깔끔하게 표현할 수 있어 중간 변수와 반복 순회를 줄이고, 의도가 한눈에 드러나는 코드를 만들 수 있습니다.

### `SequencedCollection`으로 첫/마지막 원소 접근과 역순 순회를 표준 API로 통일하기 (Java 21 정식)

지금까지 `List`의 첫 원소는 `list.get(0)`, `Deque`는 `peekFirst()`, `LinkedHashSet`은 별도 메서드가 없어 이터레이터를 돌려야 하는 등 "순서 있는 컬렉션"임에도 API가 제각각이었습니다. Java 21에서 도입된 `SequencedCollection`, `SequencedSet`, `SequencedMap` 인터페이스는 `getFirst()`, `getLast()`, `addFirst()`, `addLast()`, `reversed()`를 표준화해 어떤 컬렉션이든 동일한 방식으로 접근할 수 있게 해줍니다.

```java
List<String> list = List.of("a", "b", "c");
String first = list.getFirst();      // "a"
String last  = list.getLast();       // "c"
List<String> reversed = list.reversed(); // ["c", "b", "a"] 뷰

LinkedHashSet<Integer> set = new LinkedHashSet<>(List.of(1, 2, 3));
set.addFirst(0); // [0, 1, 2, 3]
```

> 💡 **왜 중요한가**: 컬렉션 타입에 따라 달라지던 인덱스 접근/역순 처리 코드가 일관된 메서드 호출로 통일되어, 가독성이 좋아지고 구현 교체 시 깨질 일이 줄어듭니다.
