### `Map.entry(K, V)`로 불변 Map 엔트리를 표준 API로 즉석 생성하기 (Java 9 정식)

`Map.entry()`는 `null`을 허용하지 않는 불변 `Map.Entry` 인스턴스를 즉시 만들어주는 정적 팩토리 메서드로, `AbstractMap.SimpleImmutableEntry` 생성자를 직접 호출하던 관례를 대체한다. `Map.ofEntries()`와 조합하면 10쌍 이상의 큰 초기값 맵도 가독성을 유지하면서 선언할 수 있다.

```java
Map<String, Integer> statusCodes = Map.ofEntries(
    Map.entry("OK", 200),
    Map.entry("CREATED", 201),
    Map.entry("NOT_FOUND", 404),
    Map.entry("SERVER_ERROR", 500)
);

Map.Entry<String, Integer> single = Map.entry("PENDING", 202);
```

> 💡 **왜 중요한가**: `new AbstractMap.SimpleImmutableEntry<>()`의 장황함 없이 불변 엔트리를 표준 API 한 줄로 만들 수 있어 큰 상수 맵 선언과 스트림 변환 코드가 훨씬 깔끔해진다.

### `CompletableFuture.completeOnTimeout()`로 비동기 작업에 기본값 타임아웃 부여하기 (Java 9 정식)

`completeOnTimeout(value, timeout, unit)`은 지정한 시간 내에 결과가 오지 않으면 예외를 던지는 대신 미리 정의한 기본값으로 Future를 완료시킨다. 예외를 던지고 싶다면 `orTimeout()`을 쓰고, 폴백 값을 반환하고 싶다면 `completeOnTimeout()`을 쓰는 식으로 역할을 명확히 나눌 수 있다.

```java
CompletableFuture<String> priceLookup = CompletableFuture
    .supplyAsync(() -> externalApi.fetchPrice("BTC"))
    .completeOnTimeout("N/A", 300, TimeUnit.MILLISECONDS);

String price = priceLookup.join();
```

> 💡 **왜 중요한가**: 별도 `ScheduledExecutorService`와 취소 로직을 짜지 않고도 비동기 호출에 안전한 폴백 타임아웃을 걸 수 있어 외부 API 연동 코드의 회복력이 크게 올라간다.
