### SpaceX, Cursor 60억 달러에 인수 — 개발자 IDE가 우주 로켓 회사 손에 들어간 날

일론 머스크의 SpaceX가 AI 코딩 IDE 업체 Cursor를 600억 달러 규모에 인수하며 개발자 도구 시장의 판도를 뒤흔들었다. 4월 출시된 Cursor 3는 이미 "AI 편집기"에서 "다중 에이전트 플랫폼"으로 정체성을 재정의했고, 로컬-클라우드 세션을 매끄럽게 이동하는 Cloud Handoff와 멀티 레포 워크스페이스, 통합 에이전트 사이드바를 앞세워 왔다. 인수 후 SpaceX 인프라(Starlink·자체 데이터센터)와 결합될 것이란 관측이 나온다.

> 💡 **왜 중요한가**: IDE는 더 이상 텍스트 편집기가 아니라 "에이전트 오케스트레이션 계층"이며, 이제 그 계층을 누가 소유하느냐가 클라우드·모델 벤더의 다음 전쟁터가 됐다.

### Firebase Genkit, Agents API 프리뷰 공개 — "채팅 앱 배관"을 chat() 한 줄로

Google Firebase의 오픈소스 프레임워크 Genkit이 7월 1일 TypeScript·Go용 Agents API 프리뷰를 공개했다. 메시지 히스토리, 툴 루프, 스트리밍, 세션 영속화, 클라이언트 와이어 프로토콜까지 챗형 에이전트 앱이 매번 다시 짜야 했던 배관을 단일 `chat()` 인터페이스 뒤로 숨겼고, 인프로세스와 HTTP 실행이 동일 코드로 돌아간다. 위험 액션 전 사람 승인을 받는 인터럽터블 툴, 스냅샷 ID로 재접속 가능한 롱러닝 턴, Vercel AI SDK `useChat` 어댑터가 백엔드 개발자 관점의 킬러 기능이다.

> 💡 **왜 중요한가**: 지금까지 에이전트 백엔드는 "세션 관리 코드를 매번 다시 짜기" 게임이었는데, Genkit이 이걸 표준화하면서 Spring 개발자들도 자바 진영 어댑터가 나올 시점을 계산해야 한다.

### Perplexity Computer, 'Brain' 메모리 시스템 탑재 — 에이전트가 어제의 실수를 기억한다

7월 13일 Perplexity가 자사 Computer 에이전트에 자기 학습형 메모리 시스템 'Brain'을 추가했다. 세션·커넥터·파일·과거 의사결정을 아우르는 프라이빗 컨텍스트 그래프를 만들고 밤사이 그래프를 갱신해, 다음 작업이 시작될 때부터 "무엇이 통했고 무엇이 실패했는지"를 알고 출발한다. Perplexity는 반복 작업의 답 정확도가 25% 향상, 컨텍스트 헤비 작업의 리콜이 16% 상승, 비용은 13% 감소했다고 밝혔다.

> 💡 **왜 중요한가**: 에이전트의 다음 차별화 축은 "더 큰 컨텍스트 윈도우"가 아니라 "어제 학습을 오늘로 이어붙이는 영속 메모리 아키텍처"이며, 이는 벡터 DB·그래프 DB 백엔드 설계 요건을 근본적으로 바꾼다.
