### OpenAI, GPT-5.5 정식 출시 — Terminal-Bench 2.0 82.7% 달성한 '실전 에이전트' 모델

OpenAI가 2026-04-23 코드네임 'Spud'로 알려진 GPT-5.5(Thinking·Pro)를 정식 공개했다. Terminal-Bench 2.0 82.7%, FrontierMath Tier 1–3 51.7%로 자율적으로 장기 작업을 완료하는 실전 에이전트 성능을 강조했으며, 무료 티어에는 미개방, API 접근은 하루 뒤인 4월 24일부터 열렸다.

> 💡 **왜 중요한가**: 프론티어 모델이 "무엇을 아는가"에서 "얼마나 스스로 끝내는가"로 축이 완전히 이동했다는 신호탄이다.

### Google Cloud Next '26, 'Gemini Enterprise Agent Platform' GA — Vertex AI를 삼킨 에이전트 통합 플랫폼

라스베이거스에서 열린 Next '26 개막일(4/22)에 Google Cloud가 Vertex AI를 진화시킨 Gemini Enterprise Agent Platform을 GA로 공개했다. 200개 이상의 모델(Gemini 3.1 Pro·Flash Image, Claude Opus 4.7 포함)이 Model Garden에 탑재됐고, 에이전트 오케스트레이션·거버넌스·옵저버빌리티·에이전트 아이덴티티 관리가 하나의 콘솔로 묶였다. 파트너용 7.5억 달러 혁신 펀드와 크로스 클라우드 레이크하우스 'Agentic Data Cloud'도 함께 발표됐다.

> 💡 **왜 중요한가**: 엔터프라이즈에서 에이전트를 실제 배포할 때 걸리는 정체성·정책·데이터 grounding 문제를 한 벤더가 세로로 풀겠다는 선언이다.

### Microsoft, Agent Framework 1.0 GA — Semantic Kernel + AutoGen 통합, MCP·A2A 기본 탑재

Microsoft가 4월 초 Agent Framework 1.0을 .NET·Python 양쪽에서 정식 출시했다. Semantic Kernel의 엔터프라이즈 안정성과 AutoGen의 멀티에이전트 오케스트레이션을 하나의 오픈소스 SDK로 합쳤고, Model Context Protocol(MCP)과 Agent2Agent(A2A) 프로토콜이 런타임에 GA로 내장되어 외부 툴·다른 벤더 에이전트를 코드 변경 없이 연결할 수 있다.

> 💡 **왜 중요한가**: 벤더 락인 없이 크로스 런타임으로 에이전트를 붙일 수 있는 표준이 '자바 진영에도' 열렸다는 뜻으로, 백엔드 개발자에게 실무 채택 임계점이 확 낮아졌다.
