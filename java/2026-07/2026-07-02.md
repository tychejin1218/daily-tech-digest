### `Collectors.teeing()`로 두 컬렉터의 결과를 한 번의 스트림으로 합치기 (Java 12 정식)

같은 스트림에서 평균과 최댓값처럼 서로 다른 집계를 동시에 얻으려면 보통 스트림을 두 번 돌리거나 중간 리스트로 재료화해야 했습니다. `Collectors.teeing(downstream1, downstream2, merger)`는 두 컬렉터를 병렬로 실행한 뒤 그 결과를 `BiFunction`으로 병합해, 한 번의 순회로 원하는 형태(레코드, 튜플 등)로 즉시 조합할 수 있습니다.

```java
record Stats(double avg, int max) {}

Stats stats = orders.stream()
    .collect(Collectors.teeing(
        Collectors.averagingInt(Order::amount),
        Collectors.maxBy(Comparator.comparingInt(Order::amount)),
        (avg, maxOrder) -> new Stats(avg, maxOrder.orElseThrow().amount())
    ));
```

> 💡 **왜 중요한가**: 스트림을 두 번 돌리거나 임시 컬렉션을 만들 필요 없이 여러 집계 결과를 한 번의 순회로 도메인 객체에 곧바로 담을 수 있어, I/O 스트림처럼 재순회가 불가능한 소스에서도 안전하게 동작합니다.

### `SequencedCollection` API로 첫 원소·마지막 원소 접근을 통일하기 (Java 21 정식)

`List.get(0)`, `Deque.peekFirst()`, `LinkedHashSet`의 첫 원소 얻기처럼 컬렉션마다 제각각이던 "처음/끝 원소" 접근이 `SequencedCollection` 인터페이스로 표준화됐습니다. `getFirst()`, `getLast()`, `addFirst()`, `addLast()`, `reversed()`가 `List`, `Deque`, `LinkedHashSet`, `LinkedHashMap` 등에 공통으로 도입되어 컬렉션 타입 간 코드 가독성과 대체성이 크게 개선됩니다.

```java
List<String> logs = new ArrayList<>(List.of("A", "B", "C"));
String head = logs.getFirst();   // "A"
String tail = logs.getLast();    // "C"
List<String> reversed = logs.reversed(); // 뷰(view)라 원본과 연동

LinkedHashSet<String> visited = new LinkedHashSet<>();
visited.addLast("home");
visited.addLast("cart");
String recent = visited.getLast(); // "cart"
```

> 💡 **왜 중요한가**: `list.get(list.size() - 1)` 같은 관용구나 컬렉션별 이질적 API를 없애고, `reversed()`로 뷰 기반 역순 순회까지 지원해 실수와 인덱스 계산 버그를 원천 차단합니다.
