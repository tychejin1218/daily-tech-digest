### `Files.mismatch(Path, Path)`로 두 파일의 첫 차이 바이트 위치를 한 줄로 찾기 (Java 12 정식)
`Files.mismatch(p1, p2)`는 두 파일을 바이트 단위로 비교해 처음 다른 위치의 인덱스를 반환하고, 완전히 동일하면 `-1L`을 돌려줍니다. 직접 `InputStream`을 열어 버퍼 비교 루프를 짤 필요 없이 표준 API 한 줄로 동등성 검사와 차이 위치 진단을 모두 처리할 수 있습니다. 빌드 산출물 검증, 다운로드 무결성 확인, 테스트의 골든 파일 비교 등에 특히 유용합니다.

> 💡 **왜 중요한가**: 해시 계산이나 전체 로드 없이 스트리밍 비교로 끝나, 큰 파일 비교에서도 메모리 사용을 최소화하면서 차이 발생 지점까지 정확히 알려주기 때문입니다.

### `Objects.checkIndex(index, length)`로 배열·리스트 경계 검사를 표준화하기 (Java 9 정식)
`Objects.checkIndex(i, length)`는 `0 <= i < length`를 검증하고 위반 시 표준화된 `IndexOutOfBoundsException`을 던지며, 성공 시 검사한 인덱스를 그대로 반환해 그대로 사용할 수 있습니다. 함께 추가된 `checkFromToIndex`, `checkFromIndexSize`까지 활용하면 구간(range) 검사도 일관된 예외 메시지로 표현할 수 있고, HotSpot이 인트린식으로 최적화해 수동 `if (i < 0 || i >= len) throw ...`보다 오버헤드도 적습니다.

> 💡 **왜 중요한가**: 컬렉션·버퍼 등 JDK 내부에서도 사용되는 표준 가드라 예외 메시지·동작이 통일되고, JIT 인트린식 최적화 덕분에 안전성과 성능을 동시에 챙길 수 있습니다.
