### 1. Amazon TorchNeuron 공개 — PyTorch 코드 한 줄만 바꾸면 Trainium에서 돈다, Nvidia CUDA의 '소프트웨어 해자'를 겨눴다

PyTorch Conference North America 개막일(10/20)에 Amazon이 Meta PyTorch 팀과 함께 Trainium2/3용 네이티브 백엔드 `TorchNeuron`을 Apache 2.0으로 공개하고 퍼블릭 베타를 바로 열었다. 기존 PyTorch 코드에 `.to('neuron')` 한 줄만 바꾸면 eager 모드·torch.compile·FSDP2·텐서/파이프라인 병렬·FlashAttention이 그대로 동작하며, HuggingFace Transformers v5·TorchTitan·vLLM이 재작성 없이 올라간다. 디자인 파트너로 Anthropic·Databricks·HuggingFace·Salesforce·poolside가 이름을 올렸고, Deepgram은 GPU 베이스라인 대비 '달러당 오디오 초'가 60% 증가했다고 공개했다.

> 💡 **왜 중요한가**: Nvidia의 진짜 해자는 H100이 아니라 CUDA였는데, "코드를 다시 안 써도 된다"가 사실이면 Trainium은 비로소 '선택지'가 된다 — AWS 리전에서 추론 비용을 깎고 싶은 팀의 결정 비용이 급락한다.

### 2. Google Vertex AI, Gemini 2.5 Pro/Flash/Flash-Lite 오늘(10/20)부로 서비스 종료 — 핀된 챗봇과 에이전트가 조용히 깨진다

Vertex AI의 `gemini-2.5-pro`·`gemini-2.5-flash`·`gemini-2.5-flash-lite`가 2026-10-20부로 정식 폐기됐고, 공식 마이그레이션 경로는 2.5 Pro → `gemini-3.8-flash`(또는 3.5-flash), 2.5 Flash → `gemini-3.8-flash`/`3.5-flash-lite`/`3.1-flash-lite` 순으로 안내된다. Gemini API 쪽은 "No shutdown date announced"로 남아 있어 Vertex 바인딩 코드만 선별적으로 터지는 상황이고, 호환성 깨짐 포인트는 샘플링 파라미터·`thinking_budget`·matching ID 없는 function response·PDF 토큰 카운트 네 곳으로 좁혀진다.

> 💡 **왜 중요한가**: "모델 ID만 바꾸면 되지 않나"가 아니다 — `thinking_budget`과 function-calling ID 매칭이 바뀌면서 에이전트 루프가 조용히 멈추거나 과금이 폭발한다. 오늘자로 프로덕션 Vertex 호출을 하는 팀은 리트라이 로그부터 봐야 한다.

### 3. OpenAI Codex CLI 0.163 공개 — 응답 중간에 '말을 끊어' 방향을 돌리는 Mid-Response Steering이 기본값이 됐다

10월 15~16일 롤아웃된 Codex CLI 0.163은 에이전트가 답을 쓰고 있는 도중에 사용자가 후속 메시지를 보내면 즉시 방향을 꺾는 'instant response steering'을 기본 동작으로 승격했다. `/config` 전역 검색, `/keymap`의 리더 키(기본 `Ctrl+X`), skill·memory·conversation-history 조회를 포함한 read-only 툴의 병렬 실행, 스레드 복구·네트워크 가드레일·Windows 클립보드 지원이 함께 들어왔고, 적격 계정에는 'Daybreak' 모델이 켜졌다.

> 💡 **왜 중요한가**: 지금까지 코딩 에이전트는 "일단 끝까지 답하고 → 사람이 되돌린다"였는데, 중간 개입이 1급 시민이 되면 에이전트의 작업 단위가 '턴'에서 '스트림'으로 바뀐다 — 긴 리팩터링을 돌릴 때 Ctrl+C로 죽이고 다시 프롬프트하는 패턴이 사라진다.
