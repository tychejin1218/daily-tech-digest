### 1. `java.net.http.HttpClient.newHttpClient()` (Java 11 정식, JEP 321)로 동기·비동기 HTTP 호출 통합하기 — `HttpURLConnection` 열고 `InputStream` 수동으로 읽어 바이트 조립하는 관성 벗어나기

JDK 내장 `HttpClient`는 HTTP/2, WebSocket, 비동기(`sendAsync`)를 한 API로 제공하므로, 외부 라이브러리 없이도 `BodyHandlers.ofString()` 한 줄로 응답 본문을 받아올 수 있다. `HttpURLConnection`은 타임아웃 설정이 분산되어 있고 리다이렉트·게이트웨이 에러 처리가 번거로워서, 간단한 사이드카 호출조차 유틸 클래스가 비대해지는 원인이었다.

```java
// Before: HttpURLConnection — 리소스 수동 관리, 타임아웃/인코딩 산재
HttpURLConnection conn = (HttpURLConnection) new URL(url).openConnection();
conn.setConnectTimeout(2000);
conn.setReadTimeout(3000);
conn.setRequestMethod("GET");
try (InputStream is = conn.getInputStream()) {
    byte[] bytes = is.readAllBytes();
    String body = new String(bytes, StandardCharsets.UTF_8);
}

// After: HttpClient — 동기/비동기 동일 API, HTTP/2 기본
HttpClient client = HttpClient.newBuilder()
        .connectTimeout(Duration.ofSeconds(2))
        .version(HttpClient.Version.HTTP_2)
        .build();

HttpRequest req = HttpRequest.newBuilder(URI.create(url))
        .timeout(Duration.ofSeconds(3))
        .GET()
        .build();

// 동기
String body = client.send(req, BodyHandlers.ofString()).body();

// 비동기 — 그대로 CompletableFuture 파이프라인에 연결
CompletableFuture<String> future = client.sendAsync(req, BodyHandlers.ofString())
        .thenApply(HttpResponse::body);
```

> 💡 **왜 중요한가**: `HttpClient` 하나로 동기/비동기 전환이 메서드명만 바뀌는 수준이라, Spring MVC 서블릿 스레드와 WebFlux/가상 스레드 어느 쪽으로 가도 호출 코드가 그대로 재활용된다.

### 2. `String.indent(n)` / `String.stripIndent()` (Java 12·15 정식, JEP 378)로 텍스트 블록·멀티라인 로그 정렬하기 — `split("\n")` 돌려 각 줄 앞에 공백 붙이는 관성 벗어나기

텍스트 블록(`"""..."""`)이나 외부에서 받은 멀티라인 문자열을 들여쓰기해서 로그·에러 메시지에 끼워 넣을 때, `String.indent(int n)`은 각 라인 앞에 공백 `n`칸을 붙이고 끝에 개행까지 맞춰준다. 음수를 넘기면 공통 들여쓰기만큼 제거하므로, 수동 `split`/`join` 루프가 전부 사라진다.

```java
// Before: 줄 단위로 쪼개서 공백 수동 조립
String sql = "SELECT id, name\nFROM users\nWHERE active = true";
String indented = Arrays.stream(sql.split("\n"))
        .map(line -> "    " + line)
        .collect(Collectors.joining("\n"));
log.warn("Slow query detected:\n" + indented);

// After: indent() 한 번
String sql = """
        SELECT id, name
        FROM users
        WHERE active = true
        """;
log.warn("Slow query detected:\n{}", sql.indent(4));
// → 각 줄 앞에 공백 4칸, 끝에 개행 자동 보정

// 텍스트 블록이 아닌, 외부 입력의 공통 들여쓰기만 제거하고 싶을 때
String normalized = userInput.stripIndent();  // 공통 선행 공백 자동 계산 후 제거
```

> 💡 **왜 중요한가**: 로그·예외 메시지·마크다운 조립에서 들여쓰기 유틸을 직접 짜던 코드가 사라지고, 텍스트 블록과 결합하면 SQL·JSON 템플릿을 Java 소스에서 "보이는 그대로" 보존하면서도 정렬된 모양으로 출력할 수 있다.
