### `String.chars()`와 `codePoints()`로 문자열을 IntStream으로 순회하기 (Java 8 정식)

`String.chars()`는 문자열을 `IntStream`으로 반환해 스트림 연산을 그대로 적용할 수 있게 해준다. 이모지나 서로게이트 페어까지 정확히 다뤄야 한다면 `codePoints()`를 써야 하는데, 이는 유니코드 코드 포인트 단위로 스트림을 만들어 준다.

```java
String text = "Hello 안녕 🌍";

long letterCount = text.chars()
    .filter(Character::isLetter)
    .count();

long emojiCount = text.codePoints()
    .filter(cp -> cp > 0xFFFF)
    .count();

String upper = text.codePoints()
    .map(Character::toUpperCase)
    .collect(StringBuilder::new, StringBuilder::appendCodePoint, StringBuilder::append)
    .toString();
```

> 💡 **왜 중요한가**: `for (char c : ...)` 순회는 서로게이트 페어 문자를 반쪽만 다루지만, `codePoints()`는 유니코드 규격대로 안전하게 순회한다.

### `Collectors.teeing()`으로 스트림을 두 갈래로 집계해 하나로 합치기 (Java 12 정식)

`Collectors.teeing()`은 동일한 스트림을 두 개의 다운스트림 컬렉터에 동시에 흘려보내고, 두 결과를 병합 함수로 합쳐 반환한다. 평균/합계, 최솟값/최댓값처럼 한 스트림에서 두 통계를 뽑아 하나의 객체로 조립할 때 스트림을 두 번 순회할 필요가 없다.

```java
record Stats(int min, int max) {}

List<Integer> scores = List.of(72, 88, 95, 61, 79);

Stats stats = scores.stream()
    .collect(Collectors.teeing(
        Collectors.minBy(Integer::compare),
        Collectors.maxBy(Integer::compare),
        (min, max) -> new Stats(min.orElseThrow(), max.orElseThrow())
    ));
// Stats[min=61, max=95]
```

> 💡 **왜 중요한가**: 두 번의 스트림 순회나 임시 변수 없이 한 번의 파이프라인으로 복합 집계 결과 객체를 만들 수 있다.
