### Cline 3.85, GPT-5.5(SAP AI Core) & DeepSeek V4 통합 릴리스

VS Code 기반 오픈소스 코딩 에이전트 Cline이 2026년 5월 25일 v3.85를 공개하며 SAP AI Core를 경유한 GPT-5.5 라우팅과 DeepSeek V4 Flash·Pro 프로바이더를 추가했다. 엔터프라이즈 SAP 계정만으로 프론티어 모델을 호출할 수 있게 되어 사내 감사·과금 파이프라인을 그대로 유지한 채 에이전트 코딩이 가능해졌다.

```jsonc
// .cline/providers.json
{
  "provider": "sap-ai-core",
  "model": "gpt-5.5",
  "deployment_id": "d-xxxx",
  "auth": "oauth2-client-credentials"
}
```

> 💡 **왜 중요한가**: BYO-키·BYO-엔드포인트가 자리 잡으면서 AI 코딩 에이전트 도입이 보안팀 승인 없이도 조직 표준 인증 게이트웨이를 통과할 수 있게 됐다.

### MongoDB Atlas, Voyage AI 기반 'Automated Embedding' 퍼블릭 프리뷰

MongoDB가 5월 Atlas 업데이트에서 필드 단위 자동 재임베딩(Automated Embedding)과 중첩 임베딩(Nested Embedding)을 퍼블릭 프리뷰로 공개했다. 문서 필드에 애노테이션만 붙이면 Voyage AI 임베딩 모델이 트리거되어 값이 변경될 때마다 벡터가 재계산되므로 별도 sync worker·CDC 파이프라인이 필요 없다.

```javascript
db.products.createSearchIndex({
  name: "auto_vec",
  definition: {
    fields: [{
      type: "vector",
      path: "description",
      model: "voyage-3-large",   // Atlas가 자동 호출
      dimensions: 1024,
      similarity: "cosine"
    }]
  }
})
```

> 💡 **왜 중요한가**: 프로덕션 RAG의 최대 골칫거리였던 '임베딩 최신성' 문제가 데이터베이스 계층으로 내려가면서 애플리케이션 코드에서 임베딩 파이프라인이 사라지는 시대가 열렸다.

### pgvector 0.8.2 긴급 보안 패치 — HNSW 병렬 빌드 버퍼 오버플로우(CVE-2026-3172)

PostgreSQL 벡터 확장 pgvector가 5월 말 0.8.2를 긴급 배포하며 CVE-2026-3172를 수정했다. 병렬 HNSW 인덱스 빌드 경로에서 힙 청크 경계 계산 오류로 인접 릴레이션의 페이지가 벡터 인덱스에 노출될 수 있는 취약점으로, 멀티테넌트 SaaS에서 다른 테넌트의 임베딩이 검색 결과에 섞여 나올 수 있었다.

```sql
-- 취약 버전 확인
SELECT extversion FROM pg_extension WHERE extname = 'vector';
-- 0.8.1 이하면 즉시 업그레이드
ALTER EXTENSION vector UPDATE TO '0.8.2';
-- 이미 병렬로 빌드된 HNSW는 재생성 권장
REINDEX INDEX CONCURRENTLY items_embedding_hnsw_idx;
```

> 💡 **왜 중요한가**: 벡터 검색이 '단순 유사도'가 아니라 권한·프라이버시 경계선을 넘나드는 스토리지로 자리 잡으면서, 인덱스 취약점 하나가 곧바로 데이터 격리 사고가 되는 구조로 바뀌었다.
