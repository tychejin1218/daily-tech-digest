### `Files.mismatch()`로 두 파일의 동일성을 바이트 단위로 빠르게 비교하기 (Java 12 정식)

Java 12부터 도입된 `Files.mismatch(Path, Path)`는 두 파일을 바이트 단위로 비교해 첫 번째로 다른 바이트의 위치를 반환하며, 완전히 동일하면 `-1L`을 반환합니다. 기존에는 두 파일 전체를 읽어 `Arrays.equals()`로 비교하거나 해시를 계산해야 했지만, 이 API는 내부적으로 최적화된 청크 단위 비교를 수행하여 다른 지점을 발견하면 즉시 종료합니다.

```java
long mismatchIndex = Files.mismatch(Path.of("original.pdf"), Path.of("backup.pdf"));
if (mismatchIndex == -1L) {
    System.out.println("두 파일은 완전히 동일합니다");
} else {
    System.out.println("첫 번째 차이 위치(byte): " + mismatchIndex);
}
```

> 💡 **왜 중요한가**: 백업 검증, 파일 무결성 확인, 테스트 픽스처 비교 같은 상황에서 해시 계산이나 전체 로딩 없이 표준 API 한 줄로 정확하고 효율적인 파일 동일성 판별이 가능합니다.

### `Collectors.teeing()`으로 하나의 스트림에서 두 집계를 동시에 처리하기 (Java 12 정식)

Java 12에 추가된 `Collectors.teeing(downstream1, downstream2, merger)`는 스트림을 두 번 순회하지 않고도 서로 다른 두 collector의 결과를 하나로 결합할 수 있게 해줍니다. 예를 들어 평균과 합계, 최댓값과 최솟값, 개수와 리스트를 동시에 얻어야 할 때 스트림을 재생성하거나 임시 컬렉션을 저장할 필요가 없습니다.

```java
record Stats(double average, long count) {}

Stats stats = orders.stream()
    .collect(Collectors.teeing(
        Collectors.averagingDouble(Order::amount),
        Collectors.counting(),
        Stats::new
    ));
```

> 💡 **왜 중요한가**: 단일 패스로 여러 집계를 산출하므로 대용량 스트림에서 성능 이점이 크고, 중간 변수나 재순회 코드 없이 의도가 명확한 함수형 파이프라인을 유지할 수 있습니다.
