# 2026-06-14 백엔드/서버/클라우드/AI 주요 IT 뉴스

### 1. GitHub Copilot, 'AI Credits' 기반 사용량 과금 전면 전환 — 6월 1일 발효, 9월 1일까지 프로모션 크레딧 제공
6월 1일부터 GitHub Copilot이 기존 PRU(Premium Request Unit)를 폐기하고 **GitHub AI Credits**(1 credit = $0.01)로 전환했다. 모든 모델 호출이 입력·출력·캐시 토큰 단위로 측정되어 공시 API 요금으로 환산되며, Pro($10), Pro+($39), Business($19/seat) 플랜에 동액 크레딧이 포함된다. 코드 자동완성과 Next Edit Suggestions만 무제한으로 남고, PR 리뷰조차 Actions 분당 요금으로 계산되기 시작했다.

> 💡 **왜 중요한가**: 'AI 코딩 도구 = 정액제'라는 가정이 깨지면서, 에이전트·체이닝·자동 PR 리뷰처럼 토큰을 폭식하는 워크플로의 TCO를 팀 단위로 다시 모델링해야 한다.

### 2. Workday Sana, Google Gemini Enterprise에 네이티브 통합 — Gemini가 기본 추론 엔진, 300+ HR·재무 스킬 탑재
Workday가 5월 28일 발표한 Google Cloud 파트너십이 6월 들어 본격 롤아웃되며, **Sana for Workday**의 기본 LLM이 Gemini Enterprise로 전환됐다. Sana Self-Service Agent는 휴가 잔여·급여명세·인사정보 조회 등 300개 이상 스킬을 지원하고, Sana Enterprise는 Gmail·Outlook·Salesforce·SharePoint까지 가로지른다. 대부분 작업의 응답 지연이 2초 미만으로 측정돼 대화형 UX 임계치를 통과했다.

> 💡 **왜 중요한가**: SaaS 거버넌스 데이터가 곧 에이전트의 'system of record'가 되는 흐름이 굳어지면서, 사내 LLM API는 RAG가 아니라 '권한이 살아있는 액션 레이어' 위에 얹는 패턴이 표준화되고 있다.

### 3. Microsoft, Azure Cobalt 200 ARM VM 얼리액세스 공개 — 132코어·3nm, 에이전틱 AI 워크로드용 'CPU 최적화 티어'
Build 2026에서 예고된 **Azure Cobalt 200** Arm 기반 VM이 6월 초 얼리액세스 프리뷰로 풀렸다. TSMC 3nm 공정에 132코어·코어별 DVFS·기본 메모리 암호화(Arm CCA + HSM/Key Vault FIPS 140-3)를 탑재하며, 전 세대 Cobalt 100 대비 최대 50% 성능 향상이다. Office·Teams·Azure SQL 일부 내부 워크로드가 이미 이전 중이고, AI 추론·데이터 파이프라인·API 티어를 노린 'scale-out 에이전트 전용' 인스턴스로 포지셔닝됐다.

> 💡 **왜 중요한가**: GPU가 학습·대형 추론을 가져가는 동안 '에이전트 오케스트레이션·툴 호출·벡터 후처리' 같은 CPU 바운드 워크로드가 별도 티어로 분리되며, 클라우드 비용 최적화에서 ARM-CPU 인스턴스 선택이 새로운 기본 결정이 됐다.
