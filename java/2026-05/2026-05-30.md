### `Objects.requireNonNullElse()`로 null 대체 값을 표준 API 한 줄로 처리하기 (Java 9 정식)

`Objects.requireNonNullElse(obj, defaultObj)`는 첫 번째 인자가 null이 아니면 그대로 반환하고, null이면 두 번째 기본값을 반환한다. 삼항 연산자나 `Optional.ofNullable(x).orElse(y)`보다 간결하고 의도가 명확하며, 지연 평가가 필요한 경우 `requireNonNullElseGet(obj, supplier)`를 쓰면 기본값 계산을 미룰 수 있다.

```java
String name = Objects.requireNonNullElse(user.getName(), "익명");
List<String> tags = Objects.requireNonNullElseGet(input, List::of);
```

> 💡 **왜 중요한가**: null 대체 로직을 표준 API로 통일하면 코드 리뷰에서 관성적으로 나오는 `x != null ? x : y` 패턴을 없애고 의도를 명시적으로 드러낼 수 있다.

### `Stream.takeWhile()` / `dropWhile()`로 정렬된 스트림을 조건 기반으로 자르기 (Java 9 정식)

`takeWhile(predicate)`은 조건이 처음으로 거짓이 되는 순간까지의 앞부분을 취하고, `dropWhile(predicate)`은 그 반대로 조건이 거짓이 되는 지점부터 뒷부분을 취한다. `filter`가 전체를 훑으며 조건을 통과한 요소만 남기는 것과 달리, 이들은 정렬된 데이터에서 "특정 임계까지만" 또는 "특정 임계 이후만" 같은 시간·값 기반 슬라이싱에 특히 적합하다.

```java
List<LogEntry> recent = logs.stream()
    .takeWhile(e -> e.timestamp().isAfter(cutoff))
    .toList();

List<Integer> afterZero = Stream.of(-2, -1, 0, 1, 2, 3)
    .dropWhile(n -> n < 0)
    .toList(); // [0, 1, 2, 3]
```

> 💡 **왜 중요한가**: 정렬된 로그·시계열 데이터를 조건이 무너지는 지점에서 즉시 컷하면 불필요한 순회를 없애고 코드 의도도 훨씬 명확해진다.
