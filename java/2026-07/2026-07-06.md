### `Collection.toArray(IntFunction)`로 배열 생성 없이 타입 안전한 배열 변환하기 (Java 11 정식)

기존 `toArray(new T[0])` 패턴은 빈 배열 인스턴스를 만들어 넘겨야 했지만, Java 11부터는 `IntFunction`을 받는 오버로드로 배열 생성자 참조만 넘기면 된다. 컴파일 타임 타입 안전성이 보장되고 코드도 훨씬 간결해진다.

```java
List<String> names = List.of("Alice", "Bob", "Carol");

// 기존 방식
String[] old = names.toArray(new String[0]);

// Java 11+ 권장
String[] modern = names.toArray(String[]::new);
```

> 💡 **왜 중요한가**: 배열 크기 지정이나 빈 배열 할당 없이 생성자 참조 한 줄로 타입 안전한 배열을 얻어 가독성과 성능을 동시에 챙긴다.

### `Optional.ifPresentOrElse()`로 값 존재 여부에 따른 두 갈래 로직을 한 번에 처리하기 (Java 9 정식)

`ifPresent()`는 값이 있을 때만 동작하고 없을 때 처리하려면 `isPresent()` 분기가 따로 필요했다. Java 9의 `ifPresentOrElse()`는 값이 있으면 `Consumer`, 없으면 `Runnable`을 실행해 두 갈래를 하나의 표현식으로 묶는다.

```java
Optional<User> user = repository.findById(id);

user.ifPresentOrElse(
    u -> log.info("found: {}", u.getName()),
    () -> log.warn("user not found: {}", id)
);
```

> 💡 **왜 중요한가**: `if-else` 분기 없이 존재/부재 두 경우의 부수 효과를 한 호출로 표현해 Optional 사용 시 명령형 잔재를 제거한다.
