### GitHub, 'Spec Kit 2.0' 정식 출시 — '스펙 우선 코딩'이 Copilot의 디폴트 워크플로우가 됐다, YAML 한 장이 PR 한 묶음으로 바뀐다

GitHub가 11월 13일 Spec Kit 2.0을 GA로 전환하며 `spec.yaml` 하나로 요구사항·API·테스트·마이그레이션 PR을 동시에 생성하는 워크플로우를 Copilot의 기본으로 승격시켰다. 1.x에서는 실험 CLI였던 것이 이제 Copilot Workspace와 VS Code 내장으로 들어왔고, 스펙 파일 자체가 PR 리뷰 단위로 취급된다. 코드가 아니라 명세가 1급 아티팩트가 되는 구조다.

> 💡 **왜 중요한가**: '요구사항 → 코드'가 수작업 번역이 아니라 `git diff` 가능한 파일로 고정됐다, 코드 리뷰 문화가 '스펙 리뷰'로 한 겹 위로 올라간다.

### Redis 9.0 GA — '벡터 세트' 네이티브 자료형이 들어왔다, pgvector·Pinecone 2강 체제에 세 번째 축이 꽂혔다

Redis 9.0이 11월 14일 정식 공개되며 `VSET` 커맨드 패밀리와 HNSW 인덱스를 코어에 박아넣었다. RediSearch 모듈 없이도 `VSET.ADD`/`VSET.KNN` 한 줄로 벡터 검색이 되고, 기존 TTL·pub-sub·스트림과 한 트랜잭션에 묶인다. 에이전트의 '단기 기억'을 별도 DB 없이 Redis 하나로 처리하는 레퍼런스가 공개와 동시에 쏟아지고 있다.

> 💡 **왜 중요한가**: '세션 캐시 Redis + 벡터 DB 별도'라는 이중 스택이 한 프로세스로 접혔다, LLM 앱의 기본 스토리지 토폴로지가 다시 그려진다.

### Fly.io 'Machines v3' 공개 — 128GB VRAM GPU 머신이 '요청당 300ms 콜드스타트'로 떴다, 서버리스 추론의 가격 바닥이 또 내려갔다

Fly.io가 Machines v3 런타임을 공개하며 H200/B200 GPU 인스턴스의 콜드스타트를 300ms대로 끌어내렸다. snapshot-restore로 모델 가중치가 RAM 이미지째로 보존되고, 유휴 상태에선 GPU 요금이 과금되지 않는다. Cloudflare Workers AI·Modal·RunPod이 깔아둔 '초 단위 과금 GPU' 레이스에 FaaS형 가격 모델이 본격 진입했다.

> 💡 **왜 중요한가**: '추론 호출 1건당 GPU 1초'로 단위가 쪼개지며, 전용 인스턴스를 계속 띄워둬야 하는 셀프호스팅 LLM의 TCO 계산이 통째로 바뀐다.
