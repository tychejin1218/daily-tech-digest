### 1. Anthropic Claude Developer Platform, 5개 베타 일괄 정식 GA — Computer Use · Browser Use · Files API · Agent Skills · Admin API가 프로덕션 라인으로 한꺼번에 넘어왔다
Anthropic이 Claude Developer Platform의 다섯 개 핵심 베타 — Computer Use(`computer_toolset_20260801`), Browser Use, Files API, Agent Skills + Skills API, Admin API user management — 를 8월 19일 자로 동시에 GA로 승격했다. Computer Use는 이번 GA와 함께 HIPAA 컴플라이언스, 매니지드 에이전트 도메인 컨트롤, 샌드박스 메모리 스토어, 재설계된 세션 뷰어까지 함께 얹혔다.

> 💡 **왜 중요한가**: '베타 헤더 붙여서 실험용'으로 취급받던 에이전트 스택이 이번 GA로 SLA·컴플라이언스·조직 관리까지 갖춘 '엔터프라이즈 API'로 승격됐다 — 이제 컴퓨터 조작·브라우저·파일·스킬을 프로덕션 계약서에 넣을 수 있다.

### 2. Anthropic ↔ Lambda Labs, 5년 $35B GPU 인프라 계약 체결 — AWS·GCP 위에 얹은 '제3의 사일로'로 전환
Anthropic이 Lambda Labs와 5년간 $35B 규모의 GPU 캐패시티 계약을 체결하며 AWS Trainium·Google TPU에 이은 '세 번째 컴퓨트 사일로'를 확보했다. Lambda 측 인프라는 주로 '대규모 배치 인퍼런스·에이전트 오케스트레이션 계층'용으로 전환되며, Post-Incident Security Response 문서에서 언급된 멀티-리전 격리 전략과 정확히 매칭된다.

> 💡 **왜 중요한가**: AI 프로바이더의 GPU 조달이 '단일 하이퍼스케일러 종속'에서 '멀티클라우드 헤지'로 완전히 넘어갔다 — 이제 컴퓨트 SPOF(단일 장애점)가 없는 것이 API SLA의 '숨은 조항'으로 편입된다.

### 3. HashiCorp Terraform, 모듈 내 `import` 블록 + `terraform_data` 프라이빗 스토어 + Deferred Actions 정식 릴리스 — '레거시 인프라 IaC 이관'과 '알 수 없는 값 처리'가 드디어 표준 코스로
Terraform이 모듈 내부에서 `import` 블록을 쓸 수 있게 되면서, 지금까지 루트 모듈에서만 가능하던 '기존 인프라를 IaC로 편입시키는' 작업이 재사용 가능한 모듈 레벨로 내려왔다. 여기에 프로바이더가 plan/apply 사이에 프라이빗 데이터를 보존하는 `terraform_data` store block, 그리고 `-allow-deferral` 옵션으로 `count`/`for_each`가 unknown 값을 받아들이는 Deferred Actions까지 실험 딱지를 뗐다.

> 💡 **왜 중요한가**: '기존 인프라 IaC 이관'이 스크립트·수작업 → 재사용 가능한 모듈 패턴으로 승격되면서, Terraform이 드디어 'greenfield 프로비저닝 툴'에서 'brownfield 마이그레이션 툴'로 확장된다 — 대형 조직의 legacy AWS/GCP 계정을 IaC로 정리할 수 있는 '표준 절차'가 처음으로 생긴 셈이다.
