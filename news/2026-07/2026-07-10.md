### MySQL 9.7 LTS 정식 출시 — 새로운 장기 지원 라인 확립

Oracle이 MySQL 9.7을 새로운 LTS(Long-Term Support) 릴리스로 공개했다. 벡터 데이터 타입의 안정화와 InnoDB 병렬 리두 로그 개선, JavaScript 스토어드 프로시저의 GA 승격이 포함되어 있으며, 이전 8.4 LTS 대비 온라인 DDL 대상 컬럼 타입이 확대되었다.

```sql
-- 9.7에서 GA로 승격된 벡터 인덱스 예시
CREATE TABLE docs (
  id BIGINT PRIMARY KEY,
  embedding VECTOR(1536),
  VECTOR INDEX vec_idx (embedding) USING HNSW
);
```

> 💡 **왜 중요한가**: OLTP DB가 벡터 검색을 1급 시민으로 다루기 시작하면서, RAG 워크로드를 별도 벡터 스토어 없이 기존 트랜잭션 DB에서 처리할 수 있는 선택지가 하나 더 열렸다.

### etcd v3.7.0 릴리스 — 오래 기다린 RangeStream API 도입

Kubernetes 컨트롤 플레인의 핵심 저장소인 etcd가 3.7.0을 공개하며 RangeStream을 정식 지원한다. 대용량 키 범위 조회 시 전체 응답을 메모리에 로드하지 않고 스트리밍으로 흘려보내, 수십만 오브젝트를 가진 클러스터에서 API 서버 재시작 시의 리스트 부하가 큰 폭으로 줄어든다.

> 💡 **왜 중요한가**: 대규모 K8s 클러스터의 콜드 스타트 지연과 OOM 이슈를 정면으로 해결하는 변경으로, 컨트롤 플레인 튜닝 관행 자체가 다시 쓰일 여지가 있다.

### Google Antigravity IDE 퍼블릭 프리뷰 — 다중 에이전트 오케스트레이션이 기본

Google이 Gemini 3 시리즈를 백본으로 하는 에이전트 우선 IDE 'Antigravity'를 공개 프리뷰로 열었다. 여러 코딩 에이전트가 리포지토리 전체를 병렬로 편집하고, 각 에이전트의 계획·수정 이력을 타임라인으로 시각화하며, 개인 플랜은 무료로 제공된다. VS Code 확장 호환성을 유지해 기존 워크플로에서 점진적 도입이 가능하다.

> 💡 **왜 중요한가**: 단일 페어 프로그래머 모델을 넘어 '에이전트 팀'을 관리하는 UX가 하이퍼스케일러 기본 IDE 수준으로 진입했다는 신호다.
