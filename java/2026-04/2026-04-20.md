### `Pattern Matching for instanceof`로 타입 검사와 캐스팅을 한 번에 처리하기 (Java 16 정식)

`instanceof` 검사와 별도 캐스팅을 하던 번거로움을 하나의 문법으로 통합한다. 검사에 성공하면 지정한 변수에 자동으로 바인딩되어 즉시 사용할 수 있고, 스코프도 컴파일러가 추론해 관리한다.

```java
Object obj = "Hello, Java";

// Before (Java 15 이하)
if (obj instanceof String) {
    String s = (String) obj;
    System.out.println(s.toUpperCase());
}

// After (Java 16+)
if (obj instanceof String s) {
    System.out.println(s.toUpperCase());
}

// 조건 결합도 자연스럽게
if (obj instanceof String s && !s.isBlank()) {
    System.out.println(s.length());
}
```

> 💡 **왜 중요한가**: 반복되던 타입 캐스팅 보일러플레이트를 제거하고 실수로 잘못된 타입으로 캐스팅할 여지를 컴파일 타임에 차단한다.

### `Stream.toList()`로 스트림 결과를 불변 리스트로 간결하게 수집하기 (Java 16 정식)

기존 `.collect(Collectors.toList())` 대신 `Stream` 인터페이스에 직접 추가된 종단 연산으로, 코드가 짧아지고 반환 리스트가 불변(immutable)이라는 점이 명확해진다. `Collectors.toUnmodifiableList()`와 달리 null 원소도 허용한다는 세부 차이가 있다.

```java
List<String> names = Stream.of("kim", "lee", "park")
    .map(String::toUpperCase)
    .toList();  // Java 16+

// names.add("choi"); // UnsupportedOperationException — 불변 리스트

// 비교: 기존 방식
List<String> old = Stream.of("kim", "lee", "park")
    .map(String::toUpperCase)
    .collect(Collectors.toList());  // 구현체는 ArrayList — 가변
```

> 💡 **왜 중요한가**: 스트림 결과를 우발적으로 변경하는 버그를 원천 차단하면서, `Collectors` import 없이 한 줄로 마무리할 수 있다.
