### Anthropic, Claude Code 2.1.139에 'Agent View' 리서치 프리뷰 공개 — 병렬 세션을 단일 CLI 대시보드로 통합

5월 11일 출시된 Agent View는 여러 개의 tmux 패널·터미널 탭으로 흩어져 있던 Claude Code 세션을 하나의 CLI 화면에서 관리하게 해준다. `claude agents` 또는 활성 세션에서 좌측 화살표를 누르면 세션 ID·대기 상태·마지막 응답·타임스탬프가 표시되고, `/bg` 또는 `claude --bg [task]`로 에이전트를 백그라운드로 보냈다가 입력이 필요한 시점에만 복귀할 수 있다. Pro·Max·Team·Enterprise·API 플랜에 동시 제공되며 기존 레이트리밋은 그대로 적용된다.

> 💡 **왜 중요한가**: 멀티 에이전트 코딩이 IDE/터미널 외부 도구 없이 CLI 안에서 표준화되면서, 사람이 동시에 감독할 수 있는 에이전트 수가 본격적으로 늘어난다.

### OpenAI, TanStack npm 공급망 공격(`Mini Shai-Hulud`)에 직원 단말 2대 노출 — 내부 레포 자격증명 일부 유출

5월 11일 UTC에 TanStack/router 저장소가 포크-위장(`zblgg/configuration`)과 `pull_request_target` 워크플로우, GitHub Actions 캐시 오염 3단계 체인으로 침해되면서 악성 pnpm store가 배포됐고, OpenAI 직원 단말 2대가 영향을 받았다. 공격자는 두 직원이 접근 가능한 일부 사내 소스 레포에서 자격증명 위주의 정보를 빼낸 것으로 확인됐으며, 프로덕션 시스템·고객 데이터·소프트웨어 변조는 없는 것으로 OpenAI는 밝혔다. 동일 캠페인은 Mistral AI, UiPath를 포함해 160개 이상의 npm·PyPI 패키지로 확산됐고, 위협 그룹은 `TeamPCP`로 추적되고 있다.

> 💡 **왜 중요한가**: AI 코딩 에이전트가 npm·GitHub Actions를 자동 실행하는 환경에서 단일 `pull_request_target` 설정 실수가 프런티어 랩의 내부 자격증명까지 흘려보낼 수 있다는 사실이 실측됐다.

### Subquadratic, 1,200만 토큰 컨텍스트 LLM 'SubQ' 출범 — Subquadratic Sparse Attention으로 12M 토큰 어텐션 비용 1/1,000

마이애미 스타트업 Subquadratic이 시드 2,900만 달러와 함께 SubQ를 공개했다. 모든 토큰을 짝지어 비교하는 표준 dense attention 대신 SSA(Subquadratic Sparse Attention)가 토큰별로 관련성 높은 부분집합만 계산해, 컨텍스트 길이에 대해 선형으로 스케일한다 — 1M 토큰에서 FlashAttention 대비 최대 52배 효율, 12M 토큰에서는 어텐션 연산이 약 1,000배 절감된다. RULER 128K에서 95% (Claude Opus 4.7의 94.8%와 동급)를 기록했고, 동일 평가 실행 비용은 SubQ ≈$8 vs Opus ≈$2,600이다. API·SubQ Code·SubQ Search는 현재 웨이트리스트 한정 얼리액세스.

> 💡 **왜 중요한가**: 대형 모놀리식 코드베이스·로그 전체를 한 번에 던지는 '롱-호라이즌 에이전트' 시나리오의 비용 장벽이 처음으로 frontier 품질에서 1/100 수준으로 떨어졌다.
