### 1. `HexFormat`으로 바이트 배열과 16진수 문자열을 안전하게 상호 변환하기 (Java 17 정식)

기존에는 `String.format("%02x", b)` 루프나 외부 라이브러리(Apache Commons, Guava)에 의존해 바이트를 hex로 변환했지만, Java 17부터는 표준 `java.util.HexFormat` 클래스로 깔끔하게 처리할 수 있습니다. 구분자·접두사·대소문자 옵션을 빌더식으로 지정할 수 있어 MAC 주소(`HexFormat.ofDelimiter(":")`)나 해시 출력 포맷팅에 특히 유용하며, 역방향 파싱(`parseHex`)도 지원합니다.

```java
byte[] bytes = {(byte)0xCA, (byte)0xFE, (byte)0xBA, (byte)0xBE};
String hex = HexFormat.of().withUpperCase().formatHex(bytes); // "CAFEBABE"
byte[] back = HexFormat.of().parseHex(hex);
String mac = HexFormat.ofDelimiter(":").formatHex(bytes); // "ca:fe:ba:be"
```

> 💡 **왜 중요한가**: 흔한 보일러플레이트와 외부 의존성을 제거하면서 양방향 변환을 표준 API 하나로 일관되게 처리할 수 있습니다.

### 2. `Pattern Matching for switch`와 `record` 디컨스트럭션으로 다형 분기 단순화하기 (Java 21 정식)

Java 21부터 `switch` 표현식에서 타입 패턴과 `record` 디컨스트럭션 패턴을 함께 쓸 수 있어, `instanceof` + 캐스팅 + 게터 호출이 반복되던 코드를 단일 식으로 압축할 수 있습니다. `when` 절로 가드 조건을 붙일 수 있고, sealed 계층과 결합하면 컴파일러가 분기 완전성(exhaustiveness)을 검사해 `default` 없이도 안전합니다.

```java
sealed interface Shape permits Circle, Rectangle {}
record Circle(double r) implements Shape {}
record Rectangle(double w, double h) implements Shape {}

double area = switch (shape) {
    case Circle(double r) -> Math.PI * r * r;
    case Rectangle(double w, double h) when w == h -> w * w;
    case Rectangle(double w, double h) -> w * h;
};
```

> 💡 **왜 중요한가**: 데이터 중심 분기 로직을 선언적으로 표현하면서 컴파일러가 누락된 케이스를 잡아주므로, 가독성과 안전성을 동시에 확보합니다.
