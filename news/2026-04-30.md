### Microsoft-OpenAI 독점 종료, 다음 날 AWS Bedrock에 OpenAI 모델·Codex 정식 상륙
4월 27일 Microsoft와 OpenAI가 파트너십을 재구성하며 클라우드 독점 조항을 해제하자, 단 24시간 만에 AWS가 Amazon Bedrock에 OpenAI 프런티어 모델(GPT-5.4, GPT-5.5 곧 추가)과 Codex 코딩 에이전트, 그리고 'Bedrock Managed Agents powered by OpenAI'를 리미티드 프리뷰로 동시 공개했다. Codex는 Bedrock을 통해 CLI·데스크톱 앱·VS Code 확장으로 동일하게 호출되며, 엔터프라이즈는 OpenAI 모델을 기존 Bedrock의 파인튜닝·오케스트레이션 파이프라인에 그대로 끼워 넣을 수 있게 된다.

> 💡 **왜 중요한가**: 'OpenAI = Azure 전용'이라는 4년간의 공식이 깨지며, 이제 LLM API는 모델·클라우드를 따로 고를 수 있는 진짜 멀티 벤더 시대로 진입했다.

### Google Cloud, 분기 매출 200억 달러 첫 돌파 — 그러나 "용량이 부족해서 더 못 컸다"
4월 29일 발표된 알파벳 1분기 실적에서 Google Cloud 매출이 전년 대비 +63% 성장한 200억 달러를 처음으로 넘어섰지만, 경영진은 "수요를 따라가지 못하는 GPU·TPU 용량 부족이 실질적 성장률을 제한했다"고 이례적으로 인정했다. AI Hypercomputer와 TPU 8세대(Trainium 8t/추론용 8i) 증설이 진행 중임에도, 고객사 330곳이 직전 12개월간 1조 토큰 이상을 처리하며 인프라 수요가 공급을 초과하는 구조가 굳어지는 모양새다.

> 💡 **왜 중요한가**: 하이퍼스케일러조차 GPU/TPU 부족으로 매출 기회를 놓치는 시기 — 백엔드 아키텍트는 멀티 리전·멀티 모델·인퍼런스 캐싱을 '사치'가 아니라 가용성 보험으로 설계해야 하는 신호다.

### Anthropic, Claude Code 품질 저하 사후분석 공개 + v2.1.116으로 코딩 회귀 버그 패치
4월 중순 개발자 커뮤니티에서 Sonnet/Opus 기반 Claude Code의 추론·코드 품질이 갑자기 떨어졌다는 리포트가 폭주하자, Anthropic은 4월 20일경 v2.1.116을 배포하며 ① 코딩 품질을 해치던 시스템 프롬프트 명령 제거, ② 'reasoning effort' 변경 롤백, ③ 세션 초기화 버그 수정을 단행하고 근인 분석 포스트모템을 공개했다. 같은 업데이트에서 `/tui fullscreen`(플리커 없는 풀스크린 렌더링), 푸시 알림 도구, MCP `alwaysLoad` 옵션, `/skills` 검색 박스, PR URL → 세션 매칭(GitHub/GitLab/Bitbucket) 등 IDE/에이전트 워크플로 확장이 함께 들어갔다.

> 💡 **왜 중요한가**: "AI 코딩 어시스턴트 품질이 어느 날 갑자기 변한다"는 게 더 이상 도시전설이 아닌 검증된 운영 리스크 — 팀 단위 도입 시 모델 SLO·품질 회귀 모니터링·롤백 절차를 갖추는 것이 표준 워크플로가 되고 있다.
