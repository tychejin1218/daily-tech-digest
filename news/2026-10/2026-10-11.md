### 1. AWS 'Serverless AI Runtime' 공개 — 모델 아티팩트만 올리면 GPU가 '추론 순간'에만 깨어난다
10월 10일 공개된 AWS Serverless AI Runtime은 모델 바이너리와 입출력 스키마만 던지면 플랫폼이 알아서 GPU/CPU를 할당하고, 추론 요청이 들어오는 '순간'에만 자원을 켠다. 유저는 컨테이너 이미지, 쿠버 매니페스트, 워밍 전략 중 아무것도 쓰지 않는다 — 함수(Lambda)의 '0원 스케일' 철학이 드디어 추론 레이어로 확장됐다.

> 💡 **왜 중요한가**: 추론 서빙의 가장 비싼 비용(아이들 GPU)이 '서버리스'라는 과금 모델 하나로 사라졌다 — 자가호스팅 대비 PoC·테넌트별 모델 분리의 TCO 계산식이 뒤집힌다.

### 2. Claude Code v2.1.296 공개 — Claude Desktop의 'Code 탭'이 게이트웨이 모드로 열리고, 서브에이전트에 'autoCompactWindow'가 붙었다
10월 10일 릴리스된 Claude Code v2.1.296은 Claude 앱 게이트웨이의 `managed.policies[]`에 `code` 키를 추가해 CLI 설정을 그대로 복제, Claude Desktop의 Code 탭을 '게이트웨이 모드'로 띄울 수 있게 됐다. 동시에 서브에이전트 전용 `autoCompactWindow` 옵션이 들어와 서브에이전트가 자기 컨텍스트를 '스스로' 접고 다시 돈다 — 메인 에이전트 context를 더 이상 오염시키지 않는다.

> 💡 **왜 중요한가**: 데스크톱이 CLI와 '동일 폴리시'로 묶이면 사내 거버넌스가 하나로 끝나고, 서브에이전트의 자동 컴팩션은 '멀티 에이전트가 긴 러닝 중에 터지는' 패턴의 뿌리를 뽑는다.

### 3. Reka Edge 2603 공개 — 비전·툴·구조화 출력이 '로컬 머신 한 대'로 접힌 '엣지 전용' 모델이 나왔다
10월 9일 Reka가 공개한 Edge 2603은 16K 컨텍스트에 비전·툴 콜·structured output을 전부 지원하면서 '프라이빗 머신에서 그대로 돈다'는 포지션을 들고 왔다 — OpenAI 호환 Reka Gateway(api.reka.ai)로도 input/output $0.10/백만 토큰에 콜할 수 있다. 즉, '엣지로 뽑을 모델'과 '게이트웨이로 호출할 모델'을 같은 바이너리로 쓸 수 있다는 뜻이다.

> 💡 **왜 중요한가**: '프라이빗 비전 추론'이 더는 자체 LLM 팀 + Triton + vLLM을 요구하지 않는다 — 백엔드 입장에서는 PII 영상/문서 처리의 '데이터가 외부로 안 나간다' 요건을 단일 바이너리로 만족시킬 수 있는 선택지가 하나 더 열렸다.
