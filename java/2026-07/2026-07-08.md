### `HexFormat`으로 바이트 배열과 16진수 문자열을 표준 API로 변환하기 (Java 17 정식)

기존에는 `String.format("%02x", b)`를 루프로 돌리거나 외부 라이브러리(Apache Commons, Guava)에 의존해야 했지만, Java 17부터는 `HexFormat`으로 표준화된 변환이 가능하다. 구분자, 접두어, 대소문자를 세밀하게 설정할 수 있고 파싱도 대칭적으로 지원한다.

```java
byte[] bytes = {(byte) 0xCA, (byte) 0xFE, (byte) 0xBA, (byte) 0xBE};

String hex = HexFormat.of().formatHex(bytes);
// "cafebabe"

String pretty = HexFormat.ofDelimiter(":").withUpperCase().formatHex(bytes);
// "CA:FE:BA:BE"

byte[] parsed = HexFormat.of().parseHex("cafebabe");
// 원래 바이트 배열로 복원
```

> 💡 **왜 중요한가**: 해시·암호화 결과나 바이너리 프로토콜 디버깅에서 반복되는 hex 변환 유틸을 직접 만들거나 서드파티에 기댈 필요가 없어진다.

### `switch` 패턴 매칭으로 타입 분기와 조건을 한 번에 처리하기 (Java 21 정식)

Java 21부터 `switch` 표현식이 타입 패턴과 `when` 절을 정식 지원해, `instanceof` 체인이나 `if-else` 분기를 선언형으로 대체할 수 있다. `null`도 별도 case로 다룰 수 있어 별도 방어 코드가 필요 없다.

```java
sealed interface Shape permits Circle, Rectangle, Triangle {}
record Circle(double radius) implements Shape {}
record Rectangle(double w, double h) implements Shape {}
record Triangle(double base, double height) implements Shape {}

static String describe(Shape s) {
    return switch (s) {
        case null                            -> "없음";
        case Circle c when c.radius() > 100  -> "큰 원";
        case Circle c                        -> "작은 원 r=" + c.radius();
        case Rectangle r                     -> "사각형 " + (r.w() * r.h());
        case Triangle t                      -> "삼각형";
    };
}
```

> 💡 **왜 중요한가**: `sealed` 인터페이스와 조합하면 컴파일러가 모든 하위 타입을 확인해줘 새 타입 추가 시 누락된 분기를 즉시 잡아낼 수 있다.
