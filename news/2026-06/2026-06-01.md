# 2026-06-01 백엔드/서버/클라우드/AI 최신 뉴스

### 1. xAI 'Grok Build' 코딩 에이전트 정식 출시 — Arena Mode로 8개 병렬 에이전트 경쟁
xAI가 5월 말 SuperGrok·X Premium Plus 구독자 대상으로 CLI 기반 코딩 에이전트 'Grok Build'를 공개하며 Claude Code·Codex·Gemini Code Assist와 정면 경쟁에 진입했다. 자체 학습된 `grok-code-fast-1`(SWE-Bench Verified 70.8%, 입력 100만 토큰당 $0.20)을 기반으로 plan-search-build 3단계 워크플로를 8개 서브에이전트가 동시에 실행하고, 'Arena Mode'가 결과물을 자동 채점해 개발자가 검토하기 전에 후보 출력을 랭킹화한다.

> 💡 **왜 중요한가**: Anthropic·OpenAI·Google에 이어 xAI까지 자체 코딩 모델 + 에이전트 하니스를 갖춘 풀스택을 갖추면서, 코딩 에이전트 시장이 '단일 후보 제안'에서 '여러 후보 자동 비교·채점' 구조로 전환되고 있다.

### 2. Camunda 'ProcessOS' 공개 — AWS Bedrock AgentCore 위에서 도는 에이전틱 OS (CamundaCon, 5/20)
Camunda가 연례 컨퍼런스에서 자사 오케스트레이션 플랫폼 위에 얹는 지능형 레이어 'ProcessOS'를 공개했다. 4종의 전문 에이전트(Discover·Re-engineer·Build·Improve)가 기존 업무 프로세스를 자동 발견하고, AI-first 관점으로 재설계한 뒤 KPI 기반으로 지속 최적화한다. AWS에서 네이티브로 동작하며 Amazon Bedrock과 **Bedrock AgentCore**(에이전트 메모리·아이덴티티·게이트웨이)에 깊게 통합돼 클로즈드 베타 중이다.

> 💡 **왜 중요한가**: 'BPMN 워크플로 엔진 + LLM 에이전트 + Bedrock AgentCore' 조합은 엔터프라이즈가 ServiceNow·Salesforce 외에 처음으로 손에 잡히는 '에이전트 운영 OS' 선택지를 갖게 된다는 의미다.

### 3. Hadrian 'OpenHack' 오픈소스 공개 — Claude Code·Codex·Cursor에 꽂는 AI 코드 리뷰어 (MIT)
보안 스타트업 Hadrian이 자사 내부 취약점 헌팅에 쓰던 AI 코드 리뷰 파이프라인을 'OpenHack'이라는 이름으로 MIT 라이선스 오픈소스 공개했다. Claude Code·Codex·Cursor 안에서 바로 동작하며, Hadrian 리서처들이 같은 방법론으로 네덜란드 정부 사용 OSS에서 수백 건의 취약점(크리티컬 포함)을 발견한 실전 검증 스택이다.

> 💡 **왜 중요한가**: 코딩 에이전트가 '코드를 쓰는 도구'에서 '코드를 감사하는 보안 리뷰어'로 확장되는 신호 — 별도 SaaS 결제 없이 기존 에이전트 CLI에 그대로 꽂아 쓸 수 있어 보안 리뷰의 기본기로 자리잡을 가능성이 크다.
