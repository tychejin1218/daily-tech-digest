### 1. AWS Lambda, 온디맨드 함수 30분 타임아웃 + GPU Event Functions 공개 — 서버리스가 '15분의 저주'를 깨고 LLM 추론 영토에 발을 들였다

AWS가 11월 셋째 주 서버리스 라운드업에서 Lambda 온디맨드 함수의 최대 실행시간을 15분 → 30분으로 올리고, Event Function에 GPU 인스턴스와 고객 관리형 런타임(customer-managed runtimes)을 정식 지원한다고 공식 발표했다. 'LLM 추론·에이전트 루프는 Lambda 밖에서 돌려야 한다'던 지난 5년의 상식이 깨지는 신호로, 서버리스가 Bedrock AgentCore/Fargate/EKS 영역을 거꾸로 침범하기 시작했다.

> 💡 **왜 중요한가**: 30분 + GPU + BYO 런타임 조합은 "에이전트 1틱 = Lambda 1콜"이라는 과금 모델이 처음으로 산업 표준이 되는 시점이고, '매니지드 에이전트 런타임'의 가격 바닥이 또 한 번 바닥을 친다는 뜻이다.

### 2. Microsoft Ignite 2026 'Copilot Managed Runtime' GA — Copilot Studio·Copilot Code·서드파티 툴이 '한 런타임' 안으로 빨려 들어갔다

마이크로소프트가 Ignite 2026 Book of News에서 Copilot Managed Runtime의 GA를 공식 발표했다. Copilot Studio, Copilot Code, 그리고 'compatible 서드파티 도구'로 만든 앱을 전부 마이크로소프트가 관리하는 단일 실행·거버넌스 환경에서 호스팅한다 — 즉 Azure Functions·App Service·AKS 중 어느 것 위에 돌릴지를 개발자가 더 이상 고르지 않는다. '어디서 돌리냐'가 플랫폼 벤더의 결정 사항으로 넘어간 첫 사례다.

> 💡 **왜 중요한가**: 엔터프라이즈 AI 앱의 '배포 타깃 선택권'이 사라지는 신호다 — Agent 365·Entra와 묶이면서 '에이전트 코드는 쓰되, 런타임은 MS가 먹는다'가 Azure의 디폴트가 됐고, 사내 플랫폼팀의 역할이 다시 좁아진다.

### 3. AI Daily Digest(2026-11-23): AI 에이전트가 11분 만에 '스스로' 제로데이를 발견했다 — AWS Security 리포트

AWS Security 측정 결과, 공격자 AI 에이전트가 노출된 API에 처음 접근한 지 **11분 만에 제로데이 취약점을 자체 발견하고 임의 파일 쓰기에 성공**한 반면, 같은 에이전트가 Redis 서버는 16시간·148스텝을 투입하고도 못 뚫었고 GPU 서버에는 3만 번 넘는 크리덴셜 조합을 시도했지만 실패했다. 같은 날 METR이 'AI 에이전트가 자율 수행 가능한 작업의 시간 지평(horizon)' 지표를 대폭 상향하는 보고를 냈다.

> 💡 **왜 중요한가**: '백엔드 보안 = 사람 공격자 가정' 모델이 공식적으로 금 간 날이다 — API 설계·에러 메시지·스택 트레이스 노출 하나하나가 이제 '11분짜리 공격 자동화'의 입력이 되며, LLM 코딩 에이전트와 LLM 공격 에이전트의 비대칭이 역전 구간에 들어섰다.
