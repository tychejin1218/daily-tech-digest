## 오늘의 IT 뉴스 (2026-07-17)

### 1. Google·Microsoft·Salesforce·Snowflake·ServiceNow, 공동 AI 백엔드 프로토콜 지원 합의
5대 엔터프라이즈 벤더가 Anthropic·OpenAI에 대항하기 위해 공유 AI 백엔드 프로토콜을 함께 지원하기로 합의했다. Google Cloud Next '26에서 공개된 Gemini Enterprise 플랫폼이 그 축으로, 여러 벤더에 걸쳐 AI 에이전트를 구축·오케스트레이션·거버넌스할 수 있도록 설계됐다.

> 💡 **왜 중요한가**: 에이전트 인프라 표준 전쟁이 시작됐다 — Anthropic·OpenAI의 폐쇄적 스택 vs. 하이퍼스케일러 연합의 개방형 프로토콜이라는 두 진영 구도가 굳어지고 있다.

### 2. Moonshot AI 'Kimi K2.7 Code', GitHub Copilot 모델 선택기의 첫 오픈웨이트 모델로 등재
Moonshot AI의 Kimi K2.7 Code가 GitHub Copilot 모델 선택기에서 사용 가능한 최초의 오픈웨이트 모델이 됐다. 프로바이더 리스트 요금이 Copilot의 사용량 기반 과금(AI Credits)에 그대로 적용되며, 폐쇄형 프론티어 모델(Claude·GPT·Gemini)과 동일한 UX에서 선택할 수 있다.

> 💡 **왜 중요한가**: 개발자 IDE 티어에서 오픈웨이트가 처음으로 '동등한 시민'이 됐다 — 자체 호스팅·비용 최적화 여지가 크게 열리고, 오픈 커뮤니티가 Copilot 워크로드를 직접 겨냥할 채널을 확보했다.

### 3. Anthropic Claude Opus 4.8, Google Cloud Gemini Enterprise Agent Platform에 정식 탑재
Claude Opus 4.8이 Google의 Gemini Enterprise Agent Platform에서 GA로 제공되기 시작했다. 대규모 리팩터링과 의존성 추적 등 장기 코딩 태스크에 특화된 에이전틱 능력을 강조했으며, Anthropic API 직결 없이 Vertex/Agent Platform 계약으로도 Opus 4.8을 소비할 수 있게 됐다.

> 💡 **왜 중요한가**: Anthropic이 자사 API 채널을 넘어 하이퍼스케일러의 엔터프라이즈 게이트웨이 안으로 들어왔다 — 조달·거버넌스가 Google 쪽에 묶인 대기업들도 Opus를 표준 벤더 계약만으로 도입할 수 있다.
