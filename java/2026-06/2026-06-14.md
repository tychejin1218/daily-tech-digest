### `String.indent(int)`로 멀티라인 문자열에 일관된 들여쓰기 적용하기 (Java 12 정식)

여러 줄 문자열의 모든 라인 앞에 동일한 공백을 붙이거나 제거할 때 `indent()` 메서드 한 번으로 처리할 수 있습니다. 양수면 해당 칸수만큼 공백을 추가하고, 음수면 앞쪽 공백을 그만큼 제거하며, 줄 끝에 줄바꿈이 없으면 자동으로 정규화해 붙여줍니다. 로그 포맷팅이나 코드 생성, 마크다운/HTML 출력처럼 들여쓰기 일관성이 중요한 곳에서 정규식이나 `split`/`join` 보일러플레이트 없이 깔끔하게 표현됩니다.

```java
String code = "if (x > 0) {\n    return x;\n}";
String indented = code.indent(4);
// "    if (x > 0) {\n        return x;\n    }\n"

String dedented = indented.indent(-2);
// "  if (x > 0) {\n      return x;\n  }\n"
```

> 💡 **왜 중요한가**: 멀티라인 문자열을 다루는 코드 생성·로그 출력에서 `lines().map(...).collect(...)` 같은 패턴을 한 줄로 줄여줍니다.

### `Thread.ofVirtual()`로 경량 가상 스레드를 직접 만들고 제어하기 (Java 21 정식)

`Executors.newVirtualThreadPerTaskExecutor()` 외에도 빌더 API로 가상 스레드를 세밀하게 구성할 수 있습니다. `name()`으로 디버깅 친화적인 이름을, `uncaughtExceptionHandler()`로 예외 처리를, `inheritInheritableThreadLocals(false)`로 ThreadLocal 전파 차단을 지정할 수 있어 수백만 개의 동시 작업도 OS 스레드 부담 없이 돌릴 수 있습니다. I/O 바운드 워크로드(HTTP 호출, DB 쿼리)에서 기존 플랫폼 스레드 풀의 한계를 그대로 해소합니다.

```java
Thread vt = Thread.ofVirtual()
    .name("worker-", 0)
    .uncaughtExceptionHandler((t, e) -> log.error("실패: {}", t.getName(), e))
    .start(() -> processRequest(request));

vt.join();

// 팩토리로 재사용도 가능
ThreadFactory factory = Thread.ofVirtual().name("task-", 1).factory();
```

> 💡 **왜 중요한가**: 가상 스레드의 진가는 빌더로 이름·예외 핸들러를 붙여 운영 가시성을 확보할 때 비로소 드러납니다.
