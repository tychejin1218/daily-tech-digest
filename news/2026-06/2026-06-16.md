### 1. Microsoft Work IQ API, 오늘 정식 GA — 에이전트가 M365 데이터에 직접 닿는다

Microsoft가 6월 16일자로 **Work IQ API**를 정식 출시했습니다. 이메일·캘린더·회의·채팅·파일·LOB 시스템 전반을 의미론적으로 모델링해, 외부 에이전트가 조직의 실시간 컨텍스트를 바로 조회할 수 있는 단일 진입점입니다. A2A, 재설계된 원격 **MCP 서버**, REST API 세 종류 엔드포인트를 함께 제공하며, M365 Copilot 라이선스와 분리해 **Copilot Credits 소비 기반**으로 과금합니다.

> 💡 **왜 중요한가**: "에이전트가 사내 데이터를 어떻게 안전하게 가져올 것인가"라는 엔터프라이즈 최대 난제를 Microsoft가 라이선스 없이 종량제로 풀어, 사내 RAG·에이전트 백엔드 설계의 기본값을 바꾸게 됩니다.

### 2. AWS, FinOps Agent 프리뷰 + Gemma 4 Bedrock 탑재 + Kiro Pro Max 동시 공개 (6/15)

AWS가 어제(6월 15일) Weekly Roundup에서 세 가지를 한꺼번에 풀었습니다. **AWS FinOps Agent**(프리뷰)는 비용 질의·이상치 조사·Savings Plans 추천을 자동화하고 Jira 티켓·Slack 알림까지 직접 생성합니다. **Gemma 4 패밀리**(31B Dense / 26B MoE / E2B)는 Bedrock에서 256K 컨텍스트·네이티브 함수 호출·멀티모달을 지원하며, 코딩 IDE **Kiro의 Pro Max 티어**는 프런티어 모델 우선 접근과 상향된 에이전트 한도를 제공합니다.

> 💡 **왜 중요한가**: 클라우드 비용 거버넌스(FinOps)에 에이전트가 들어오기 시작했고, Bedrock이 OpenAI·Anthropic 일변도에서 벗어나 Google 오픈웨이트까지 흡수하며 멀티 모델 허브 전략이 명확해졌습니다.

### 3. Cursor Bugbot, Composer 2.5 탑재로 PR 리뷰 시간 5분 → 90초 (6/10)

Cursor가 자사 코드 리뷰 에이전트 **Bugbot**을 자사 모델 **Composer 2.5** 기반으로 재구성했습니다. 평균 리뷰 시간 5분 → 90초(3배 이상 빠름), 비용 22% 절감, 버그 검출율 10% 향상을 달성했고, 90%의 리뷰가 3분 안에 끝납니다. push 전 `/review` 명령, 더 똑똑한 재리뷰, GitHub·GitLab 동기화 확장도 함께 추가됐습니다.

> 💡 **왜 중요한가**: 자체 모델(Composer)이 외부 프런티어 모델 호출 비용을 따라잡으면서, AI 코드 리뷰가 "선택적 기능"에서 **모든 PR 머지 게이트의 기본 단계**로 자리 잡는 전환점입니다.
