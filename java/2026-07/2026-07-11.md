### `String.indent(int)`로 여러 줄 문자열의 들여쓰기를 표준 API로 조정하기 (Java 12 정식)

`text.indent(4)`는 각 줄 앞에 공백 4칸을 붙이고, 음수 값을 주면 해당 개수만큼 앞 공백을 제거한다. 텍스트 블록으로 생성한 다중 행 문자열이나 로그 출력에서 계층을 표현할 때 수동 `replaceAll("(?m)^", "    ")` 없이 깔끔하게 처리할 수 있다.

```java
String block = """
        line1
        line2
        """;
System.out.print(block.indent(4));  // 앞에 4칸 추가
System.out.print(block.indent(-2)); // 앞 2칸 제거 (있는 만큼만)
```

> 💡 **왜 중요한가**: 정규식 치환이나 스트림 조합 없이 표준 API 한 줄로 다중 행 들여쓰기를 조정할 수 있다.

### `Math.floorDiv()` / `Math.floorMod()`로 음수 나눗셈 결과를 수학적 정의에 맞게 얻기 (Java 8 정식)

자바의 `/`와 `%` 연산자는 0 방향으로 절삭(truncated division)하므로 `-7 / 2 == -3`, `-7 % 2 == -1`이 되어 음수 피연산자에서 직관과 어긋난다. `Math.floorDiv(-7, 2)`는 `-4`, `Math.floorMod(-7, 2)`는 `1`을 돌려주며, 나머지 부호가 항상 제수(divisor)와 같아 인덱스 계산이나 순환 버퍼에서 안전하다.

```java
int i = -1;
int len = 5;
int idx1 = i % len;              // -1 (배열 인덱스로 부적합)
int idx2 = Math.floorMod(i, len); // 4 (원형 인덱스로 안전)
```

> 💡 **왜 중요한가**: 원형 버퍼, 회전 배열, 좌표 wrap-around에서 `if (x < 0) x += n` 같은 방어 코드를 없앨 수 있다.
