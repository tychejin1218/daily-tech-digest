### Prisma 6.0 정식 출시 — 엣지 네이티브 드라이버 & AI 쿼리 옵티마이저 통합

Prisma가 6.0을 릴리스하며 기존 Rust 쿼리 엔진 대신 TypeScript 네이티브 드라이버를 기본으로 채택했다. Cloudflare Workers·Vercel Edge·Deno Deploy에서 별도 어댑터 없이 동작하며, 신규 `prisma optimize` 커맨드는 슬로우 쿼리 로그를 LLM에 입력해 인덱스 추천과 N+1 리팩터링 패치를 자동 제안한다. 엣지 콜드 스타트가 평균 340ms → 12ms로 축소돼 서버리스 백엔드의 실사용 임계값이 크게 낮아졌다.

```ts
import { PrismaClient } from '@prisma/client/edge'
const prisma = new PrismaClient()
// 6.0부터 WASM 없이 순수 TS 드라이버로 실행
const users = await prisma.user.findMany({ where: { active: true } })
```

> 💡 **왜 중요한가**: ORM 계층의 콜드 스타트 오버헤드가 사라지면서 "엣지에서 관계형 DB 사용"이 실전 옵션으로 격상됐다.

### Snowflake Cortex Analyst GA — 자연어 SQL에 거버넌스 레이어 결합

Snowflake가 Cortex Analyst를 정식 출시하며 자연어 질의를 SQL로 변환할 때 세만틱 모델(YAML 정의)과 행 수준 정책을 강제 적용하는 구조를 표준화했다. 기존 텍스트-투-SQL 도구가 스키마 추론에 의존해 환각 컬럼을 생성하던 문제를, Analyst는 사전 정의된 메트릭·차원 사전에 바인딩된 쿼리만 발급하도록 제약한다. 결과 SQL은 실행 전 Verified Query 캐시와 대조되며, 감사 로그에 프롬프트·세만틱 모델 버전·최종 쿼리가 함께 기록된다.

> 💡 **왜 중요한가**: BI 도구에 LLM을 얹을 때 가장 큰 리스크였던 "환각 지표"를 스키마 계약으로 원천 차단하는 첫 GA급 솔루션이다.

### Groq, 'GroqCloud Batch' 공개 — 비동기 추론 90% 할인 요금제 도입

Groq가 LPU 기반 GroqCloud에 배치 추론 티어를 신설, 24시간 SLA 내 완료 조건으로 요금을 최대 90% 인하했다. OpenAI Batch API와 동일한 JSONL 인터페이스를 제공해 마이그레이션이 단순하며, Llama 3.3 70B 기준 100만 토큰당 입력 $0.06·출력 $0.09로 클라우드 GPU 추론 대비 압도적 단가를 형성했다. 데이터 라벨링·문서 요약·평가 파이프라인 등 지연 비민감 워크로드가 주 타깃이며, 요청은 자동으로 유휴 LPU 슬롯에 스케줄링된다.

> 💡 **왜 중요한가**: 실시간 추론용 특화 칩을 배치 모드로 재판매하면서 오프라인 LLM 파이프라인의 경제성이 근본적으로 바뀌었다.
