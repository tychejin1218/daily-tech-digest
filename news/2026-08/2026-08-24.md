### 1. Anthropic Skills API + Files API, Microsoft Foundry로 정식 확장 — LLM 파일 시스템이 '멀티클라우드 API 티어'가 됐다

Anthropic이 Skills API와 Files API를 Microsoft Foundry에 정식 배포하고, computer use / browser use 툴은 곧 Google Cloud Vertex AI에도 상륙한다. 지금까지 "Claude 전용" 확장 인터페이스로 갇혀 있던 스킬·파일·툴 세트가 하이퍼스케일러 두 곳에 동일한 시그니처로 얹히면서, 엔터프라이즈는 IAM은 클라우드에서 잠그고 모델 호출은 벤더 API로 나눠 쓰는 이중 계층이 실체가 된다.

> 💡 **왜 중요한가**: 이제 "Anthropic API를 쓴다"가 아니라 "Foundry의 Claude 티어를 쓴다"가 조달·감사·과금 단위가 된다 — LLM 벤더 락인의 축이 모델에서 툴 API로 옮겨간다.

### 2. Google Cloud, 'Open Knowledge Format(OKF)' 오픈 스펙 공개 — RAG의 지식 베이스가 드디어 이식 가능해졌다

Google Cloud가 LLM-wiki 패턴을 정형화한 벤더 중립 오픈 스펙 OKF를 공개했다. 메타데이터·컨텍스트·큐레이션된 지식을 사람과 에이전트가 동시에 읽을 수 있는 포맷으로 표준화하며, Vertex AI Search·Bedrock KB·Azure AI Search 간에 지식 베이스 원본을 그대로 옮길 수 있는 첫 스펙이다. 사실상 RAG 인덱스 계층의 OpenAPI를 노리는 움직임.

> 💡 **왜 중요한가**: 지금까지 RAG 프로젝트가 벤더 이관에 실패한 이유는 임베딩이 아니라 청킹 규칙과 메타데이터 스키마였다 — OKF는 그 재작성 비용을 0으로 만든다.

### 3. Meta 'Muse Glimmer' 오픈웨이트 공개 — 30B에 네이티브 MCP 지원, 소비자 GPU 한 장으로 에이전트가 돈다

Meta가 Apache 2.0으로 30B 파라미터 Muse Glimmer를 공개했다. 특별한 건 프로토콜 레벨의 MCP 네이티브 지원 — 어댑터 없이 파인튜닝 없이 MCP 서버를 툴로 직접 붙일 수 있고, 인터페이스 자동화용 비전 인코더가 기본 탑재됐다. 24GB VRAM 한 장이면 로컬에서 에이전트 루프가 완결된다는 뜻이다.

> 💡 **왜 중요한가**: "온프렘 에이전트"의 마지막 병목이었던 툴 파싱과 스크린 조작이 모델 안으로 흡수됐다 — 규제 산업의 로컬 에이전트 도입 문턱이 실질적으로 무너진다.
