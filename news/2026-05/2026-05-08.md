### 1. Coder Technologies, 'Coder Agents' 베타 공개 — 'Self-Hosted · 모델 불가지론' AI 코딩 에이전트 표준 도전 (5/6)

Coder가 컨트롤 플레인·오케스트레이션·실행을 모두 고객 인프라 안에서 돌리는 자가호스팅(Self-Hosted) AI 코딩 에이전트 베타를 공개했습니다. 클로드, GPT, Llama 등 어떤 모델이든 붙일 수 있는 **모델 불가지론(Model-Agnostic)** 구조로, 소스코드·프롬프트·모델 호출 흐름이 외부 벤더 클라우드로 전혀 빠져나가지 않는 점을 차별점으로 내세웠습니다. 엔지니어링 팀의 61%가 이미 에이전트를 운영하지만 거버넌스가 부족하다는 시장 지표를 정면으로 겨냥한 포지셔닝입니다.

> 💡 **왜 중요한가**: Cursor·Claude Code·Copilot 같은 SaaS 코딩 에이전트의 보안·컴플라이언스 한계가 명확해진 시점에, 금융·국방·규제 산업이 채택할 수 있는 'On-Prem 코딩 에이전트' 카테고리가 정식으로 열렸습니다.

### 2. AWS, 'Agent Toolkit for AWS' 공개 — 40+ Agent Skills · 관리형 MCP 서버 · 멀티 에이전트 호환

AWS가 코딩 에이전트가 AWS 위에서 'AWS답게' 빌드하도록 돕는 **Agent Toolkit for AWS**를 공식 공개했습니다. CloudFormation 작성·데이터 파이프라인·서버리스 등 40개 이상의 검증된 **Agent Skills**, 풀매니지드 **MCP 서버**, 그리고 AWS Core / Data Analytics / AWS Agents 3종 플러그인을 포함합니다. **Claude Code, Cursor, Codex, Kiro, Windsurf, Cline** 등 MCP 호환 에이전트라면 무엇이든 즉시 연결되며, IAM 가드레일·CloudTrail 감사·샌드박스 코드 실행이 기본 내장됐습니다.

> 💡 **왜 중요한가**: 'Bedrock Agent Registry'가 에이전트의 **레지스트리**였다면, Agent Toolkit은 외부 코딩 에이전트가 AWS 인프라를 다룰 때의 **공식 SDK·런북** 역할 — 즉 AWS가 자체 모델·자체 IDE 없이도 에이전틱 시대의 게이트웨이를 차지하려는 본격 전략입니다.

### 3. IREN ↔ NVIDIA, 5년 34억 달러 'AI 클라우드 서비스' 계약 + 최대 5GW · 21억 달러 지분 옵션 동시 체결 (5/7)

데이터센터 사업자 IREN이 NVIDIA와 **5년·34억 달러** 규모 매니지드 GPU 클라우드 서비스 계약을 체결했습니다. 텍사스 Childress 캠퍼스의 약 60MW에 공랭식 Blackwell 시스템이 우선 배치되며, 클러스터 오케스트레이션은 **Mirantis** 협업으로 제공됩니다. 더 의미심장한 건 부속 합의 — NVIDIA가 IREN 주식 3,000만 주를 5년간 주당 70달러에 매수할 수 있는 옵션(최대 **21억 달러** 투자)을 받았고, 양사는 **최대 5GW** AI 인프라 공동 구축에 합의했습니다.
