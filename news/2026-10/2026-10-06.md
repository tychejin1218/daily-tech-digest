### 1. GitHub Copilot CLI v1.0.92 공개 — HTTP+SSE MCP를 공식 폐기, Streamable HTTP로 '전환 데드라인'을 그었다
Copilot CLI가 1.0.92에서 `copilot config` 서브커맨드와 `Ctrl+E` 환경 선택기를 추가하면서, 동시에 과거의 HTTP+SSE MCP 연결 방식을 공식 deprecate 처리했다. MCP 전송 레이어가 'Streamable HTTP' 하나로 수렴하는 시점에 들어섰다는 신호다.

> 💡 **왜 중요한가**: 사내에서 Copilot용 MCP 서버를 운영 중이라면 HTTP+SSE 어댑터는 다음 분기 안에 걷어낼 로드맵이 지금 필요하다.

### 2. Reflection 'Beam' 501B 오픈웨이트 공개 — 코드 전문 추론 모델이 '엔터프라이즈 자가호스팅' 전선에 뛰어들었다
Reflection이 코드 추론에 특화된 501B 파라미터 오픈웨이트 모델 Beam을 공개했다. 상용 API 비용 없이 사내 GPU 클러스터에서 '엔터프라이즈급' 코딩 모델을 돌릴 수 있는 선택지가 또 하나 생긴 셈이다.

> 💡 **왜 중요한가**: 데이터 보안·레이턴시·토큰 비용 세 축이 걸린 백엔드 조직에게는 '프라이빗 코딩 에이전트' 레시피 한 장이 더 완성됐다.

### 3. Qwen Code v0.25.0 공개 — 로컬 워크스페이스 안에서 서브에이전트가 '서로 협업'한다
Qwen Code v0.25.0이 'local workspace intelligent agent collaboration'을 정식 기능으로 추가했다. 한 머신 안에서 여러 에이전트가 같은 워크스페이스를 공유하며 역할을 나눠 작업하는 패턴이 Qwen 생태계에서도 표준으로 올라섰다.

> 💡 **왜 중요한가**: 서브에이전트 병렬 실행이 Claude Code·Cline에 이어 Qwen까지 들어온 건, '멀티 에이전트 로컬 러너'가 CLI 코딩 도구의 공통 기능선으로 굳어졌다는 뜻이다.
