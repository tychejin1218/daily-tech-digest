### `String.formatted()`로 `String.format()`을 메서드 체이닝처럼 자연스럽게 쓰기 (Java 15 정식)

기존 `String.format("Hello %s, you are %d", name, age)`는 포맷 문자열이 앞에 오고 인자가 뒤에 붙어 가독성이 떨어졌다. Java 15부터 도입된 `"Hello %s, you are %d".formatted(name, age)` 인스턴스 메서드는 포맷 문자열이 주체가 되어 자연스럽게 읽히며, Text Blocks(`"""`)와 결합하면 SQL이나 JSON 템플릿을 훨씬 깔끔하게 조립할 수 있다.

```java
String sql = """
    SELECT * FROM users
    WHERE id = %d AND status = '%s'
    """.formatted(userId, "ACTIVE");
```

> 💡 **왜 중요한가**: 포맷 문자열이 문장의 주어가 되어 코드가 자연어처럼 읽히고, Text Blocks와의 궁합이 특히 뛰어나다.

### `Objects.requireNonNullElse()`로 null 대체값을 표준 API로 처리하기 (Java 9 정식)

`value != null ? value : defaultValue` 패턴이나 `Optional.ofNullable(value).orElse(defaultValue)`를 대체하는 간결한 표준 API다. `Objects.requireNonNullElse(value, defaultValue)`는 첫 인자가 null이면 두 번째 인자를 반환하며, `requireNonNullElseGet(value, supplier)` 변형은 기본값 생성 비용이 클 때 지연 평가로 처리한다.

```java
String displayName = Objects.requireNonNullElse(user.getNickname(), "익명");
List<String> tags = Objects.requireNonNullElseGet(config.getTags(), ArrayList::new);
```

> 💡 **왜 중요한가**: 삼항 연산자나 Optional 우회 없이 null 방어 로직을 한 줄로 표현할 수 있고, 지연 평가 변형까지 준비되어 있다.
