### 1. Google Antigravity, Gemini API '무료 하네스'로 강림 — 코딩 에이전트가 IDE를 벗어나 API 콜 한 방으로 소환된다
Google이 자사 Antigravity 코딩 에이전트를 `antigravity-preview-09-2026` 하네스로 감싸 Gemini API·AI Studio 위에 얹었다. Gemini 3.8 Flash 백엔드 기준 파일 변경 시 출력 토큰 40% 감소, 리서치·소프트웨어 엔지니어링 태스크 완료율 6% 상승, 장문 대화 캐시 히트율 16% 향상을 자체 벤치로 공개했으며, Files API·Credentials API가 하네스에 정식 편입됐다.

> 💡 **왜 중요한가**: IDE에 갇혀 있던 에이전트 하네스가 순수 API 자원으로 풀리면서, '커서·안티그래비티·클라인' 같은 GUI 계층 없이도 서버 사이드에서 자율 코딩 잡을 돌리는 게 첫 시민이 됐다.

### 2. Kubernetes v1.37 정식 릴리스 — 'Scale to Zero'·Checkpoint Restore가 스테이블로, LLM 워크로드가 K8s 안으로 들어왔다
Kubernetes v1.37이 9월 스테이블로 승격되면서 Scale to Zero, Checkpoint Restore, API Server Resilience 3종이 한꺼번에 GA를 받았다. 특히 Scale to Zero는 GPU 서빙 파드를 '요청 0일 때 완전 소멸' 상태로 두다가 트리거 시 컨테이너 스냅샷에서 복원하는 흐름을 그대로 지원해, KServe·Ray Serve·vLLM 스택이 별도 프록시 없이 콜드스타트를 관리할 수 있게 됐다.

> 💡 **왜 중요한가**: '서버리스 GPU 추론'을 위해 Knative·자체 오토스케일러를 얹어야 했던 K8s AI 서빙 아키텍처가, 코어 API만으로 완성되는 최소 구성으로 재편된다.

### 3. Qodo, 'Agentic Toolbox' 정식 공개 — Copilot·Codex·Claude Code가 짜준 코드를 '전용 QA 에이전트'가 게이트 처리한다
Qodo가 9월에 Agentic Toolbox를 공개하며 코딩 에이전트가 생성한 PR을 버그·품질·시큐리티·테스트 커버리지 4개 병렬 스페셜리스트 에이전트가 리뷰하는 A2A(agent-to-agent) 게이트 아키텍처를 상용화했다. 자체 벤치마크 기준 경쟁 도구 대비 F1 스코어 11% 상승, '휴먼 정의 정책' 기반의 A2A 거버넌스 룰을 CI에 훅으로 붙일 수 있게 됐다.

> 💡 **왜 중요한가**: '코드 쓰는 에이전트' 옆에 '코드 리뷰만 하는 에이전트'가 표준 계층으로 올라가면서, 스타트업에서 사라져 가던 코드 리뷰 문화가 봇 대 봇 구조로 재현된다.
