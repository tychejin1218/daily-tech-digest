### 1. Azure SQL Hyperscale Serverless, 'Auto-Pause' 퍼블릭 프리뷰 — 트래픽 없으면 컴퓨트가 0원으로 잠든다

Microsoft가 2026-10-01자 업데이트에서 Azure SQL Database Hyperscale Serverless의 auto-pause/auto-resume를 퍼블릭 프리뷰로 공개했다. 유휴 시간에 compute 청구가 완전히 멈추고 요청이 들어오면 알아서 깨어난다. 같은 발표에 SQL Server on Azure Local 'Disconnected'(ALDO) GA, Cosmos DB in Fabric Database Hub 프리뷰가 함께 묶였다.

```
[유휴 워크로드]
전통 Hyperscale:   █████████████████ (24시간 compute 과금)
Serverless+Pause:  █▁▁▁▁▁▁▁▁▁▁▁█▁▁▁ (요청 순간만 과금, 나머지 0)
                   ↑ auto-resume 콜드 스타트 수 초
```

> 💡 **왜 중요한가**: LLM 사이드카·에이전트 세션 저장소처럼 '스파이키한' AI 백엔드에서 Postgres/Neon serverless를 골랐던 이유(=idle=0)가 이제 엔터프라이즈 SQL 위에서도 성립한다 — DB 선택 기준이 '가격 곡선'에서 '스키마·툴체인'으로 되돌아간다.

### 2. Meta Muse for Small Business 공개 — 개인 에이전트가 Asana·Slack·Zoom·Salesforce의 '벽'을 넘었다

Meta가 자사 개인 에이전트 Muse를 소상공인용으로 확장하며, Asana·Zoom·Intuit·Box·Canva·Slack(Salesforce) 등 주요 SaaS와의 커넥터를 퍼스트파티로 붙였다. OpenAI도 같은 주 'Dots'를 내놓으며 "지시가 없어도 컨텍스트를 관찰하고 스스로 행동하는 상시(persistent) 에이전트" 카테고리에 진입, 개인 에이전트 시장이 프론티어 랩끼리의 직접 경쟁으로 바뀌었다.

```
기존 챗봇:      user prompt ──▶ LLM ──▶ answer  (단발성)
Muse/Dots:      ┌─ Asana/Slack/Zoom/CRM 관찰 (지속)
                ├─ 조건 트리거로 자율 행동
                └─ 세션 넘어서 컨텍스트 유지
```

> 💡 **왜 중요한가**: 백엔드 관점에서 '앱 UI'가 아니라 '앱 API'가 최종 소비자가 됐다는 신호다 — 사내 시스템은 이제 사람 대시보드가 아니라 에이전트가 크론처럼 두드리는 대상이 되고, rate limit·audit log·permission scope 설계가 전면에 온다.

### 3. Microsoft Fabric, Cosmos DB GA + PostgreSQL·SQL Server 미러링 — Ops DB와 분석 레이크가 한 개 계정으로 접힌다

SQLCon/FabCon Europe 2026(9/28) 발표를 이어받아 Cosmos DB in Microsoft Fabric과 Cosmos DB Mirroring이 정식 GA로 승격됐고, Azure Database for PostgreSQL·SQL Server 2016~2025 미러링도 함께 열렸다. 운영 DB의 변경이 별도 ETL 없이 Fabric OneLake로 스트리밍돼, Copilot·에이전트가 프로덕션 데이터에 곧바로 붙는다.

```
[Before] OLTP ──(CDC/ETL/Kafka)──▶ Warehouse ──▶ BI/AI
[After]  OLTP ──(Fabric Mirroring, near-real-time)──▶ OneLake ──▶ Copilot/Agents
                                     └─ 별도 파이프라인 0개
```

> 💡 **왜 중요한가**: "에이전트에게 실시간 프로덕션 데이터 붙이려면 Debezium+Kafka+dbt 스택 하나 만든다"가 관행이었는데, 하이퍼스케일러가 그걸 '체크박스 하나'로 흡수 중이다 — Databricks/Snowflake와 달리 DB 벤더가 직접 쥐고 있다는 게 락인 관점의 새 전선이다.
