### PostgreSQL 18 GA — 비동기 I/O·UUIDv7 네이티브 지원, OLTP 처리량 40% 향상

PostgreSQL 18이 정식 릴리스되며 io_uring 기반 비동기 I/O를 도입해 순차 스캔·비트맵 힙 스캔에서 대기 시간이 크게 감소했다. UUIDv7 생성 함수 `uuidv7()`가 코어에 내장되어 시계열 정렬 친화적 PK를 별도 확장 없이 사용할 수 있으며, Skip Scan 인덱스 최적화로 복합 인덱스 활용도가 넓어졌다.

```sql
-- UUIDv7 (시간 정렬 가능) PK 예시
CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT uuidv7(),
  created_at TIMESTAMPTZ DEFAULT now()
);
```

> 💡 **왜 중요한가**: PG 18의 UUIDv7 네이티브화는 분산 시스템에서 ULID/외부 라이브러리 의존성을 없애고 인덱스 단편화 문제를 해결한다.

### Deno 2.5, 'Deno Deploy Isolate Cloud' GA — 에지에서 상태 유지 워크로드 실행

Deno가 KV·Queue·Cron에 이어 장기 상태를 갖는 격리(Isolate) 실행 환경을 정식 공개했다. WebSocket 세션이 최대 24시간 유지되고 리전 간 자동 마이그레이션되어, 서버리스에서 어려웠던 WebRTC 시그널링·게임 세션·실시간 협업 서버를 단일 파일 배포로 구현할 수 있다. Node 호환 레이어도 v22 API까지 확장되었다.

> 💡 **왜 중요한가**: 서버리스의 콜드스타트·무상태 제약을 넘어선 '에지 스테이트풀' 컴퓨팅이 상용화 단계에 진입했다.

### Anthropic, MCP 스펙 1.0 확정 — OAuth 2.1·리소스 서명·에이전트 페더레이션 표준화

Model Context Protocol이 1.0으로 안정화되면서 툴 간 인증에 OAuth 2.1 DPoP 바인딩이 필수가 되고, 리소스 응답에 대한 서명 검증(JWS) 스펙이 확정됐다. 여러 MCP 서버를 라우터를 통해 페더레이션하는 'MCP Bridge' 프로파일이 함께 공개되어, 사내 툴 수십 개를 하나의 논리적 툴셋으로 노출할 수 있게 됐다.

> 💡 **왜 중요한가**: MCP 1.0 확정으로 툴 호출 파편화가 해소되고, 사내 에이전트를 감사·인증 요건 아래 운영할 표준 근거가 생겼다.
