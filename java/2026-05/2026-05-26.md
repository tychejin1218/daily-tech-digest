### `Files.writeString()`과 `Files.readString()`으로 텍스트 파일 I/O를 한 줄로 처리하기 (Java 11 정식)
기존에는 `BufferedWriter`나 `Files.write(Path, List<String>)`로 인코딩과 줄바꿈을 신경 쓰며 파일을 다뤄야 했지만, Java 11부터 `Files.writeString(path, content, StandardCharsets.UTF_8)`과 `Files.readString(path)` 한 줄로 전체 텍스트를 읽고 쓸 수 있습니다. 기본 인코딩이 UTF-8이라 플랫폼별 인코딩 차이로 깨지는 문제도 자연스럽게 사라집니다.

```java
Path path = Path.of("config.json");
Files.writeString(path, "{\"version\": 1}");
String content = Files.readString(path);
```

> 💡 **왜 중요한가**: 설정 파일·로그·캐시 같은 작은 텍스트 파일 처리에서 보일러플레이트와 인코딩 버그를 동시에 제거할 수 있습니다.

### `Thread.onSpinWait()`으로 짧은 busy-wait 루프의 CPU 효율을 힌트로 알리기 (Java 9 정식)
락 없는 알고리즘이나 짧은 대기 루프에서 `while (!ready) {}` 같은 spin loop는 CPU를 100% 점유하며 다른 하이퍼스레드의 자원까지 빼앗습니다. `Thread.onSpinWait()`을 루프 내부에 호출하면 JVM이 CPU의 `PAUSE` 명령어(x86) 같은 아키텍처별 힌트로 변환해 전력 소모를 줄이고 메모리 순서 위반(memory order violation) 비용을 낮춥니다.

```java
while (!flag.get()) {
    Thread.onSpinWait();
}
```

> 💡 **왜 중요한가**: 동기화 프리미티브를 만들거나 짧은 컨디션을 폴링할 때, 코드 변경 없이 단 한 줄로 CPU 친화적인 대기로 바꿀 수 있습니다.
