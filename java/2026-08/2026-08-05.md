### `Files.mismatch(Path, Path)`로 두 파일이 같은지 바이트 단위로 비교하기 (Java 12 정식)

두 파일의 내용이 동일한지 확인할 때 예전에는 스트림을 열어 바이트 배열을 읽고 `Arrays.equals()`로 비교하거나, MD5·SHA 해시를 계산해서 맞추는 코드를 직접 짜야 했다. `Files.mismatch(path1, path2)`는 첫 번째로 다른 바이트의 위치를 `long`으로 반환하며, 완전히 같으면 `-1L`을 반환한다. 파일 크기가 다르면 짧은 파일 길이를 반환하기 때문에 조기 종료 최적화가 내장되어 있어 대용량 파일 비교에도 안전하다.

> 💡 **왜 중요한가**: 파일 동등성 검사·백업 검증·캐시 무효화 판단을 표준 API 한 줄로 처리할 수 있고, 해시 충돌 걱정 없이 바이트 정확도를 보장한다.

### `Math.floorDiv(int, int)`와 `Math.floorMod(int, int)`로 음수 나눗셈의 함정 피하기 (Java 8 정식)

자바의 `/`와 `%` 연산자는 0으로 향해 반올림(truncated division)하기 때문에 `-7 / 2`는 `-3`, `-7 % 2`는 `-1`이 되어 음수를 다룰 때 배열 인덱스 계산이나 순환 큐 로직에서 미묘한 버그를 만든다. `Math.floorDiv(-7, 2)`는 `-4`, `Math.floorMod(-7, 2)`는 `1`을 반환해서 수학적 나머지(항상 0 이상)를 보장한다. 특히 요일 계산, 원형 버퍼 인덱싱, 좌표 변환처럼 음수 입력이 섞이는 곳에서 `((i % n) + n) % n` 같은 관용구를 대체할 수 있다.

> 💡 **왜 중요한가**: 조용히 잠복하는 부호 관련 오프바이원 버그를 표준 API로 원천 차단할 수 있고, 의도를 코드에 명시적으로 드러낼 수 있다.
