### `String.repeat(int)`로 문자열 반복을 표준 API 한 줄로 처리하기 (Java 11 정식)

구분선이나 들여쓰기용 문자열을 만들 때 `StringBuilder` 루프나 `String.join(Collections.nCopies(...))` 같은 우회로를 쓰지 않고, `"-".repeat(50)`처럼 한 줄로 표현할 수 있다. 내부적으로 `char[]`을 미리 할당해 채우기 때문에 수동 루프보다 빠르고, 음수 인자는 `IllegalArgumentException`을 던져 실수를 조기에 잡아준다.

```java
String divider = "=".repeat(60);
String indent = " ".repeat(depth * 2);
String header = "| %s |".formatted("title").repeat(3);
```

> 💡 **왜 중요한가**: 문자열 반복은 로그 포맷·CLI 출력·테스트 픽스처에서 자주 쓰는 연산인데, 표준 API 한 줄로 의도가 즉시 드러난다.

### `Stream.iterate(seed, hasNext, next)` 3-인자 버전으로 for 루프를 스트림으로 대체하기 (Java 9 정식)

기존 `Stream.iterate(seed, next)`는 무한 스트림이라 `limit()`이 필수였지만, Java 9부터 종료 조건 프리디케이트를 받는 3-인자 버전이 추가되어 `for (int i = 0; i < n; i += 2)` 같은 유한 반복을 그대로 스트림으로 표현할 수 있다. 조건이 처음부터 거짓이면 빈 스트림이 되고, 게으르게 평가되므로 큰 범위에도 안전하다.

```java
List<Integer> evens = Stream.iterate(0, i -> i < 20, i -> i + 2)
    .collect(Collectors.toList());

Stream.iterate(root, Objects::nonNull, TreeNode::parent)
    .forEach(node -> System.out.println(node.name()));
```

> 💡 **왜 중요한가**: 시작값·종료조건·증가식이라는 for 루프의 세 요소를 스트림 파이프라인에 자연스럽게 녹여, 명령형과 함수형 사이의 어색한 경계를 없앤다.
