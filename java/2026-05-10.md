### 1. `Stream.mapMulti()`로 `flatMap`보다 가볍게 1:N 변환 처리하기 (Java 16 정식)

`Stream.mapMulti(BiConsumer)`는 한 요소를 0개 이상의 결과로 펼치는 연산이지만, 내부적으로 매번 새로운 `Stream` 인스턴스를 생성하는 `flatMap`과 달리 호출자가 `Consumer`에 직접 결과를 넘기는 방식이라 임시 스트림 객체 할당이 사라진다. 변환 결과가 평균 0~수 개로 적거나 조건부로만 방출되는 경우, 또는 비제네릭 타입 분기를 한 곳에서 처리해야 할 때 유용하다.

```java
// flatMap: 요소마다 임시 Stream 생성
List<Integer> r1 = Stream.of(1, 2, 3, 4)
    .flatMap(n -> n % 2 == 0 ? Stream.of(n, n * 10) : Stream.empty())
    .toList(); // [2, 20, 4, 40]

// mapMulti: Stream 객체 할당 없이 직접 downstream으로 push
List<Integer> r2 = Stream.of(1, 2, 3, 4)
    .<Integer>mapMulti((n, downstream) -> {
        if (n % 2 == 0) {
            downstream.accept(n);
            downstream.accept(n * 10);
        }
    })
    .toList(); // [2, 20, 4, 40]

// 타입 분기에도 강점: instanceof 패턴과 결합
Stream.of(1, "a", 2.5, "b", 3)
    .<String>mapMulti((obj, ds) -> {
        if (obj instanceof String s) ds.accept(s.toUpperCase());
    })
    .toList(); // [A, B]
```

> 💡 **왜 중요한가**: 0~수 개로 펼치는 핫패스에서 `flatMap`의 스트림 생성 오버헤드를 제거해 GC 압력과 지연을 줄이고, 조건부 방출 로직을 직관적인 명령형 스타일로 표현할 수 있다.

### 2. 언더스코어(`_`) Unnamed Variables로 의도적으로 무시할 값을 명시하기 (Java 22 정식)

Java 22부터 `_`는 "사용하지 않을 변수"를 가리키는 정식 식별자가 되어, try-with-resources의 미사용 리소스, catch의 사용 안 하는 예외 변수, 람다 파라미터, 그리고 `record` 디컨스트럭션 패턴에서 관심 없는 컴포넌트를 한 글자로 명시할 수 있다. 컴파일러는 `_`로 표기된 변수의 읽기를 금지하므로, 실수로 참조하는 버그를 차단하면서도 "의도적으로 버린 값"이라는 신호를 코드 리뷰어에게 명확히 전달한다.

```java
// 1) catch 절: 예외 객체를 사용하지 않을 때
try {
    return Integer.parseInt(input);
} catch (NumberFormatException _) {
    return 0;
}

// 2) 람다: 두 번째 인자만 필요
map.forEach((_, value) -> System.out.println(value));

// 3) record 디컨스트럭션 패턴 (Java 21+)
record Point(int x, int y) {}
if (obj instanceof Point(int x, _)) {
    System.out.println("x = " + x); // y는 관심 없음
}

// 4) try-with-resources: lock 획득만 필요하고 변수는 안 씀
try (var _ = lock.acquire()) {
    doWork();
}

// 5) 같은 스코프에서 여러 번 _ 사용 가능 (shadowing 아님)
for (var _ : items) counter++;
```

> 💡 **왜 중요한가**: "의도하지 않은 미사용"과 "의도적인 무시"가 시각적으로 분리되어 IDE의 미사용 경고를 깨끗하게 유지하면서, 패턴 매칭과 람다에서 신경 쓸 값만 남기는 노이즈 제거 효과를 얻는다.
