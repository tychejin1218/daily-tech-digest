### 1. `Pattern.asMatchPredicate()` (Java 11 정식)로 Stream 필터링에서 매 요소마다 `pattern.matcher(s).matches()` 호출하는 관성 벗어나기

`list.stream().filter(s -> Pattern.compile(regex).matcher(s).matches())` 패턴은 매 요소마다 `Matcher` 객체를 새로 만든다. `Pattern.compile(regex).asMatchPredicate()`로 `Predicate<String>`을 한 번만 만들어 두면 내부적으로 `ThreadLocal` 캐시된 Matcher를 재사용해서 할당 비용이 사라진다. 비슷하게 `asPredicate()`는 `find()` 기준으로, `asMatchPredicate()`는 `matches()` 기준으로 동작하니 용도에 맞춰 골라야 한다.

```java
// 관성: 매 요소마다 Pattern.compile + Matcher 생성
List<String> emails = raw.stream()
    .filter(s -> Pattern.compile("^[\\w.]+@[\\w.]+$").matcher(s).matches())
    .toList();

// 개선: Pattern은 한 번, Predicate로 재사용
private static final Predicate<String> IS_EMAIL =
    Pattern.compile("^[\\w.]+@[\\w.]+$").asMatchPredicate();

List<String> emails = raw.stream().filter(IS_EMAIL).toList();
```

> 💡 **왜 중요한가**: 정규식은 컴파일 비용이 비싸고, Stream 파이프라인 안에서 람다로 숨어들면 매 요소 호출마다 `Pattern.compile`이 반복되는 걸 리뷰에서조차 놓치기 쉽다 — `asMatchPredicate()`는 "한 번 컴파일, 재사용"을 타입 시스템 수준에서 강제한다.

### 2. `List.copyOf(coll)` (Java 10 정식)로 방어적 복사할 때 `Collections.unmodifiableList(new ArrayList<>(src))` 이중 래핑 관성 벗어나기

생성자/게터에서 외부 가변성 차단하려고 `Collections.unmodifiableList(new ArrayList<>(src))`를 쓰는 경우가 많은데, 이건 ArrayList 복사 + unmodifiable 래퍼 2개 객체를 만든다. `List.copyOf(src)`는 결과 리스트가 이미 불변 구현체이면 복사 자체를 생략하고 그대로 리턴하고, 아니면 내부 불변 배열 하나로 복사해 래퍼 없이 끝낸다. `Set.copyOf`, `Map.copyOf`도 동일 전략이다.

```java
// 관성: ArrayList + unmodifiable 래퍼 두 겹
public Order(List<Item> items) {
    this.items = Collections.unmodifiableList(new ArrayList<>(items));
}

// 개선: 이미 불변이면 복사도 생략, 아니면 단일 불변 복사본
public Order(List<Item> items) {
    this.items = List.copyOf(items);  // null 포함 시 NPE — 입력 검증 효과도 있음
}
```

주의: `List.copyOf`는 `null` 요소가 있으면 `NullPointerException`을 던지고, 결과는 완전 불변이라 `.sort()` 같은 변경 연산도 UnsupportedOperationException으로 막힌다 — 이게 보통 원하는 동작이지만, 내부에서 정렬·수정이 필요한 경로에서는 `new ArrayList<>(src)`가 맞다.

> 💡 **왜 중요한가**: "불변 리스트 돌려주기"는 DDD 엔티티 게터, record 보상 생성자, API 응답 DTO에서 매일 쓰는 패턴이다 — `List.copyOf`는 할당 하나를 줄이면서 "null 혼입은 생성 시점에서 터뜨린다"는 fail-fast 효과까지 공짜로 얹어준다.
