### `Predicate.not()`으로 람다 부정을 자연스럽게 표현하기 (Java 11 정식)
`stream.filter(s -> !s.isBlank())` 처럼 메서드 참조 앞에 `!`를 붙일 수 없어 람다로 풀어 써야 했던 부분을, `Predicate.not(String::isBlank)`로 메서드 참조를 그대로 유지하면서 부정할 수 있습니다. 정적 임포트하면 `filter(not(String::isBlank))`처럼 읽기 좋은 영어 문장에 가까워져 의도가 분명해집니다.

```java
import static java.util.function.Predicate.not;

List<String> nonEmpty = lines.stream()
    .filter(not(String::isBlank))
    .toList();
```

> 💡 **왜 중요한가**: 메서드 참조의 가독성을 포기하지 않고도 부정 조건을 표현할 수 있어, 스트림 필터가 자연어처럼 읽힙니다.

### `Stream.mapMulti()`로 `flatMap`보다 가볍게 1:N 변환 처리하기 (Java 16 정식)
`flatMap`은 원소마다 새 `Stream` 객체를 만들어야 하지만, `mapMulti`는 `Consumer`(downstream)에 결과를 직접 푸시하는 방식이라 0개·1개·소수 원소를 방출하는 케이스에서 중간 스트림 할당 비용이 사라집니다. 특히 조건부로 0개 또는 1개를 내보내는 패턴(`filter` + `map`을 합친 형태)이나 타입 캐스팅을 곁들인 분기에 잘 맞습니다.

```java
List<String> upperNames = people.stream()
    .<String>mapMulti((p, downstream) -> {
        if (p.age() >= 18) downstream.accept(p.name().toUpperCase());
    })
    .toList();
```

> 💡 **왜 중요한가**: "걸러내며 변환"하는 흔한 패턴을 한 단계에서 끝낼 수 있어 코드가 짧아지고, 짧은 시퀀스를 다룰 때 `flatMap`보다 GC 부담이 적습니다.
