### 1. `Pattern.asMatchPredicate()`로 정규식을 스트림 필터에 그대로 꽂아 넣기 (Java 11 정식)

정규식으로 문자열을 걸러낼 때 `stream.filter(s -> pattern.matcher(s).matches())` 같은 람다를 매번 쓰는 대신, `Pattern.compile("...").asMatchPredicate()`로 `Predicate<String>`을 직접 얻어 `filter`에 그대로 넘길 수 있다. `asPredicate()`(부분 매치)와 `asMatchPredicate()`(전체 매치)가 구분되어 있어 의도를 명시적으로 드러낼 수 있고, `Pattern` 인스턴스는 재사용되므로 컴파일 오버헤드도 한 번뿐이다.

```java
Predicate<String> isEmail = Pattern
    .compile("^[\\w.+-]+@[\\w.-]+\\.[A-Za-z]{2,}$")
    .asMatchPredicate();

List<String> emails = inputs.stream()
    .filter(isEmail)
    .toList();
```

> 💡 **왜 중요한가**: 정규식 필터링 코드에서 람다 보일러플레이트를 제거하고 "부분 매치인지 전체 매치인지"를 API 이름으로 강제해 실수를 원천 차단한다.

### 2. `Map.Entry.copyOf(Entry)`로 뷰 기반 Entry를 안전한 스냅샷으로 고정하기 (Java 17 정식)

`Map.entrySet()`에서 얻은 `Entry`는 원본 맵을 참조하는 뷰라, 맵이 수정되거나 iterator가 진행되면 값이 바뀌거나 `IllegalStateException`이 터질 수 있다. Java 17부터는 `Map.Entry.copyOf(entry)`로 불변이면서 원본과 완전히 분리된 스냅샷 Entry를 한 줄에 만들 수 있어, `entrySet().stream().map(Map.Entry::copyOf).toList()` 패턴으로 나중에 순회하거나 다른 스레드에 넘겨도 안전하다.

```java
List<Map.Entry<String, Integer>> snapshot = scores.entrySet().stream()
    .map(Map.Entry::copyOf)
    .toList();

scores.clear();
snapshot.forEach(e -> System.out.println(e.getKey() + "=" + e.getValue()));
```

> 💡 **왜 중요한가**: HashMap iterator의 재사용 Entry나 ConcurrentModificationException 함정을, 새 `AbstractMap.SimpleImmutableEntry`를 손으로 만들지 않고 표준 API 한 줄로 없앤다.
