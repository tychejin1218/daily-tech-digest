### MongoDB, '에이전트 운영용 통합 데이터 플랫폼' 공개 — 실시간 DB·벡터검색·메모리·임베딩·리랭커를 단일 백엔드로 (MongoDB.local London, 5/7)
MongoDB가 그간 별도로 조립해야 했던 실시간 데이터베이스, 풀텍스트·벡터 검색, 에이전트 메모리, Voyage AI 자동 임베딩, 리랭커 모델을 단일 백엔드로 합친 '프로덕션 에이전트용 통합 AI 데이터 플랫폼'을 발표했습니다. 함께 공개된 MongoDB 8.3은 코드 변경 없이 읽기 45%·쓰기 35% 향상을 제공하며, LangGraph.js Long-Term Memory Store가 Atlas 기반으로 GA되어 JS/TS 에이전트의 대화 간 영구 메모리를 제공합니다.

> 💡 **왜 중요한가**: 에이전트 백엔드를 만들기 위해 'DB + 벡터DB + 임베딩 파이프라인 + 메모리 스토어'를 따로 운영하던 구조가 단일 플랫폼으로 흡수되어, OLTP 데이터베이스가 곧 에이전트 런타임의 상태 저장소가 되는 흐름이 가속됩니다.

### Honeycomb, '에이전트 네이티브 옵저버빌리티' 공개 — Agent Timeline · Canvas Agent · Canvas Skills로 프로덕션 에이전트 가시화 (5/12)
Honeycomb이 멀티 에이전트 워크플로우를 단일 타임라인으로 보여주는 Agent Timeline, 채팅·자율 에이전트 겸용으로 재설계된 Canvas Workspace, 그리고 디버깅 플레이북을 재사용 가능한 형태로 저장하는 Canvas Skills를 공개했습니다. Skills는 엔지니어가 한 번 가르친 조사 절차를 에이전트가 자율적으로 실행해, 동일 이슈가 재발할 때 긴 프롬프트 없이 자동 분석을 수행합니다.

> 💡 **왜 중요한가**: '에이전트가 무엇을 했는지'를 사후에 추적하는 것을 넘어 '운영팀의 SRE 노하우를 에이전트에 내장해 자동 트리아지'까지 옵저버빌리티의 책임 범위가 확장되면서, AIOps의 표준 인터페이스가 트레이스에서 Skills 라이브러리로 옮겨가고 있습니다.

### ServiceNow Build Agent GA — Cursor·Windsurf·Claude Code·Copilot에 거버넌스 채로 임베드 (Knowledge 2026)
ServiceNow가 Build Agent를 ServiceNow Studio에서 GA하면서, 그 핵심 스킬을 Cursor·Windsurf·Claude Code·GitHub Copilot 안에서도 호출 가능하도록 확장했습니다. AI 코딩 도구에서 만들어진 코드가 App Engine Management Center로 자동 등록·검사되어, 거버넌스를 거치지 않은 '섀도우 앱'이 늘어나는 문제를 도구를 바꾸지 않고 차단하도록 설계되었습니다.

> 💡 **왜 중요한가**: 엔터프라이즈가 '코딩 에이전트를 어떻게 통제할 것인가'를 풀기 위해 IDE를 표준화하는 대신 SaaS 거버넌스 레이어를 모든 코딩 도구에 주입하는 모델이 등장해, 향후 컴플라이언스 정책은 IDE가 아니라 에이전트 콘트롤 평면에서 강제됩니다.
