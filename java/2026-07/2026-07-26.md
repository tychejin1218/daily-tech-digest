### Switch Expressions와 `yield`로 값을 반환하는 switch를 표현식처럼 쓰기 (Java 14 정식)

`switch`를 문(statement)이 아닌 표현식(expression)으로 쓰면 `break` 없이 `->`로 케이스마다 값을 돌려주고, 여러 줄 블록이 필요하면 `yield`로 결과를 지정한다. 임시 변수와 `default: throw` 상용구를 없애 컴파일러가 완전성(exhaustiveness) 검사까지 강제한다.

```java
int days = switch (month) {
    case FEB -> year.isLeap() ? 29 : 28;
    case APR, JUN, SEP, NOV -> 30;
    case JAN, MAR, MAY, JUL, AUG, OCT, DEC -> {
        log.debug("31일 달: {}", month);
        yield 31;
    }
};
```

> 💡 **왜 중요한가**: 값 반환용 `switch`에서 임시 변수 선언과 fall-through 버그를 원천 차단해 로직을 한눈에 파악할 수 있다.

### `LocalDate.datesUntil()`로 날짜 범위를 스트림으로 순회하기 (Java 9 정식)

두 날짜 사이를 반복하려고 `while (!date.isAfter(end)) { ... date = date.plusDays(1); }`을 매번 쓰지 말고, `start.datesUntil(end)`로 하루 단위(또는 `Period` 지정) 스트림을 바로 얻어 필터·매핑에 그대로 연결한다. 끝 날짜는 배타적(exclusive)이므로 `end.plusDays(1)`로 조정하거나 그대로 두면 된다.

```java
LocalDate start = LocalDate.of(2026, 7, 1);
LocalDate end = LocalDate.of(2026, 8, 1);

List<LocalDate> weekdays = start.datesUntil(end)
    .filter(d -> d.getDayOfWeek().getValue() < 6)
    .toList();

// Period 지정으로 격주 순회
start.datesUntil(end, Period.ofDays(14)).forEach(System.out::println);
```

> 💡 **왜 중요한가**: 날짜 반복 상용구를 없애 영업일 계산·리포트 기간 집계 같은 로직을 스트림 파이프라인 한 줄로 표현할 수 있다.
