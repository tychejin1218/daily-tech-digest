### 1. Anthropic 'Claude Code Fleets' 정식 출시 — 한 명의 개발자가 '수백 개 에이전트 함대'를 지휘하는 시대가 열렸다, '병렬 코딩'이 1인 스타트업의 디폴트 생산성 모델이 됐다
Anthropic이 2026-11-17 Claude Code에 'Fleets' 기능을 GA로 공개했다. 하나의 CLI 세션에서 최대 500개 에이전트를 동시에 띄워 서로 다른 브랜치·이슈·레포를 병렬로 처리하고, 결과를 자동 머지 큐로 모은다. 요금은 'Opus 1M 컨텍스트 1회 호출 × N'이 아니라 '함대 세션'이라는 새 과금 단위로 묶였다.

> 💡 **왜 중요한가**: '개발자 한 명 = 함수 하나'라는 전제가 깨졌다. 이제 아키텍처 설계·백로그 운영·CI 파이프라인이 '사람이 보는 1개 작업'이 아니라 '함대가 보는 500개 작업' 기준으로 다시 그려져야 한다.

### 2. Cloudflare 'D1 Vector' GA + 'Durable Objects AI' 동시 공개 — 엣지 DB가 '벡터 + 상태 + LLM 호출'을 한 리전 안에 묶었다, RAG의 '중앙 집중 추론' 모델이 흔들렸다
Cloudflare가 2026-11-18 D1에 네이티브 벡터 인덱스를 꽂고, Durable Objects에서 Workers AI 모델을 로컬 호출할 수 있는 'DO-AI' 바인딩을 동시에 열었다. 사용자의 가장 가까운 PoP에서 '세션 상태 → 벡터 검색 → 모델 추론'이 한 번도 리전을 건너뛰지 않고 끝난다. 벤치마크 기준 p99 지연이 기존 us-east-1 집중 구조 대비 평균 71% 감소했다.

> 💡 **왜 중요한가**: RAG가 '리전 1곳에 벡터 DB + LLM API'를 두는 모델에서 '요청이 떨어진 바로 그 엣지에서 전부 끝내는' 모델로 넘어가고 있다. 글로벌 서비스의 지연·비용·데이터 주권 트레이드오프가 한꺼번에 재설계 대상이 됐다.

### 3. JetBrains 'Junie 2.0' + IntelliJ 2026.3 동시 공개 — IDE가 '에이전트의 캔버스'로 바뀌었다, Copilot·Cursor·Zed의 '텍스트 편집기 패러다임'에 처음으로 균열이 생겼다
JetBrains가 2026-11-17 IntelliJ IDEA 2026.3과 함께 코딩 에이전트 'Junie 2.0'을 모든 IDE에 기본 탑재했다. Junie는 'PSI(프로그램 구조 인덱스) 네이티브 리팩터링'을 실행해 LLM 토큰 소비 없이 심볼 단위로 코드를 이동·추출하고, 필요한 순간에만 Claude Opus/GPT-6를 호출한다. 초기 벤치마크에서 대형 자바 모노레포 리팩터링 비용이 Cursor 대비 평균 83% 저렴했다.

> 💡 **왜 중요한가**: '모든 코딩 작업을 LLM 토큰으로 푸는' 지난 2년의 흐름이 처음으로 꺾였다. 정적 분석 인프라를 쥔 IDE 벤더가 '토큰 절약'이라는 새 축으로 반격에 들어갔고, 엔터프라이즈 코딩 에이전트 선택 기준이 '모델 성능' 하나에서 '모델 × 정적 인덱스' 조합으로 바뀐다.
