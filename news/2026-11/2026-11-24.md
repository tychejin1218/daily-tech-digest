### 1. Vercel 'AI SDK 6.0' + 'Fluid Compute Agent Mode' 동시 GA — 프론트엔드 프레임워크가 '에이전트 런타임'을 삼켰다, Next.js 한 프로젝트 안에서 UI·API·에이전트 루프가 '같은 배포 단위'로 묶인다

Vercel이 AI SDK 6.0과 함께 Fluid Compute의 'Agent Mode'를 정식 공개했다. `streamUI`가 React Server Component를 1급 출력으로 받아들이고, 에이전트 루프가 30분 장기 실행 + 중간 상태를 Durable Checkpoint에 자동 저장한다. `useAgent` 훅 하나로 프런트엔드가 서버 에이전트의 사고 흐름을 실시간으로 받아 렌더링하는 'Generative UI' 패턴이 디폴트가 됐다.

> 💡 **왜 중요한가**: '백엔드 에이전트 서버 + 프론트엔드 앱'이라는 2-티어 구조가 무너지고, 프레임워크 레벨에서 '에이전트 = 컴포넌트'라는 새 추상화가 자리 잡기 시작했다.

### 2. Replit 'Agent 3' + 'Autoscale Deployments Agent Mode' 공개 — 브라우저 탭 하나가 '기획→코드→DB→결제 연동→프로덕션 배포'를 자율 수행하는 디폴트 워크플로우가 됐다

Replit이 Agent 3를 공개하면서, 자연어 요구사항 한 줄로 PostgreSQL 스키마·Stripe 웹훅·OAuth·CI 파이프라인까지 자동 구성하는 'End-to-End 빌드'를 선보였다. 기존 Agent 2 대비 Playwright 기반 자기 테스트 루프를 내장해, 배포 후 실제 브라우저에서 유저 플로우를 돌려보고 실패 시 자율 롤백한다. Hobbyist 요금제에서도 월 150분 Agent 크레딧이 제공돼 1인 개발자의 '풀스택 외주' 수요를 정면으로 겨눴다.

> 💡 **왜 중요한가**: '바이브 코딩'이 MVP 단계를 넘어 '결제·인증·관측이 붙은 실서비스'까지 자율로 밀어내면서, 소규모 외주 시장과 노코드 플랫폼의 경계가 동시에 녹아내리기 시작했다.

### 3. Google 'Gemini 3.0 Pro' + 'Vertex AI Agent Engine 2.0' 동시 GA — '1M 토큰 멀티모달 컨텍스트'가 코드·아키텍처 다이어그램·로그 그래프를 한 호출에 집어넣는다, 엔터프라이즈 에이전트의 '관측-추론 루프'가 매니지드가 됐다

Google Cloud가 Gemini 3.0 Pro를 Vertex AI에 올리면서 Agent Engine 2.0을 GA로 전환했다. SRE 시나리오에서 Grafana 대시보드 스크린샷·Cloud Logging 쿼리 결과·Terraform 소스를 한 번에 넣고 "어제 03:42 레이턴시 스파이크 원인"을 추론하는 데모가 대표 유스케이스로 제시됐다. Agent Engine 2.0은 Spanner를 상태 저장소로 받아 멀티 리전 에이전트 세션을 투명하게 복제하며, 과금은 '사고 토큰 + 액션 호출' 분리 모델로 바뀌었다.

> 💡 **왜 중요한가**: 엔터프라이즈 에이전트의 '진짜 병목'이 모델 성능이 아니라 '관측 스택과의 연결'이었음이 공식화됐고, Datadog·New Relic 같은 APM 벤더가 'Gemini-Native 통합'을 CTO 레벨에서 재검토하기 시작했다.
