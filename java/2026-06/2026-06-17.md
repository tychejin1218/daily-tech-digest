### `Optional.stream()`으로 `Optional` 컬렉션을 깔끔하게 펼치기 (Java 9 정식)
`Optional<T>`를 0개 또는 1개 요소의 `Stream<T>`로 변환해주는 메서드로, `Stream<Optional<T>>`를 `flatMap(Optional::stream)`에 통과시키면 `isPresent()` 체크와 `get()` 호출 없이 빈 값이 자연스럽게 제거됩니다. `filter(Optional::isPresent).map(Optional::get)` 패턴을 한 줄로 대체할 수 있어 가독성이 크게 향상됩니다.

```java
List<User> users = userIds.stream()
    .map(repository::findById)   // Stream<Optional<User>>
    .flatMap(Optional::stream)   // Stream<User> — 빈 Optional은 자동 제외
    .toList();
```

> 💡 **왜 중요한가**: Optional과 Stream API의 경계에서 발생하는 가장 흔한 보일러플레이트를 제거해 함수형 파이프라인을 자연스럽게 이어줍니다.

### Text Blocks(`"""`)로 멀티라인 문자열을 들여쓰기 걱정 없이 작성하기 (Java 15 정식)
삼중 따옴표(`"""`)로 감싼 텍스트 블록은 줄바꿈 이스케이프(`\n`)와 따옴표 이스케이프(`\"`)를 제거하고, 컴파일러가 가장 왼쪽 라인을 기준으로 공통 들여쓰기를 자동으로 벗겨내(incidental whitespace) 실제 들여쓰기와 코드 들여쓰기를 분리합니다. JSON, SQL, HTML 같은 임베디드 문자열을 작성할 때 특히 강력합니다.

```java
String json = """
        {
          "user": "%s",
          "role": "admin"
        }
        """.formatted(name);
```

> 💡 **왜 중요한가**: 코드에 박힌 SQL/JSON/HTML 가독성을 비약적으로 끌어올리면서 들여쓰기 실수로 인한 미묘한 버그(불필요한 선행 공백)도 컴파일러가 알아서 처리해줍니다.
