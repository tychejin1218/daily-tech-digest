### `Records`로 불변 데이터 클래스를 한 줄로 선언하기 (Java 16 정식)
DTO나 값 객체를 만들 때마다 반복해서 작성하던 생성자, 접근자, `equals()`, `hashCode()`, `toString()`을 컴파일러가 자동으로 생성해줍니다. `record Point(int x, int y) {}` 한 줄이면 완전한 불변 클래스가 완성되며, 필요하면 컴팩트 생성자로 유효성 검증을 추가할 수 있습니다.

```java
public record Point(int x, int y) {
    public Point {
        if (x < 0 || y < 0) throw new IllegalArgumentException();
    }
}

Point p = new Point(3, 5);
System.out.println(p.x());        // 3
System.out.println(p);            // Point[x=3, y=5]
```

> 💡 **왜 중요한가**: Lombok 같은 외부 라이브러리 없이도 값 객체를 안전하고 간결하게 표현할 수 있어 도메인 모델링의 상용구를 획기적으로 줄여줍니다.

### `Stream.gatherers()`로 스트림에 커스텀 중간 연산 정의하기 (Java 24 정식)
`map`, `filter`, `flatMap`만으로 표현하기 어려웠던 상태 기반 스트림 변환(슬라이딩 윈도우, 중복 제거, 스캔 등)을 표준 API로 만들 수 있습니다. `Gatherers.windowFixed()`, `Gatherers.scan()` 같은 내장 gatherer를 바로 쓰거나, `Gatherer.of()`로 직접 정의해 재사용할 수 있습니다.

```java
List<List<Integer>> windows = Stream.of(1, 2, 3, 4, 5, 6, 7)
    .gather(Gatherers.windowFixed(3))
    .toList();
// [[1, 2, 3], [4, 5, 6], [7]]

List<Integer> cumulative = Stream.of(1, 2, 3, 4)
    .gather(Gatherers.scan(() -> 0, Integer::sum))
    .toList();
// [1, 3, 6, 10]
```

> 💡 **왜 중요한가**: 그동안 `collect()`를 우회하거나 외부 라이브러리(Guava, StreamEx)에 의존해야 했던 복잡한 스트림 처리를 표준 문법으로 자연스럽게 표현할 수 있게 되었습니다.
