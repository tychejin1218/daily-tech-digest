### `Pattern.asMatchPredicate()`로 정규식을 `Predicate<String>`로 바로 변환하기 (Java 11 정식)

컴파일된 `Pattern`을 스트림 필터에 넘길 때 매번 `s -> pattern.matcher(s).matches()` 람다를 쓸 필요 없이 `asMatchPredicate()` 한 번으로 재사용 가능한 술어를 얻는다. `asPredicate()`는 부분 일치, `asMatchPredicate()`는 전체 일치라는 차이도 명확하다.

```java
Pattern email = Pattern.compile("[\\w.+-]+@[\\w.-]+");
Predicate<String> isEmail = email.asMatchPredicate();

List<String> emails = inputs.stream()
    .filter(isEmail)
    .toList();
```

> 💡 **왜 중요한가**: 정규식 사용 코드에서 반복되는 람다 보일러플레이트를 줄이고 부분/전체 일치 의도를 API 이름으로 드러낸다.

### `Collectors.teeing()`으로 스트림 한 번에 두 집계 결과를 합치기 (Java 12 정식)

평균과 최대, 합계와 개수처럼 같은 스트림을 두 방식으로 집계해 하나의 결과 객체로 합쳐야 할 때 스트림을 두 번 순회하거나 임시 변수를 쓰지 않고 `teeing()`으로 한 번에 처리할 수 있다. 두 downstream `Collector`의 결과를 `BiFunction`으로 병합해 반환한다.

```java
record Stats(long count, double average) {}

Stats stats = orders.stream().collect(Collectors.teeing(
    Collectors.counting(),
    Collectors.averagingDouble(Order::amount),
    Stats::new
));
```

> 💡 **왜 중요한가**: 두 번 순회하거나 가변 상태를 만들지 않고 단일 파이프라인에서 복합 집계를 안전하게 얻을 수 있다.
