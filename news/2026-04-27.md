# 백엔드/서버/클라우드/AI 최신 IT 뉴스 (2026-04-27)

### 1. Cloudflare Sandboxes·Containers 정식 GA — AI 에이전트에게 '진짜 컴퓨터' 한 대씩 (Agents Week 2026)

Cloudflare가 Agents Week 2026에서 Sandboxes와 Containers를 정식 GA로 발표하며, AI 에이전트가 사용할 수 있는 영속(persistent) 격리 리눅스 환경을 글로벌 엣지에서 온디맨드로 제공하기 시작했습니다. egress 프록시 기반 시크릿 주입, PTY 터미널, 파일시스템 워처, 스냅샷 기반 세션 복원이 추가되어 `git clone + npm install` 부팅이 30초 → 스냅샷 복구 시 2초로 단축되며, Figma Make가 이미 프로덕션 워크로드를 올려 운영 중입니다. 과금은 Active CPU(실제 사용 사이클) 기반으로 가벼운 V8 isolate 기반 Dynamic Workers와 함께 두 계층(2-tier) 에이전트 런타임을 구성합니다.

> 💡 **왜 중요한가**: 호스티드 에이전트 런타임 경쟁에서 엣지 분산 + 영속 컨테이너 + 사용량 과금이 기본 SLA로 자리 잡으면서, 자체 샌드박스를 굴려야 했던 에이전트 빌더들의 인프라 비용 곡선이 한 단계 내려갑니다.

---

### 2. Cursor 3 출시 — 'Agents Window'와 자체 모델 Composer 2로 IDE를 에이전트 오케스트레이터로 재설계

Cursor가 4월 초 Cursor 3를 출시하며 기존 Composer 사이드바를 들어내고 풀스크린 'Agents Window'를 중심으로 IDE를 다시 짰습니다. 로컬·git worktree·클라우드·원격 SSH에 걸쳐 다중 에이전트를 병렬로 띄우고 모니터링하며, 모바일·웹·Slack·GitHub·Linear에서 트리거한 에이전트도 한 사이드바에 모입니다. 함께 공개된 자체 프런티어 코딩 모델 Composer 2는 200+ tok/s로 동작하고, 새 Design Mode는 브라우저 UI 요소를 클릭·주석으로 가리켜 에이전트에 시각적 피드백을 주는 방식까지 지원합니다.

> 💡 **왜 중요한가**: AI 코딩 도구의 UX 패러다임이 '한 명의 페어 프로그래머'에서 '여러 에이전트의 워크 매니저'로 넘어가고 있다는 가장 명확한 시그널이며, IDE 공급자가 직접 코딩 전용 frontier 모델을 운영하는 수직통합 흐름을 가속합니다.

### 3. Microsoft, 자체 'MAI' 모델 3종을 Foundry에 투입 — 음성·이미지 분야에서 OpenAI·Google과 정면 경쟁

Microsoft가 4월 초 Foundry Labs를 통해 자체 개발 MAI 모델 3종을 일반 공개했습니다. **MAI-Transcribe-1**은 25개 언어 평균 WER 3.9%(FLEURS)로 Azure Fast 대비 배치 속도 2.5배·GPU 비용 약 50%↓($0.36/시간), **MAI-Voice-1**은 단일 GPU에서 1초 미만에 60초 분량 음성 생성($22/100만 자), **MAI-Image-2**는 Arena.ai 리더보드 톱3로 Copilot 이미지 파이프라인을 갈아치웁니다. 분배자(distributor)가 아닌 모델 개발자로서 OpenAI·Google 라인업과 직접 경쟁 구도를 만든 첫 번째 구체적 증거로 평가됩니다.

> 💡 **왜 중요한가**: 클라우드 사업자가 OEM 모델에만 의존하던 시대가 끝나고, '하이퍼스케일러 자체 모델 + OpenAI 모델 병용'이 LLM API 조달 표준이 되면서 멀티모달(STT/TTS/이미지) 비용 구조가 빠르게 재편됩니다.
