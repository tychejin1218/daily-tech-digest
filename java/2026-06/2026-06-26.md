### `HexFormat`으로 바이트 배열과 16진수 문자열을 안전하게 변환하기 (Java 17 정식)

기존에는 `String.format("%02x", b)`를 반복하거나 외부 라이브러리(Apache Commons Codec, Guava)에 의존해 hex 변환을 처리했습니다. Java 17부터 표준으로 추가된 `java.util.HexFormat`을 사용하면 구분자, 접두사, 대소문자까지 한 줄로 제어할 수 있습니다.

```java
byte[] bytes = {0x1A, 0x2B, 0x3C};

// 인코딩
String hex = HexFormat.of().formatHex(bytes);              // "1a2b3c"
String pretty = HexFormat.ofDelimiter(":").withUpperCase()
                         .formatHex(bytes);                 // "1A:2B:3C"

// 디코딩
byte[] decoded = HexFormat.of().parseHex("1a2b3c");
```

> 💡 **왜 중요한가**: 해시값 출력, 디버깅 로그, 바이너리 프로토콜 처리에서 흔히 쓰이는 hex 변환을 외부 의존성 없이 표준 API로 일관되게 처리할 수 있습니다.

### `Thread.ofVirtual()`로 수십만 개의 경량 스레드를 자유롭게 생성하기 (Java 21 정식)

가상 스레드(Virtual Thread)는 JVM이 관리하는 경량 스레드로, OS 스레드 1개에 다수의 가상 스레드를 매핑해 I/O 대기 중에도 OS 스레드를 점유하지 않습니다. 기존 `Executors.newFixedThreadPool()` 기반 풀링 코드를 거의 수정 없이 대체할 수 있어, "스레드 풀 크기 튜닝"이라는 오래된 문제 자체를 사라지게 만듭니다.

```java
// 단발성 가상 스레드
Thread.startVirtualThread(() -> System.out.println("hi"));

// 가상 스레드 기반 ExecutorService
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    IntStream.range(0, 100_000).forEach(i ->
        executor.submit(() -> {
            Thread.sleep(Duration.ofSeconds(1));
            return fetch(i);
        })
    );
}
```

> 💡 **왜 중요한가**: I/O 바운드 작업이 많은 서버(웹 요청 처리, 외부 API 호출)에서 동기적이고 읽기 쉬운 `thread-per-request` 스타일을 유지하면서도 처리량을 수십 배 끌어올릴 수 있습니다.
