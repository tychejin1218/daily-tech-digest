### `Files.writeString(Path, CharSequence)`로 문자열을 파일에 한 줄로 저장하기 (Java 11 정식)

`Files.write()`에 `Collections.singletonList()`나 `getBytes(StandardCharsets.UTF_8)`를 감싸 넘기던 번거로움을 제거한 표준 API입니다. `Files.writeString(path, "hello", StandardCharsets.UTF_8)` 한 줄이면 UTF-8 인코딩까지 명시적으로 처리되고, `StandardOpenOption`으로 append 모드도 그대로 지정할 수 있습니다. 짝으로 `Files.readString(Path)`도 함께 도입되어 소형 텍스트 파일 I/O에서 보일러플레이트가 사실상 사라집니다.

> 💡 **왜 중요한가**: 문자열 파일 저장에서 `List` 래핑과 `getBytes()` 실수로 인한 인코딩 버그를 원천 차단할 수 있습니다.

### `CompletableFuture.orTimeout(long, TimeUnit)`로 비동기 작업에 타임아웃을 강제하기 (Java 9 정식)

기존에는 `CompletableFuture`에 타임아웃을 걸려면 `ScheduledExecutorService`로 별도 타이머를 만들어 `completeExceptionally()`를 호출하는 보일러플레이트가 필요했습니다. `future.orTimeout(3, TimeUnit.SECONDS)`는 지정 시간이 지나면 `TimeoutException`으로 예외 완료시키고, `completeOnTimeout(defaultValue, 3, TimeUnit.SECONDS)`는 기본값으로 정상 완료시킵니다. 외부 API 호출을 논블로킹으로 조합할 때 무한 대기를 방지하는 표준 방어선이 됩니다.

> 💡 **왜 중요한가**: 외부 의존성이 응답하지 않을 때 스레드와 리소스가 무한 점유되는 사고를 표준 API 한 줄로 막을 수 있습니다.
