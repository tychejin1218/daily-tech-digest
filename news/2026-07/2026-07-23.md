### Anthropic, Claude Skills API 정식 공개 — 조직 전용 도구 세트를 SDK로 배포

Anthropic이 조직 내부 도구·프롬프트·워크플로우를 하나의 'Skill' 번들로 패키징해 배포하는 Skills API를 정식 공개했다. 개발자는 YAML 매니페스트와 실행 스크립트를 함께 등록하고, Claude가 컨텍스트에 따라 자동으로 스킬을 선택·호출하도록 위임할 수 있다.

```bash
anthropic skills push ./my-skill --org acme
```

> 💡 **왜 중요한가**: MCP 서버를 조직 단위로 배포·버전 관리하는 표준이 생기면서, 사내 지식과 도구를 LLM에 재사용하는 파이프라인이 코드처럼 취급된다.

### Docker, 'Model Runner' GA — 컨테이너처럼 LLM을 로컬에서 실행

Docker Desktop 4.42에서 Model Runner가 GA로 승격되어, `docker model pull llama3.3` 한 줄로 로컬 GGUF/Ollama 모델을 컨테이너 이미지처럼 관리할 수 있게 됐다. OpenAI 호환 엔드포인트(`localhost:12434/v1`)를 자동 노출하고, GPU 패스스루와 모델 캐시 공유가 기본 활성화된다.

```bash
docker model run llama3.3 --port 11434
curl localhost:12434/v1/chat/completions -d '{"model":"llama3.3","messages":[...]}'
```

> 💡 **왜 중요한가**: LLM 개발이 이제 Dockerfile 워크플로우에 완전히 흡수되어, 로컬 추론 환경을 표준 이미지처럼 배포·재현할 수 있다.

### AWS Lambda, 'Response Streaming for AI' 확장 — 15분 타임아웃 & 200MB 페이로드

AWS가 Lambda의 스트리밍 응답 한계를 20MB→200MB, 실행 시간을 최대 15분까지 상향해 LLM 프록시·에이전트 워크로드를 정식 지원 대상에 포함시켰다. `awslambda.streamifyResponse`가 SSE·NDJSON을 네이티브로 처리하고, 이벤트 소스 매핑에서 Bedrock InvokeAgent 응답을 직접 릴레이할 수 있다.

```javascript
export const handler = awslambda.streamifyResponse(async (event, stream) => {
  for await (const chunk of bedrock.invokeAgentStream(event)) {
    stream.write(chunk);
  }
  stream.end();
});
```

> 💡 **왜 중요한가**: 서버리스에서 LLM 스트리밍의 마지막 병목이었던 페이로드·타임아웃 제한이 풀리면서, 별도 컨테이너 없이 Lambda만으로 에이전트 백엔드를 완결할 수 있다.
