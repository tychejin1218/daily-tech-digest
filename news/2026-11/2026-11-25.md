### 2026-11-25 백엔드/AI 뉴스 브리핑

#### 1. Elastic 'Serverless Vector Database' GA — 벡터 DB '4강 체제'가 오늘자로 굳었다, 수백억 벡터를 '분 단위'로 띄우는 서버리스가 디폴트가 됐다

Elastic이 Elastic Cloud Serverless 위에 올라간 전용 벡터 검색 서비스를 정식 출시했다. 자동 양자화(Better Binary Quantization)로 벡터 메모리를 최대 32배 압축하면서도 리콜을 유지하고, 수백억 벡터 스케일까지 '분 단위 프로비저닝'으로 올라간다고 발표했다. 한때 Pinecone·pgvector의 2강 구도였던 벡터 DB 시장은 Redis Vector Sets에 이어 Elastic까지 뛰어들며 사실상 4강 체제로 재편됐다.

> 💡 **왜 중요한가**: RAG 스택을 새로 짜는 팀이라면 '기존 Elasticsearch 로그 인프라'를 벡터 DB로 그대로 승격시킬 수 있는 선택지가 생겼다 — 벡터 DB를 '별도 신규 시스템'으로 도입할 명분이 하나 더 약해졌다.

#### 2. Google 'Agent Substrate' + 'gVisor' CNCF 기부 — 쿠버네티스가 '에이전트 컨트롤 플레인' 표준을 품었다, LangGraph Platform·Bedrock AgentCore 위에 '벤더 중립' 레이어가 꽂혔다

Google이 액터(actor) 기반 에이전트 컨트롤/데이터 플레인인 Agent Substrate와 격리 런타임 gVisor를 CNCF(Cloud Native Computing Foundation)에 기부했다. 이로써 "장기 실행 에이전트 상태를 어디에 두고, 어떤 샌드박스에서 돌릴 것인가"라는 질문이 처음으로 '쿠버네티스 생태계 내부'에서 중립적으로 답해질 수 있게 됐다. 지금까지 각사가 각자 PaaS(LangGraph Platform, Bedrock AgentCore, Vertex AI Agent Engine)로 가둬두던 영토가, 쿠버네티스 클러스터가 있는 어느 조직이든 자가 호스팅할 수 있는 OSS 레이어로 흘러나왔다.

> 💡 **왜 중요한가**: '에이전트 플랫폼 = 특정 클라우드 매니지드 서비스'라는 공식에 균열이 생겼다 — 내년 K8s 운영팀의 1급 업무로 "에이전트 런타임 배치/감사"가 올라올 가능성이 매우 높다.

#### 3. boxes.dev (YC F26) 정식 런칭 — '내 Claude Code·Codex 구독'을 클라우드 샌드박스에 '무한 복제'해서 돌린다, '1인 개발자 에이전트 함대'가 구독료 추가 없이 가능해졌다

Y Combinator F26 배치의 boxes.dev가 어제(11-24) 공개됐다. 핵심은 "내 로컬 맥북에 깔려 있는 Claude Code·Codex CLI 구독을 클라우드의 여러 격리 샌드박스에 그대로 복제해서 동시 실행"하는 것. 각 박스는 격리된 dev container로, 레포 체크아웃·테스트 러너·브라우저 자동화까지 묶여 있어 "로컬 환경을 그대로 N개로 뻗은 뒤 각각에 다른 태스크를 던지는" 패턴이 월 구독 요금 안에서 가능해졌다.

> 💡 **왜 중요한가**: Cursor Background Agents·Claude Code Fleets가 '벤더 내부 함대'였다면, boxes.dev는 '내 기존 구독으로 돌리는 벤더 중립 함대'다 — '1인 개발자의 에이전트 병렬성'을 늘리는 데 추가 토큰 요금 없이 베팅할 수 있는 첫 레이어다.
