### 1. OpenCode v1.16.0 출시 — 오픈소스 코딩 에이전트 1위 등극, 워크스페이스 클로닝 지원

SST 팀이 만든 터미널 네이티브 오픈소스 AI 코딩 에이전트 OpenCode가 6월 5일 v1.16.0을 출시하며 LogRocket의 6월 AI 개발 도구 랭킹에서 Cursor 3를 제치고 1위에 올랐다. 새 버전은 dirty/untracked 파일을 유지하는 managed workspace cloning, 세션의 워크스페이스·디렉터리 간 이동을 지원하며 GitHub 스타 16만, 월 750만 개발자가 사용하는 최대 규모 오픈소스 코딩 에이전트로 자리잡았다. 1월 Anthropic의 서드파티 차단 이후 OpenAI가 공식 파트너십을 맺어 Codex·ChatGPT 구독을 OpenCode 안에서 직접 사용할 수 있게 됐다.

> 💡 **왜 중요한가**: 모델 종속성에서 벗어난 model-agnostic·privacy-first 에이전트가 상용 IDE를 처음으로 추월하며 "에이전트는 곧 IDE 부속"이라는 공식을 깨뜨렸다.

### 2. Qwen3 Coder Next · MiniMax M2.7 동시 출시 — 오픈웨이트 코딩 모델이 프런티어와의 격차를 좁히다

6월 6일 Alibaba의 Qwen3 Coder Next, MiniMax M2.5 Highspeed, M2.7 Highspeed, M2.7이 같은 날 릴리스되며 오픈웨이트 진영의 코딩 모델 라인업이 한꺼번에 갱신됐다. DeepSeek V4, Kimi K2.6, GLM 5.1과 함께 이들 모델은 실제 엔지니어링 파이프라인에 배포되며 GPT-5.5·Claude Opus 4.7·Gemini 3.1 Pro 등 클로즈드 프런티어 모델과의 격차를 좁히고 있으며, MiMo-V2.5-Pro는 SWE-Bench Pro에서 long-horizon tool use 부문 오픈소스 1위를 차지했다.

> 💡 **왜 중요한가**: 출력 토큰당 $12~$30를 받는 프런티어 API 대신, 자체 호스팅이 가능한 오픈웨이트 모델로 에이전트 워크로드의 단가를 한 자릿수 센트대로 끌어내릴 수 있는 선택지가 늘었다.

### 3. MCP, Linux Foundation 산하 'Agentic AI Foundation'으로 이관 — 엔터프라이즈 생산 채택률 41% 돌파

Anthropic이 작년 12월 MCP(Model Context Protocol)를 Linux Foundation 산하 신설 Agentic AI Foundation에 기증한 이후 6개월 만에 Stacklok 2026 소프트웨어 리포트 기준 41% 기업이 MCP 서버를 한정 또는 광범위 프로덕션에서 운영 중이며, SDK 월 다운로드 9,700만 건·공개 서버 1만 개를 돌파했다. Anthropic·OpenAI·Block이 공동 설립하고 Google·Microsoft·AWS·Cloudflare·Bloomberg가 지원하는 거버넌스 구조 아래 Working Group과 SEP(Spec Enhancement Proposal) 프로세스가 가동 중이며, Forrester는 2026년 안에 엔터프라이즈 앱 벤더 30%가 자체 MCP 서버를 출시할 것으로 전망했다.

> 💡 **왜 중요한가**: "AI용 USB-C"로 불리던 단일 벤더 표준이 중립 재단으로 옮겨가며 SSO 인증·감사 로그·게이트웨이 등 엔터프라이즈가 막혀 있던 거버넌스 공백이 본격적으로 메워지기 시작했다.
