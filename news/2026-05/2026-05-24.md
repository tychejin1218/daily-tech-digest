### Anthropic Claude Code 'Dynamic Workflows' & 'Ultra Code' 모드 공개 — Bun 런타임 Zig→Rust 포팅 11일 만에 완료

Anthropic이 Claude Code에 장시간 자율 작업을 위한 Dynamic Workflows와 심층 추론 모드인 Ultra Code를 추가했다. 실전 검증 사례로 Bun 런타임의 Zig→Rust 대규모 포팅(약 75만 라인)을 단 11일 만에 수행해 테스트 스위트 99.8% 통과율로 병합했으며, 같은 날 Pro/Max/Team/Enterprise 요금제의 주간 사용량 한도를 50% 상향해 7월 13일까지 유지한다고 발표했다.

> 💡 **왜 중요한가**: AI 코딩 에이전트가 '보조 자동완성'을 넘어 대형 오픈소스 런타임을 언어 단위로 포팅할 수 있는 자율 실행 단계에 진입했다는 실증 사례다.

### OpenAI 'Daybreak' 발표 — GPT-5.5 + Codex 결합 프론티어 사이버보안 플랫폼, Cloudflare와 공동 런칭

OpenAI가 코드 취약점 탐지·자동 패치·인시던트 대응을 통합한 사이버보안 특화 플랫폼 Daybreak를 공개했다. GPT-5.5의 장기 추론과 Codex의 코드 실행 능력을 결합해 CVE 스캔부터 프로덕션 롤아웃까지 에이전트가 처리하며, 초기 파트너 Cloudflare는 자사 WAF·Workers 로그와 실시간 연동되는 통합을 함께 출시했다.

> 💡 **왜 중요한가**: LLM 에이전트의 첫 번째 대규모 수직 특화 SaaS로, '보안 자동화'는 감사 추적 요구가 강한 만큼 에이전트 옵저버빌리티·감사 로그 표준의 새 기준을 만들 가능성이 크다.

### Ollama 0.24 릴리스 — Codex App 네이티브 지원 & Gemma 4 MTP 투기적 디코딩 MLX 러너 도입

로컬 LLM 런타임 Ollama가 0.24로 올라오면서 OpenAI Codex 데스크톱 앱을 로컬 모델 백엔드로 직접 연결하는 어댑터를 내장하고, Apple Silicon용 MLX 러너에 Gemma 4 Multi-Token Prediction(MTP) 기반 투기적 디코딩을 정식 지원해 M5 맥에서 토큰 처리량이 최대 2.1배 향상됐다. vLLM 0.21·llama.cpp도 같은 주에 MTP를 정식 채택하며 로컬 인퍼런스 스택의 표준 최적화 기법으로 자리잡았다.

> 💡 **왜 중요한가**: 온디바이스 코딩 에이전트가 클라우드 API 대비 실사용 가능한 지연·처리량 구간에 진입해, 프라이빗 코드베이스를 다루는 팀의 로컬-우선 개발 워크플로가 실전 옵션이 된다.
