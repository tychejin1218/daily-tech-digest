### 1. Microsoft, '결정론적' 멀티에이전트 오케스트레이터 `Conductor` 오픈소스 공개 (5/14)

마이크로소프트가 YAML로 멀티에이전트 워크플로우를 정의하고 에이전트 간 라우팅을 **결정론적으로(deterministic)** 처리하는 CLI 도구 `Conductor`를 MIT 라이선스로 공개했다. GitHub Copilot SDK·Anthropic Agents SDK를 동시에 지원해 단일 워크플로우 안에서 `claude-haiku-4.5`로 분류, `gpt-5.2`로 MCP 도구 호출, `claude-opus-4.6-1m`으로 복잡 추론을 혼합 실행할 수 있고, 오케스트레이션 레이어 자체는 **토큰을 0개 소모**한다. 정적 병렬 그룹·동적 for-each·실시간 DAG 대시보드까지 포함된다.

> 💡 **왜 중요한가**: 그동안 LangGraph·CrewAI 등 LLM이 라우팅을 결정하던 "에이전트가 스스로 분기" 모델 대신, 정의 시점에 토폴로지가 고정된 결정론 오케스트레이션이 엔터프라이즈 표준으로 굳어지고 있다는 신호다.

### 2. OpenAI Responses API, 'Shell Tool · Agent Skills · 서버사이드 컴팩션' 동시 탑재 — Codex 없이도 풀-에이전트 실행

OpenAI가 Responses API를 단순 응답 생성기에서 **자율 에이전트 런타임**으로 확장했다. `container_auto`로 호스팅 Debian 12 워크스페이스(Python 3.11/Node 22/Java 17/Go 1.23/Ruby 3.1)가 자동 프로비저닝되는 `shell` 툴, `SKILL.md` 마크다운 매니페스트 기반의 재사용 가능한 Agent Skills, 그리고 5M 토큰·150회 툴 호출 세션에서도 정확도가 떨어지지 않은 서버사이드 컴팩션이 한꺼번에 들어갔다. Anthropic의 Skills 포맷과 **동일한 오픈 표준(YAML 프론트매터)** 으로 수렴한 점이 핵심.

> 💡 **왜 중요한가**: 클라이언트에서 에이전트 루프를 직접 돌리던 시대가 끝나고, "에이전트 실행 환경 + 영구 컨텍스트 + 스킬 패키지"가 API 한 호출로 묶여 제공되는 **에이전트 PaaS** 형태로 LLM API가 재정의되고 있다.

### 3. GitHub Copilot, 6/1부터 전 플랜 '사용량 기반 AI Credits' 전환 — 코딩 에이전트·CLI 호출이 모두 토큰으로 과금

GitHub가 Premium Request Unit(PRU) 체계를 폐기하고 **AI Credits**(입력·출력·캐시 토큰을 API 정가로 차감)로 전면 전환한다고 공지, 2026년 6월 1일부터 발효된다. Pro+ $39/월에는 $39 크레딧, Business $19에 $19 크레딧, Enterprise $39에 $39 크레딧이 포함되며 **Copilot Chat·CLI·클라우드 에이전트·Spaces·Spark·서드파티 코딩 에이전트**가 모두 크레딧을 소모한다(코드 자동완성·Next Edit는 무제한 유지). 월간 Pro/Pro+는 자동 마이그레이션, 연간 결제는 만료까지 PRU 유지.

> 💡 **왜 중요한가**: AI 코딩 도구 가격이 "정액 + 호출 횟수" 환상에서 벗어나 **실제 토큰 원가에 직결**되면서, 팀은 모델 선택·컨텍스트 관리·캐시 활용을 비용 최적화 관점으로 다뤄야 하는 시대로 진입한다.
