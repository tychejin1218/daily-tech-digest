### 1. AWS Kiro Crew 오픈소스 공개 — Cursor에게 던진 아마존의 정면 반격 카드
아마존이 8월 초 자사 AI IDE 'Kiro'에 다중 에이전트 오케스트레이터 **Kiro Crew**를 오픈소스로 공개했다. 세션 하나에 갇히지 않고 여러 리포·툴·수일에 걸친 작업을 병렬 서브에이전트에 위임하는 구조로, 이미 6개월간 3만9천여 명의 아마존 내부 빌더가 597번의 업데이트를 쏟아낸 물건이다.

> 💡 **왜 중요한가**: 커서·클로드 코드가 장악하던 AI IDE 시장에 하이퍼스케일러가 "오픈소스"라는 카드로 진입 — 벤더 락인 없는 다중 에이전트 워크플로 표준 다툼이 시작됐다.

### 2. Amazon Bedrock Web Search 정식 GA — LLM API에 '실시간 웹'이 서버사이드 툴로 붙었다
AWS가 Bedrock의 OpenAI GPT-5.4/5.5/5.6(Sol·Terra·Luna) 라인에 **서버사이드 웹 검색 툴**을 정식 GA로 붙였다. Responses API 파라미터 하나만 켜면 활성화되고, 구조화된 인용을 반환하며, 쿼리 데이터는 리전(us-east-1/2, us-west-2) 밖으로 절대 유출되지 않는다.

> 💡 **왜 중요한가**: RAG용 서드파티 검색 API·크롤러를 벤더 락인·에그레스 없이 대체 — 그라운딩 파이프라인 설계가 통째로 뒤집힌다.

### 3. AWS Dogwood 오픈소스 공개 — Cedar에 '시간'을 붙여 에이전트 인가를 재정의
Bedrock AgentCore에 통합된 오픈소스 정책 언어 **Dogwood**가 아파치 2.0으로 공개됐다(2026-08-06). Cedar와 완전 하위 호환되면서 세션 히스토리·레이트 리밋·워크플로 시퀀스·누적 비용 캡 같은 **시간 축 제약**을 인프라 레이어에서 강제해, 매 에이전트마다 하드코딩하던 가드레일을 정책으로 뽑아낸다.

> 💡 **왜 중요한가**: 에이전트 인가가 코드 조건문이 아니라 IAM 수준의 선언적 정책 계층으로 올라간 첫 사례 — 프로덕션 에이전트 거버넌스의 기준선이 바뀐다.
