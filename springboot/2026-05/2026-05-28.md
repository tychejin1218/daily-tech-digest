### `spring.jpa.open-in-view=false`로 OSIV를 꺼서 영속성 컨텍스트 생명주기를 트랜잭션 안으로 제한하기

Spring Boot는 기본적으로 OSIV(Open Session In View)가 켜져 있어 영속성 컨텍스트가 컨트롤러·뷰 렌더링 단계까지 유지되며, 그 덕에 지연 로딩이 어디서든 동작하지만 DB 커넥션을 요청 끝까지 잡고 있어 커넥션 풀 고갈을 유발합니다. `application.yml`에 `spring.jpa.open-in-view=false`를 주면 영속성 컨텍스트가 트랜잭션 경계에서 닫히므로 커넥션을 빨리 반납할 수 있습니다. 대신 컨트롤러에서 지연 로딩 시 `LazyInitializationException`이 나므로, 서비스 계층에서 필요한 연관관계를 fetch join이나 `@EntityGraph`로 미리 로딩하거나 DTO로 변환해 반환해야 합니다.

```yaml
spring:
  jpa:
    open-in-view: false
```

> 💡 **왜 중요한가**: OSIV를 끄면 DB 커넥션 점유 시간이 트랜잭션 범위로 줄어 고부하 상황에서 커넥션 풀 고갈과 응답 지연을 크게 완화할 수 있습니다.

### `@HttpExchange` 선언형 HTTP 인터페이스로 외부 API 클라이언트를 인터페이스만으로 정의하기

Spring 6+는 Feign처럼 인터페이스에 `@HttpExchange`/`@GetExchange` 등을 붙이면 실제 HTTP 호출 구현을 프레임워크가 만들어 주는 선언형 클라이언트를 지원합니다. `HttpServiceProxyFactory`에 `RestClientAdapter`(동기) 또는 `WebClientAdapter`(리액티브)를 물려 프록시 빈을 등록하면, URL 조립·직렬화·역직렬화를 직접 작성하지 않고도 타입 안전한 메서드 호출만으로 외부 API를 사용할 수 있습니다.

```java
public interface UserApiClient {
    @GetExchange("/users/{id}")
    User getUser(@PathVariable Long id);
}

@Bean
UserApiClient userApiClient(RestClient.Builder builder) {
    RestClient client = builder.baseUrl("https://api.example.com").build();
    var factory = HttpServiceProxyFactory
            .builderFor(RestClientAdapter.create(client)).build();
    return factory.createClient(UserApiClient.class);
}
```

> 💡 **왜 중요한가**: 별도 라이브러리(Feign) 없이 Spring 표준만으로 보일러플레이트 없는 타입 안전한 HTTP 클라이언트를 만들 수 있어 외부 연동 코드의 가독성과 테스트 용이성이 높아집니다.
