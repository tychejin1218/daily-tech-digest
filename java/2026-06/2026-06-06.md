### `Stream.takeWhile()` / `dropWhile()`로 정렬된 스트림을 조건부로 자르기 (Java 9 정식)
`filter()`는 전체 요소를 순회하지만, `takeWhile()`은 조건이 처음 깨지는 지점에서 멈추고 `dropWhile()`은 그 지점부터 끝까지 흘려보냅니다. 정렬된 데이터나 로그 스트림에서 "특정 시점까지만" 또는 "특정 시점 이후만" 처리할 때 인덱스 계산 없이 간결하게 표현할 수 있습니다.

```java
List<Integer> nums = List.of(1, 2, 3, 8, 4, 5);
nums.stream().takeWhile(n -> n < 5).toList();  // [1, 2, 3]
nums.stream().dropWhile(n -> n < 5).toList();  // [8, 4, 5]
```

> 💡 **왜 중요한가**: 정렬된 스트림에서 `filter()`로 전수 검사하는 대신 단락 평가(short-circuit)로 동작하므로 큰 데이터에서 불필요한 순회를 줄여줍니다.

### Pattern Matching for `switch`로 타입별 분기를 깔끔하게 (Java 21 정식)
`switch`에서 직접 타입 패턴과 `when` 가드를 쓸 수 있어, 길게 늘어지던 `if-else instanceof` 체인을 하나의 표현식으로 압축할 수 있습니다. `sealed` 인터페이스와 함께 쓰면 컴파일러가 모든 하위 타입의 분기를 강제해 누락된 케이스를 사전에 잡아냅니다.

```java
sealed interface Shape permits Circle, Square, Triangle {}

double area(Shape s) {
    return switch (s) {
        case Circle c       -> Math.PI * c.r() * c.r();
        case Square sq when sq.side() > 0 -> sq.side() * sq.side();
        case Square sq      -> 0;
        case Triangle t     -> 0.5 * t.base() * t.height();
    };
}
```

> 💡 **왜 중요한가**: `instanceof` 체인의 다운캐스팅 보일러플레이트를 제거하고, `sealed` 타입과 결합하면 새 하위 타입이 추가될 때 컴파일러가 누락된 분기를 강제로 알려줍니다.
