### 1. `Stream.mapMulti((element, consumer) -> ...)`로 `flatMap`의 스트림 생성 오버헤드 벗어나기 (Java 16 정식)

`flatMap`은 요소마다 새 `Stream`을 만들어 반환해야 하지만, `mapMulti`는 `Consumer`를 직접 호출해 0..N개 결과를 방출한다. 조건부로 소수 요소만 뿜거나 원시 타입 결과가 필요할 때 특히 이득이며, `mapMultiToInt/Long/Double` 오버로드로 박싱 없이 IntStream까지 만들 수 있다.

```java
// AS-IS: 요소당 Stream.of / Stream.empty 생성
List<Integer> evens = numbers.stream()
    .flatMap(n -> n % 2 == 0 ? Stream.of(n * 10) : Stream.empty())
    .toList();

// TO-BE: Consumer 호출만으로 0/1/N개 방출
List<Integer> evens = numbers.stream()
    .<Integer>mapMulti((n, out) -> {
        if (n % 2 == 0) out.accept(n * 10);
    })
    .toList();

// 원시 타입은 mapMultiToInt로 박싱 제거
int sum = orders.stream()
    .mapMultiToInt((o, out) -> o.items().forEach(i -> out.accept(i.price())))
    .sum();
```

> 💡 **왜 중요한가**: 대량 스트림에서 `flatMap`의 요소당 Stream 인스턴스 생성 비용이 사라져, 필터+변환 조합의 지연·GC 압박이 눈에 띄게 줄어든다.

### 2. `switch` 패턴 매칭 + `when` 가드로 `if-else instanceof` 사다리 벗어나기 (Java 21 정식)

`switch` 표현식이 타입 패턴과 `when` 절을 지원하면서, 클래스 계층 분기·값 조건을 한 문장으로 표현할 수 있다. `sealed` 타입과 결합하면 컴파일러가 누락된 케이스를 잡아주므로 `default`를 강제로 넣던 관성에서 벗어난다.

```java
sealed interface Payment permits Card, Cash, Voucher {}
record Card(long amount, String brand) implements Payment {}
record Cash(long amount) implements Payment {}
record Voucher(long amount, boolean expired) implements Payment {}

// AS-IS: instanceof 사다리 + 캐스팅 + null 체크
String describe(Payment p) {
    if (p == null) return "none";
    if (p instanceof Card c && c.amount() > 100_000) return "VIP " + c.brand();
    if (p instanceof Card c) return "Card " + c.brand();
    if (p instanceof Cash cash) return "Cash " + cash.amount();
    if (p instanceof Voucher v && v.expired()) return "Expired";
    return "Voucher";
}

// TO-BE: 패턴 매칭 + when 가드, sealed 덕분에 default 불필요
String describe(Payment p) {
    return switch (p) {
        case null                          -> "none";
        case Card c when c.amount() > 100_000 -> "VIP " + c.brand();
        case Card c                        -> "Card " + c.brand();
        case Cash cash                     -> "Cash " + cash.amount();
        case Voucher v when v.expired()    -> "Expired";
        case Voucher v                     -> "Voucher";
    };
}
```

> 💡 **왜 중요한가**: 캐스팅·null 분기·`default`를 컴파일러가 강제·자동화해줘서, 새 하위 타입이 추가되면 빌드가 즉시 깨지는 안전한 계층 분기를 얻는다.
