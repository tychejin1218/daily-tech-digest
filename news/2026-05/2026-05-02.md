### 1. Microsoft, 'Agent 365' 정식 GA 출시 — 사용자당 월 15달러 'AI 에이전트 통합 관제센터' (5/1)

마이크로소프트가 5월 1일 **Microsoft Agent 365**를 정식 GA로 공개하며, 새로운 'Frontier Suite' 라이선스 체계인 **M365 E7(월 99달러/사용자)**과 동시에 출시했다. Agent 365는 'observe·govern·secure' 3개 축 위에서 조직 내 모든 AI 에이전트(자체 제작·서드파티·CoPilot 포함)를 단일 콘솔에서 모니터링·정책 적용·런타임 보호하는 컨트롤 플레인이며, **Defender가 에이전트의 권한 남용(예: 메일 MCP 서버 호출)을 런타임에 차단**하고, Intune의 새로운 'Shadow AI' 패널로 비승인 AI 사용까지 통제한다. 단독 가격은 사용자당 월 15달러.

> 💡 **왜 중요한가**: 'AI 에이전트 거버넌스'가 별도 보안 솔루션이 아니라 **M365 표준 관리 스택의 정식 한 축**으로 편입된 첫 사례이며, 사실상 엔터프라이즈 에이전트 운영의 OS-레벨 표준 자리를 노린다.

### 2. Alibaba, Qwen3.6-27B 공개 — 27B Dense 모델로 397B MoE를 뛰어넘은 '에이전틱 코딩' 신기록 (4/22)

알리바바 Qwen 팀이 Apache 2.0 라이선스로 **Qwen3.6-27B 공개**, **397B MoE 모델을 SWE-bench·Terminal-Bench 등 에이전틱 코딩 벤치마크에서 추월**했다. 같은 주에 동급 라인업인 **Qwen3.6-35B-A3B**(4/16)도 Hugging Face·ModelScope에 풀렸으며, 동시에 **Qwen3-Coder-Next**(Qwen3-Next-80B-A3B 기반, hybrid attention + MoE)도 코딩 에이전트와 로컬 개발용으로 공개됐다. 27B Dense 모델이 100B+ MoE급 성능을 낸다는 점에서 **단일 GPU 추론으로 프런티어 코딩 모델을 돌릴 수 있는 첫 오픈웨이트 후보**라는 평가가 나온다.

> 💡 **왜 중요한가**: '에이전틱 코딩 = 폐쇄형 SaaS' 구도가 흔들리고, 사내 단일 GPU/온프레미스에서 Cursor·Claude Code급 워크플로를 돌리는 시나리오가 현실화됐다.

### 3. Anthropic, 공식 'ant CLI' 공개 + Claude API 출력 토큰 한도 300k 베타 — Claude Code-API 일체화 가속

Anthropic이 Claude API 전용 공식 커맨드라인 클라이언트 **`ant` CLI**를 공개, **Claude Code와의 네이티브 통합**과 YAML 기반의 API 리소스(프롬프트·툴·에이전트 정의) 버전 관리를 지원한다. 동시에 **Message Batches API의 max_tokens 상한이 300,000 토큰**(`output-300k-2026-03-24` 베타 헤더, Opus 4.6·Sonnet 4.6 대상)으로 확장됐고, **Bedrock에서는 `ANTHROPIC_BEDROCK_SERVICE_TIER` 환경변수**로 default/flex/priority 서비스 티어를 골라 비용·우선순위를 튜닝할 수 있게 됐다. 단, **신규 Opus 4.7 토크나이저는 동일 입력에 대해 토큰을 최대 1.35배(기술 문서 기준 1.47배까지)** 더 소비해 명목 단가 동결에도 실질 비용이 20~30% 상승한다는 측정 결과가 잇따라 공유되고 있다.

> 💡 **왜 중요한가**: API 호출 단위에서 끝나던 LLM 사용 모델이 **CLI·YAML·서비스 티어·토크나이저까지 포괄하는 '플랫폼 운영' 단위**로 확장됐고, 비용 관리는 이제 단가 협상이 아니라 **토크나이저 벤치마킹**이 되어가고 있다.
