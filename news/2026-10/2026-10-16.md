### 1. OpenAI 'Dots' 공개 — GPT-6 Astra가 '대화 사이'에도 깨어 있는 '상시 가동 에이전트'가 됐다

OpenAI가 GPT-6 Astra 기반의 'Dots'를 공개했다. 사용자가 던진 목표를 **대화 세션 사이에도 계속 추적**하는 상시 가동(always-on) 에이전트로, 각 Dot은 자기 전용 클라우드 컴퓨터와 영구 메모리를 들고 백그라운드에서 돌아가며 "진행 중 상태"를 보고한다. 챗봇의 '요청-응답' 루프가 '목표-계속-보고' 루프로 접히는 전환으로, "ChatGPT를 또 열어야 한다"는 전제가 사라진다.

> 💡 **왜 중요한가**: LLM API 과금 모델이 '토큰당'에서 '에이전트 가동시간당'으로 넘어가는 첫 번째 상용 사례 — 백엔드 설계에서 '세션'이 아니라 '에이전트 수명'을 1급 리소스로 다뤄야 한다.

### 2. Anthropic 'Claude Platform on AWS' 정식 공개 — Claude API가 AWS 네이티브 서비스로 접혔다, IAM이 API 키를 대체한다

Anthropic이 'Claude Platform on AWS'를 공개했다. 기존 Bedrock 프록시가 아니라 **Anthropic이 직접 AWS 리전 안에서 운영**하는 Claude API로, 인증은 Anthropic API 키가 아니라 **AWS IAM 역할**로 처리되고 과금은 AWS 청구서에 한 줄로 합류한다. 'Claude를 쓰려면 두 번째 벤더 계약·두 번째 키 로테이션·두 번째 보안 심사가 필요하다'는 엔터프라이즈 저항이 공식적으로 사라진 날이다.

> 💡 **왜 중요한가**: '멀티 벤더 LLM 전략'의 비용이 급락 — 엔터프라이즈 백엔드는 이제 OpenAI(Azure OpenAI)·Claude(AWS)·Gemini(Vertex) 셋 다 "같은 기존 클라우드 계약" 안에서 라우팅할 수 있다.

### 3. DigitalOcean 'Agent Data' + 'Agent Learning' GA — '자가 개선 에이전트'를 직접 짜지 말라, 피드백 루프가 패키징돼 나왔다

DigitalOcean이 에이전트 운영자용 Managed 서비스 두 개를 한꺼번에 GA로 올렸다. **Agent Data**는 에이전트의 입출력·툴 호출·실패를 자동 수집해서 "어떤 입력에서 터지는가"를 보여주고, **Agent Learning**은 그 수집 데이터로 평가셋을 만들어 프롬프트·툴 디스크립션을 재튜닝해 다시 배포한다. '관찰(Observe) → 탐지(Detect) → 테스트(Test)' 루프를 **직접 OpenTelemetry·Langfuse·Promptfoo로 조립하지 말고 한 묶음으로 사라**는 포지셔닝이다.

> 💡 **왜 중요한가**: AI 애플리케이션 운영의 "오픈소스 자가 조립 vs. 매니지드 번들" 전선이 열렸다 — 소규모 팀은 피드백 루프 인프라에 엔지니어 2~3명을 쓸지, 월 과금으로 사버릴지의 1차 분기점이 생겼다.
