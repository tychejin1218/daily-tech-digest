### LangChain, 'LangGraph Cloud 2.0' GA — 스테이트풀 에이전트 프로덕션 배포 표준화

LangChain이 에이전트 워크플로우 런타임인 LangGraph Cloud를 정식 출시했다. 지속 체크포인트·휴먼 인더 루프 승인·병렬 서브그래프 실행을 매니지드로 제공하며, LangSmith와 통합돼 노드 단위 트레이싱과 재실행이 가능하다. Python·JavaScript SDK 모두 새로운 `Assistant` 리소스 개념을 도입해 동일 그래프의 여러 설정 프로파일을 API로 관리한다.

```python
from langgraph_sdk import get_client

client = get_client(url="https://api.langgraph.cloud")
thread = await client.threads.create()
run = await client.runs.create(
    thread_id=thread["thread_id"],
    assistant_id="agent-prod",
    input={"messages": [{"role": "user", "content": "..."}]},
    interrupt_before=["human_review"],
)
```

> 💡 **왜 중요한가**: 자체 구축하던 에이전트 상태 저장·재개 인프라를 매니지드로 넘길 수 있어, 프로덕션 에이전트 서비스의 진입 장벽이 크게 낮아졌다.

### Cloudflare Workers AI, Llama 3.5 405B 서버리스 인퍼런스 GA — 콜드스타트 200ms 이하

Cloudflare가 Workers AI 플랫폼에서 Meta Llama 3.5 405B Instruct의 완전 서버리스 실행을 정식 지원한다고 발표했다. 300개 이상 엣지 로케이션에 분산 배치돼 콜드스타트 200ms 미만·평균 첫 토큰 지연 400ms를 보장하며, 요청당 과금(입력 $2.75/M 토큰, 출력 $5.50/M 토큰)으로 GPU 예약 없이 사용할 수 있다. AI Gateway·Vectorize·D1과의 바인딩이 워커 스크립트 한 파일에서 완결된다.

```javascript
export default {
  async fetch(request, env) {
    const res = await env.AI.run("@cf/meta/llama-3.5-405b-instruct", {
      messages: [{ role: "user", content: "Refactor this SQL..." }],
      stream: true,
    });
    return new Response(res, { headers: { "content-type": "text/event-stream" } });
  },
};
```

> 💡 **왜 중요한가**: 405B급 오픈웨이트 모델을 서버리스 요금으로 쓸 수 있게 되면서, 자체 GPU 클러스터를 운영할 여력이 없는 팀도 프론티어 오픈 모델을 프로덕션에 태울 수 있게 됐다.

### Snowflake 'Cortex Analyst' 정식 출시 — 시맨틱 모델 기반 Text-to-SQL, 정확도 92% 달성

Snowflake가 자연어 질의를 SQL로 변환하는 Cortex Analyst를 GA로 승격했다. 단순 스키마 매칭이 아니라 YAML로 정의한 시맨틱 모델(측정치·차원·조인·비즈니스 용어)을 기반으로 쿼리를 생성해, 자체 벤치마크에서 정답률 92%(GPT-4o 단독 대비 +34%p)를 기록했다고 밝혔다. REST API로 노출돼 Slack봇·BI 대시보드·사내 챗봇에 직접 연동 가능하며, 생성된 SQL과 사용된 시맨틱 요소를 함께 반환해 검증할 수 있다.

```yaml
# semantic_model.yaml
tables:
  - name: orders
    dimensions:
      - name: region
        expr: customer_region
    measures:
      - name: total_revenue
        expr: SUM(amount)
        synonyms: ["매출", "revenue", "판매액"]
```

> 💡 **왜 중요한가**: LLM에 스키마만 던지던 방식의 한계를 시맨틱 레이어로 돌파한 첫 상용 사례로, 사내 데이터 셀프서비스 챗봇을 실무 신뢰도까지 끌어올릴 수 있게 됐다.
