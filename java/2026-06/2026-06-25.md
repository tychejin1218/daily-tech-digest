### `Math.clamp()`로 값을 특정 범위 내로 강제하기 (Java 21 정식)
`Math.clamp(value, min, max)`는 값이 범위 밖이면 경계값으로 잘라내고, 범위 안이면 그대로 반환합니다. 기존에는 `Math.max(min, Math.min(max, value))`처럼 중첩 호출이 필요했지만, 이제 의도가 명확한 한 줄로 표현되며 `min > max`인 잘못된 인자에는 `IllegalArgumentException`을 던져 안전성도 보장됩니다.

```java
int volume = Math.clamp(userInput, 0, 100);   // 음수면 0, 100 초과면 100
double opacity = Math.clamp(value, 0.0, 1.0); // long, double 오버로드 제공
```

> 💡 **왜 중요한가**: UI 좌표, 볼륨, 진행률 등 "유효 범위 내로 보정"이 필요한 코드에서 가독성과 안전성을 동시에 확보할 수 있습니다.

### `Stream.takeWhile()` / `dropWhile()`로 조건부 스트림 자르기 (Java 9 정식)
`takeWhile(predicate)`는 조건이 처음 거짓이 되는 순간까지의 요소만 취하고, `dropWhile(predicate)`는 그 지점 이후만 남깁니다. `filter()`는 모든 요소를 검사해 조건에 맞는 것을 모두 남기지만, 이들은 **순서가 의미 있는** 스트림에서 정렬된 데이터의 앞/뒤 구간을 잘라낼 때 유용합니다.

```java
// 로그를 읽다가 ERROR 라인을 만나기 전까지만 처리
lines.stream()
     .takeWhile(line -> !line.contains("ERROR"))
     .forEach(System.out::println);

// 헤더(주석 라인)를 건너뛰고 본문부터 파싱
lines.stream()
     .dropWhile(line -> line.startsWith("#"))
     .forEach(parser::parse);
```

> 💡 **왜 중요한가**: 정렬된 시계열 데이터나 헤더가 있는 텍스트 처리에서 인덱스 계산이나 플래그 변수 없이 의도를 그대로 코드로 옮길 수 있습니다.
