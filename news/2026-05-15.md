# 2026-05-15 백엔드/클라우드/AI 주요 IT 뉴스 3선

### 1. xAI, 첫 코딩 에이전트 'Grok Build' CLI 베타 공개 — Plan Mode·병렬 서브에이전트 8개·ACP/MCP 호환
xAI가 5월 14일 터미널 네이티브 코딩 에이전트 **Grok Build**를 SuperGrok Heavy 가입자 대상으로 베타 출시했다. 200만 토큰 컨텍스트의 Grok 4.3 기반으로, 최대 8개 서브에이전트를 병렬 실행하고 Anthropic의 Skills·MCP 서버, Agent Client Protocol(ACP)을 그대로 사용할 수 있어 Claude Code·Codex와의 호환 계층을 노골적으로 겨냥했다. 설치는 `curl -fsSL https://x.ai/cli/install.sh | bash` 한 줄, 가격은 월 $300(초기 6개월 $99 프로모션).

> 💡 **왜 중요한가**: '코딩 에이전트 = CLI + 표준 프로토콜(MCP/ACP) + 병렬 서브에이전트'라는 합의가 굳어지면서, 기존 에이전트 자산(Skills·MCP 서버)을 그대로 들고 모델만 갈아끼우는 멀티-에이전트 시대로 진입했다.

### 2. CNCF, '쿠버네티스 버그 픽스' 에이전트 검색 전략 벤치마크 공개 — RAG-only가 가장 빠르지만 시스템 영향 추론은 약점
CNCF/InfoQ가 9건의 실제 쿠버네티스 버그(kubelet·scheduler·네트워킹·스토리지)를 대상으로 ① KAITO RAG Engine + Qdrant(BM25+임베딩) ② RAG-우선 → 로컬 FS 하이브리드 ③ 로컬 클론-온리 세 가지 에이전트 구성을 비교했다. **RAG-only**가 평균 76초로 가장 빨랐고 하이브리드는 ~2분 30초로 가장 느렸으며, "검색 전략은 코드 발견 속도엔 영향을 주지만 시스템 전반 영향 추론 품질엔 거의 영향을 주지 않는다"는 결론을 냈다. 결국 *이슈 설명의 품질*이 검색 아키텍처 선택보다 더 큰 레버였다.

> 💡 **왜 중요한가**: "RAG만 잘 깔면 자동 버그 픽스가 된다"는 환상에 제동을 건 첫 컨트롤드 벤치마크 — 인프라 팀은 검색 인덱스 튜닝보다 *버그 리포트 템플릿*에 투자해야 ROI가 나온다는 신호다.

### 3. Meta, 'Unified AI Agent' 플랫폼으로 하이퍼스케일 성능 회귀 자동 픽스 — 10시간 조사를 30분으로 압축
Meta가 자사 인프라 전반의 성능·전력 회귀를 AI 에이전트가 자동 탐지·수정하는 **Unified AI Agent** 플랫폼을 공개했다. 시니어 효율 엔지니어의 도메인 지식을 재사용 가능한 'Skill'로 인코딩해, AI Regression Solver가 FBDetect와 연동되어 성능 회귀 PR을 자동 생성한다. 평균 약 10시간이 걸리던 수동 조사가 약 30분으로 줄었고, 누적 회수 전력은 **수백 메가와트** 규모. 같은 기반 위에 캐파시티 플래닝·대화형 어시스턴트·가이드 조사 워크플로가 동시에 올라갔다.

> 💡 **왜 중요한가**: 코딩 에이전트의 다음 전선은 IDE가 아니라 **SRE·캐파시티·전력 최적화** — '엔지니어가 본 적 없는 회귀를 AI가 PR로 던지는' 자가-튜닝 인프라가 하이퍼스케일에선 이미 프로덕션이다.
