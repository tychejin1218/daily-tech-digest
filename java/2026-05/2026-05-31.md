### `String.formatted()`로 `String.format()`을 메서드 체인 스타일로 호출하기 (Java 15 정식)

`String.format("Hello, %s!", name)` 대신 `"Hello, %s!".formatted(name)`처럼 포맷 문자열 자체에 인자를 넘길 수 있어 가독성이 좋아지고 정적 임포트도 필요 없어진다. 특히 텍스트 블록(`"""`)과 함께 쓰면 여러 줄 템플릿을 자연스럽게 채울 수 있다.

```java
String greeting = "Hello, %s! You are %d years old.".formatted("Jin", 30);

String json = """
    {
      "id": %d,
      "name": "%s"
    }
    """.formatted(1, "Jin");
```

> 💡 **왜 중요한가**: 포맷 문자열이 앞에 오면 결과 형태를 바로 파악할 수 있어 로그·예외 메시지·JSON 템플릿 등에서 코드 흐름이 훨씬 자연스러워진다.

### `Collectors.filtering()`으로 `groupingBy` 내부에서 필터링을 안전하게 하기 (Java 9 정식)

`groupingBy` 앞에서 `filter()`를 걸면 조건에 맞지 않는 그룹 키 자체가 사라지지만, `Collectors.filtering()`을 다운스트림으로 쓰면 모든 그룹 키를 유지하면서 값만 걸러낼 수 있다. "카테고리별 프리미엄 상품 수"처럼 0건인 그룹도 결과에 남겨야 할 때 특히 유용하다.

```java
Map<String, List<Product>> premiumByCategory = products.stream()
    .collect(Collectors.groupingBy(
        Product::category,
        Collectors.filtering(p -> p.price() >= 100_000, Collectors.toList())
    ));
// 결과: 모든 카테고리가 키로 남고, 프리미엄 상품이 없는 카테고리는 빈 리스트가 됨
```

> 💡 **왜 중요한가**: 사전 필터링과 다운스트림 필터링은 그룹 키 보존 여부가 달라 통계·리포트에서 "0건 카테고리 누락" 같은 버그의 원인이 되기 쉽다.
