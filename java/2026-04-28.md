### 1. Flexible Constructor Bodies로 `super()`/`this()` 호출 이전에 검증·초기화 로직 실행하기 (Java 25 정식)
생성자 첫 줄에서만 `super()`/`this()`를 호출할 수 있던 기존 제약이 풀려, 해당 호출 **이전**에 인수 검증, 매개변수 정규화, 보조 변수 계산 같은 prologue 코드를 자유롭게 작성할 수 있습니다. 단, 호출 이전 단계에서는 아직 미초기화된 인스턴스 필드와 `this` 참조에 접근할 수 없다는 규칙은 그대로 유지되어 안전성이 보장됩니다.

```java
public class PositiveBigInteger extends BigInteger {
    public PositiveBigInteger(long value) {
        if (value <= 0) {                      // super() 호출 전 검증
            throw new IllegalArgumentException("must be positive");
        }
        var normalized = Long.toString(value); // 보조 변수 계산
        super(normalized);                     // 마지막에 super 호출
    }
}
```

> 💡 **왜 중요한가**: 그동안 정적 팩토리 메서드나 `private` 보조 생성자 우회로 처리하던 "부모 호출 전 검증"을 정공법으로 표현해 코드 가독성과 안전성이 동시에 향상됩니다.

### 2. Foreign Function & Memory (FFM) API로 JNI 없이 네이티브 라이브러리 호출하기 (Java 22 정식)
`java.lang.foreign` 패키지의 `Linker`, `SymbolLookup`, `MemorySegment`, `Arena`를 사용해 C 헤더 시그니처를 그대로 매핑하고, 오프힙 메모리를 결정적(deterministic) 라이프사이클로 관리할 수 있습니다. JNI에 필요했던 별도 C 컴파일·헤더 생성·수동 메모리 해제가 사라지고, `Arena.ofConfined()`로 스코프 종료 시 자동 해제까지 보장됩니다.

```java
Linker linker = Linker.nativeLinker();
SymbolLookup stdlib = linker.defaultLookup();
MethodHandle strlen = linker.downcallHandle(
    stdlib.find("strlen").orElseThrow(),
    FunctionDescriptor.of(ValueLayout.JAVA_LONG, ValueLayout.ADDRESS));

try (Arena arena = Arena.ofConfined()) {
    MemorySegment cString = arena.allocateUtf8String("Hello, FFM!");
    long len = (long) strlen.invoke(cString);   // = 11
}
```

> 💡 **왜 중요한가**: 사라질 예정인 `sun.misc.Unsafe`와 보일러플레이트 가득한 JNI를 모두 대체하는 표준·안전·고성능 네이티브 인터롭 수단으로, 시스템 라이브러리·GPU 런타임·암호화 백엔드 연동의 진입 장벽을 크게 낮춥니다.
