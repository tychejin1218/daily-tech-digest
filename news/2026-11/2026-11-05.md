### 1. OpenAI 'Pando' Git 백엔드 + Pierre Computer 인수 — Git 그 자체가 '에이전트 네이티브'로 다시 쓰이기 시작했다, GitHub의 30년 독점에 금이 갔다
OpenAI가 11월 2일 사내에서 만든 Git 백엔드 'Pando'를 공개한 데 이어 개발자 도구 스타트업 Pierre Computer 인수를 발표했다. 에이전트가 하루에 수백 개의 PR을 찍어내는 트래픽 패턴(관측된 에이전트 PR 6배 증가)을 기존 Git·GitHub 아키텍처가 못 버틴다는 전제에서, 저장소 레이어부터 Codex에 맞춰 다시 쓰고 있다.

> 💡 **왜 중요한가**: '에이전트가 PR을 쓴다'는 전제가 CI 파이프라인과 코드 호스팅 전체를 재설계하게 만들고 있다 — Git이 사람의 커밋 주기(하루 10개)가 아니라 에이전트의 커밋 주기(시간당 100개)에 맞춰져야 한다는 뜻이다.

### 2. Anthropic Messages API 'Message Threads' 퍼블릭 베타 공개 — 롱호라이즌 에이전트가 턴마다 '전체 컨텍스트'를 다시 안 보내도 된다, 긴 대화 비용 곡선이 꺾였다
Claude Messages API에 메시지 스레드가 공개 베타로 들어왔다. 에이전트가 턴마다 전체 히스토리를 재전송하지 않고 '새 메시지만' 보내면 서버가 스레드 상태를 들고 있다가 이어서 응답한다. Opus 5.5가 11월 플래그십으로 올라서고, Ultra 플랜($200/월, API 크레딧 $200 포함)이 같이 떴다.

> 💡 **왜 중요한가**: 지금까지 "장시간 에이전트는 토큰 비용으로 죽는다"가 상식이었다. 서버사이드 세션 상태가 1급 기능이 됐다는 건, LangGraph·Vercel AI SDK가 쥐고 있던 '에이전트 상태 머신' 레이어를 모델 벤더가 직접 삼키러 왔다는 신호다.

### 3. Google·Mandiant 'LLMjacking' 공식 경보 — 탈취된 IAM 키 한 건이 월 $1M 청구서로 돌아왔다, 'AI API 키'가 공급망 공격의 1번 과녁이 됐다
Google과 Mandiant가 UNC6993를 포함한 위협 그룹이 GitHub PAT·세션 토큰·서비스 계정 키를 훔쳐 피해자 클라우드 프로젝트에 몰래 LLM API 키를 더 만들고, 그 키로 Claude·GPT를 대량 호출해 피해자에게 수십만~$1M 단위의 Vertex/Bedrock 청구서를 떠넘기고 있다고 발표했다. Apigee를 'AI 게이트웨이'로 세워 tenant·token·quota 예산을 끊으라는 가이드가 같이 나왔다.

> 💡 **왜 중요한가**: 전통적 침해 지표가 '데이터 유출'이었다면, LLM 시대의 1번 손실은 '청구서'다. API 키 1개의 가치가 10만~100만 달러 단위로 뛰었다는 건, 백엔드 아키텍처에서 LLM 호출이 이제 'DB 접근'보다 더 엄격하게 게이팅돼야 한다는 뜻이다 — 레이트 리밋·토큰 예산·키 로테이션이 선택이 아니라 최소 요건이 됐다.
