### Anthropic 'Claude Sonnet 5' 정식 출시 — 에이전틱 코딩에 집중, $2/$10 per MTok 도입 가격
Anthropic이 롱런 코딩·툴 사용·디버깅 성능을 강화한 Claude Sonnet 5를 공개했다. 프로모션 가격은 입력 $2 / 출력 $10 per MTok(2026-08-31 이후 $3/$15로 전환)로, 전작 대비 큰 폭의 가격 인하로 에이전트 워크플로우 원가 절감이 목표다. 이 인하 압박에 OpenAI도 엔터프라이즈 계정 방어를 위한 토큰 가격 대규모 조정을 검토 중인 것으로 알려졌다.

> 💡 **왜 중요한가**: 프론티어 모델의 토큰 단가가 실질적으로 반값으로 내려가면서, 장시간 실행되는 에이전트 파이프라인(리팩터·리서치·QA)이 경제성 임계값을 넘기 시작했다.

### OpenAI GPT-5.6 패밀리 'Sol · Terra · Luna' GA — Sol Ultra는 Codex 클라이언트에 기본 탑재
OpenAI가 GPT-5.6 패밀리(Sol·Terra·Luna)를 일반 공급으로 전환했다. 최상위 모델인 Sol Ultra는 Codex 클라이언트에 기본 라우팅되며, Codex는 시트 요금 없이 완전한 페이-퍼-토큰 과금으로 전환된다. 이와 함께 GPT-5.5·GPT-5.4·Codex가 Amazon Bedrock에서도 GA에 진입해 AWS Commit 사용량으로 차감이 가능해졌다.

> 💡 **왜 중요한가**: 프리미엄 LLM API가 하이퍼스케일러 커밋 예산 안으로 흡수되기 시작했다는 신호 — 조달·법무 검토 없이 기존 클라우드 계약으로 GPT-5.6을 붙일 수 있다는 뜻이다.

### HashiCorp Terraform MCP Server GA — 에이전트가 Registry API를 직접 호출
HashiCorp가 오픈소스 Terraform MCP Server의 정식 GA를 발표했다. 코딩 에이전트가 Terraform Registry API를 직접 조회·조합해 provider 스캐폴딩, 모듈 검색, 상태 조회 같은 반복 작업을 대체할 수 있게 됐다. MCP 표준을 채택한 첫 인프라 벤더 GA 사례로, 에이전트-IaC 통합의 레퍼런스가 될 가능성이 크다.

> 💡 **왜 중요한가**: DevOps 툴체인이 "에이전트가 IDE에서 직접 인프라를 호출"하는 방식으로 재편되고 있다 — Terraform·Kubernetes·클라우드 콘솔 순으로 MCP 어댑터화가 이어질 전망이다.
