### `String.lines()`로 멀티라인 문자열을 줄 단위 스트림으로 처리하기 (Java 11 정식)

`String.lines()`는 문자열을 줄바꿈 기준으로 분리해 `Stream<String>`을 반환하며, `\n`, `\r`, `\r\n` 같은 다양한 줄바꿈 문자를 플랫폼에 의존하지 않고 일관되게 처리합니다. `split("\\n")`이나 `BufferedReader`를 직접 다루는 것보다 짧고, 스트림 연산(`filter`, `map`, `count`)과 자연스럽게 연결됩니다.

```java
String text = "apple\nbanana\r\ncherry\rgrape";
long count = text.lines()
                 .filter(s -> !s.isBlank())
                 .count(); // 4
```

> 💡 **왜 중요한가**: 줄바꿈 처리에서 플랫폼/구분자 차이로 생기는 미묘한 버그를 표준 API 한 줄로 차단할 수 있습니다.

### `CompletableFuture.orTimeout()`으로 비동기 작업에 타임아웃 걸기 (Java 9 정식)

`CompletableFuture.orTimeout(long, TimeUnit)`은 지정된 시간 안에 작업이 완료되지 않으면 `TimeoutException`으로 future를 예외 완료시킵니다. 별도의 `ScheduledExecutorService`를 만들어 타이머를 돌리는 보일러플레이트 없이, 비동기 파이프라인 중간에 체이닝만으로 타임아웃 제약을 추가할 수 있고, 기본값 폴백이 필요하면 `completeOnTimeout(value, ...)`을 함께 쓸 수 있습니다.

```java
CompletableFuture.supplyAsync(() -> callSlowApi())
    .orTimeout(2, TimeUnit.SECONDS)
    .exceptionally(ex -> "fallback");
```

> 💡 **왜 중요한가**: 외부 호출이 무한히 매달려 스레드/리소스를 잠식하는 사고를, 직접 타이머를 짜지 않고도 표준 API로 막을 수 있습니다.
