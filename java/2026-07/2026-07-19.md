### `Stream.toList()`로 스트림 종료 연산의 상용구를 걷어내기 (Java 16 정식)

컬렉션으로 수집할 때 매번 `collect(Collectors.toList())`를 붙일 필요 없이 스트림에 직접 `toList()`를 호출하면 된다. 반환된 리스트는 불변(unmodifiable)이며, `Collectors.toList()`가 돌려주던 수정 가능 리스트와 달리 계약이 명확하다. `null` 원소는 허용된다는 점만 주의하면 대부분의 조회용 파이프라인에서 즉시 대체 가능하다.

```java
List<String> names = users.stream()
        .filter(User::isActive)
        .map(User::name)
        .toList();
```

> 💡 **왜 중요한가**: `Collectors` 임포트와 두 단계 호출이 사라져 파이프라인의 의도가 시각적으로 더 또렷해진다.

### `Predicate.not()`으로 부정 조건을 메서드 참조 문법 그대로 쓰기 (Java 11 정식)

`stream.filter(s -> !s.isBlank())` 같은 표현은 부정을 위해 굳이 람다로 되돌려야 했다. `Predicate.not()`을 정적 임포트하면 메서드 참조를 그대로 유지하면서 부정을 자연스럽게 걸 수 있다. 조건이 복잡해질수록 가독성 차이가 커진다.

```java
import static java.util.function.Predicate.not;

List<String> nonBlank = lines.stream()
        .filter(not(String::isBlank))
        .toList();
```

> 💡 **왜 중요한가**: `!` 하나 때문에 메서드 참조를 람다로 풀어내는 손해를 없애서, 조건식이 코드 리뷰에서 걸리는 마찰을 줄인다.
