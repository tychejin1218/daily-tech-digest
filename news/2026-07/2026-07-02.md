### 1. Anthropic 'Claude Sonnet 5' 정식 출시 — 1M 토큰 컨텍스트 + 128k 출력, 도입가 $2/$10 per MTok
7월 1일 Anthropic이 Claude Sonnet 5(`claude-sonnet-5`)를 공개하며 네이티브 1M 토큰 컨텍스트와 128k 최대 출력을 표준 사양으로 지원한다. Claude Code의 기본 모델로 즉시 승격됐고, GitHub Copilot Pro/Pro+/Max/Business/Enterprise 티어에도 같은 날 롤아웃되어 IDE·CLI에서 바로 선택 가능하다. 프로모션 가격은 8월 31일까지 유효.

> 💡 **왜 중요한가**: Sonnet 등급 모델이 처음으로 1M 컨텍스트를 '기본'으로 들고 나오면서, 리포지토리 전체를 한 번에 넣는 코딩 에이전트 워크플로우가 프리미엄이 아닌 표준 옵션이 됐다.

### 2. Cloudflare Sandboxes·Containers 정식 GA — AI 에이전트 전용 격리 실행 환경 확립
Cloudflare가 Sandboxes와 Containers를 정식 GA로 승격, AI 에이전트 코드 실행용 영구 격리 리눅스 환경을 표준 제품으로 편입했다. egress 프록시 기반 시크릿 주입, PTY 터미널, 영속 코드 인터프리터, 파일시스템 watch, 스냅샷 기반 세션 복구를 기본 제공한다. 또한 Dynamic Workers는 리눅스 컨테이너 대신 isolate로 AI 생성 코드를 실행해 시작·실행이 기존 서버리스 대비 최대 100배 빠르다고 주장한다.

> 💡 **왜 중요한가**: AI 에이전트가 임의 코드를 실행하는 게 일상이 되면서, '격리 실행 환경'이 별도 인프라가 아닌 엣지 플랫폼의 기본 프리미티브로 편입되는 지점을 보여준다.

### 3. Google GKE Labs, 'OpenRL' 오픈소스 공개 — Kubernetes 클러스터에서 LLM 포스트트레이닝을 셀프호스트
Google의 GKE Labs가 OpenRL을 오픈소스로 공개했다. 표준 Kubernetes 클러스터 위에서 LLM 포스트트레이닝·파인튜닝을 셀프호스트 API로 돌릴 수 있게 한 프로젝트로, RLHF·DPO 같은 정책 학습을 사내 GKE로 옮길 수 있는 길을 튼다. 같은 시점 Microsoft도 AKS에 AI 학습/추론 우선 강화 세트를 발표하며 K8s를 AI 워크로드의 1급 런타임으로 재정의하는 흐름이 뚜렷하다.

> 💡 **왜 중요한가**: LLM 학습·튜닝 파이프라인이 매니지드 폐쇄 서비스에서 '자기 Kubernetes 위에서 돌리는 표준 잡'으로 이동 중임을 시사한다 — 데이터 주권과 비용 최적화가 동시에 걸린 흐름.
