### `String.indent()`로 멀티라인 문자열의 들여쓰기를 일괄 조정하기 (Java 12 정식)

여러 줄 문자열의 각 줄 앞에 공백을 추가하거나 제거할 때 `String.indent(int n)`을 사용하면 한 번의 호출로 처리됩니다. 양수면 해당 칸수만큼 들여쓰기를 추가하고, 음수면 들여쓰기를 제거하며, 결과에는 항상 줄바꿈 문자가 정규화되어 포함됩니다.

```java
String code = "public class Hello {\nSystem.out.println(\"hi\");\n}";
String indented = code.indent(4);
// 각 줄 앞에 공백 4칸이 추가되고, 끝에 \n이 보장됨
```

> 💡 **왜 중요한가**: 텍스트 블록이나 로그 출력에서 들여쓰기를 동적으로 제어할 때, `split("\n")` 후 재조립하는 보일러플레이트 없이 가독성 좋은 결과물을 만들 수 있습니다.

### `CompletableFuture.orTimeout()`로 비동기 작업에 타임아웃 강제하기 (Java 9 정식)

`CompletableFuture`가 지정된 시간 안에 완료되지 않으면 `TimeoutException`으로 예외 완료시키는 `orTimeout(long, TimeUnit)` 메서드를 활용할 수 있습니다. 별도의 `ScheduledExecutorService`를 만들어 타임아웃을 관리하던 번거로움 없이, 체인 형태로 자연스럽게 시간 제한을 걸 수 있습니다.

```java
CompletableFuture<String> result = CompletableFuture
    .supplyAsync(() -> callSlowService())
    .orTimeout(3, TimeUnit.SECONDS)
    .exceptionally(ex -> "기본값");

// 또는 타임아웃 시 기본값을 즉시 반환하려면:
.completeOnTimeout("기본값", 3, TimeUnit.SECONDS);
```

> 💡 **왜 중요한가**: 외부 API 호출이나 DB 쿼리처럼 응답 시간이 불확실한 비동기 작업에서 무한 대기를 방지하는 가장 간단한 표준 방법이며, 리소스 누수와 응답성 저하를 동시에 막아줍니다.
