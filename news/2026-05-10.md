### 1. Anthropic, SDK 생성·MCP 서버 빌더 'Stainless' 3억 달러+ 인수 협상 — OpenAI·Google·Meta SDK 인프라까지 흡수

Anthropic이 OpenAI·Google·Meta Llama Stack·Runway가 모두 사용하는 SDK 자동 생성 스타트업 Stainless를 최소 $300M에 인수하는 협상을 진행 중이다 (The Information 5/12 보도, 직전 주 협상). Stainless는 OpenAPI 스펙에서 Python/TS/Kotlin/Go/Java 등 프로덕션 SDK를 AI 컴파일러로 찍어내고, 동시에 외부 API를 에이전트와 연결하는 MCP 서버까지 생성한다. 매주 수백만 개발자가 Stainless 생성 SDK를 다운로드하는 만큼, Anthropic이 경쟁사 개발자 인터페이스 레이어 자체를 장악하게 되는 셈.

> 💡 **왜 중요한가**: 모델 경쟁이 SDK·MCP 서버라는 '에이전트 인터페이스 표준' 레이어로 옮겨가고 있다는 신호다.

### 2. Google Ironwood TPU GA + 8세대 'Sunfish/Zebrafish' 프리뷰 — Anthropic 100만 칩 앵커 계약, 2027년 3.5GW로 확장

Google이 7세대 TPU Ironwood를 Cloud Next에서 GA 전환했다. 칩당 4.6 PFLOPS, 9,216칩 슈퍼팟에서 42.5 EFLOPS, TPU v5p 대비 피크 성능 10배·전성비 4배 개선. 동시에 8세대 듀얼 칩 아키텍처(TPU 8t 'Sunfish' 학습용·TPU 8i 'Zebrafish' 추론용, TSMC 2nm, 2027년 말 양산)도 프리뷰로 공개했다. Anthropic은 2026년 100만 칩(1차 40만 Ironwood = $10B 규모) + 2027년 3.5GW로 확장하는 앵커 고객 계약을 체결했다.

> 💡 **왜 중요한가**: NVIDIA 의존도를 깨려는 LLM 워크로드 흐름이 'TPU 슈퍼팟 단위로 모델사를 통째로 묶는' 다년 계약으로 굳어지고 있다.

### 3. OpenAI 'Daybreak' 사이버보안 이니셔티브 + GPT-5.5-Cyber 공개 — AI 에이전트를 취약점 탐지·검증 파이프라인에 정식 투입

OpenAI가 보안 전문가용 특화 모델 GPT-5.5-Cyber와 함께 사이버보안 이니셔티브 'Daybreak'를 공개했다. Daybreak는 개발자·보안팀이 코드베이스에서 취약점을 식별하고, 패치 후보를 자동 검증하며, SDLC 단계마다 보안 에이전트를 호출하도록 설계됐다. Realtime API GA와 함께 발표된 실시간 음성 모델 3종도 동일한 엔터프라이즈 API 게이트웨이로 합쳐지면서, 'ChatGPT·Codex·Daybreak·Realtime'을 단일 토큰·단일 권한 모델로 호출하는 방향으로 정리되고 있다.

> 💡 **왜 중요한가**: AI 보안이 별도 도구가 아닌 '에이전트가 SDLC 안에서 자동으로 호출하는 LLM 함수'로 자리잡고 있다.
