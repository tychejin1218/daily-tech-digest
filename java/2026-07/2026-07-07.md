### `String.chars()` + `Collectors.groupingBy()`로 문자 빈도수를 한 줄로 집계하기 (Java 8 정식)

문자열의 각 문자 등장 횟수를 세려면 반복문과 `HashMap`을 오가는 코드가 흔했지만, `str.chars()`로 `IntStream`을 얻고 `boxed()` 후 `Collectors.groupingBy(c -> c, Collectors.counting())`로 넘기면 한 줄로 `Map<Integer, Long>`을 만든다. 문자 단위 통계, 빈도 분석, 중복 판정 같은 로직을 함수형 파이프라인으로 간결하게 정리할 수 있다.

```java
String text = "programming";
Map<Character, Long> freq = text.chars()
    .mapToObj(c -> (char) c)
    .collect(Collectors.groupingBy(c -> c, Collectors.counting()));
// {p=1, r=2, o=1, g=2, a=1, m=2, i=1, n=1}
```

> 💡 **왜 중요한가**: 반복문·조건문·임시 맵 없이 문자열 통계를 한 표현식으로 끝낼 수 있어 가독성과 안정성이 동시에 올라간다.

### `Comparator.comparing().thenComparing()`로 다중 정렬 기준을 선언형으로 연결하기 (Java 8 정식)

익명 `Comparator`를 직접 구현하며 `if-else`로 2·3차 정렬 기준을 이어붙이던 코드는 `Comparator.comparing(Person::getLastName).thenComparing(Person::getFirstName).thenComparingInt(Person::getAge)` 형태로 완전히 선언형이 된다. `reversed()`, `nullsFirst()`, `nullsLast()`까지 조합하면 SQL의 `ORDER BY`처럼 정렬 규칙을 조립할 수 있다.

```java
List<Person> people = ...;
people.sort(
    Comparator.comparing(Person::getDepartment)
        .thenComparing(Person::getLastName)
        .thenComparingInt(Person::getAge).reversed()
);
```

> 💡 **왜 중요한가**: 정렬 로직이 데이터 필드 이름의 조합만으로 표현되어, 새로운 기준 추가·변경에 대한 유지보수 비용이 크게 줄어든다.
