### GitHub Universe 2026, 'Copilot Workspaces' GA — 이슈 하나로 멀티 리포 PR 자동 생성

GitHub이 Universe 2026에서 Copilot Workspaces 정식 출시를 발표했다. 이슈 링크만 붙이면 에이전트가 관련 리포지토리를 스캔해 계획·구현·테스트·PR을 병렬로 생성하며, GitHub Actions 시크릿·환경 변수까지 자동 상속받아 실제 CI를 통과한 상태로 리뷰 요청이 올라온다.

> 💡 **왜 중요한가**: "이슈 → PR" 사이의 사람 손이 사라지고 있어, 백엔드 팀 워크플로가 코드 리뷰 중심으로 재편된다.

### Meta, 'Llama 4.5 Maverick-Serve' 발표 — vLLM·SGLang 없이 자체 인퍼런스 런타임 오픈소스화

Meta가 Llama 4.5 Maverick과 함께 자체 서빙 런타임 'Maverick-Serve'를 Apache 2.0으로 공개했다. FP4 KV 캐시 압축과 speculative decoding을 기본 탑재해 H100 8장 기준 400B MoE 모델을 초당 5,200 토큰까지 뽑아내며, OpenAI 호환 API를 그대로 제공해 기존 SDK 코드 수정 없이 교체 가능하다.

> 💡 **왜 중요한가**: 오픈웨이트 모델을 프로덕션에 올릴 때 vLLM 튜닝 부담이 줄어, 사내 LLM 인프라 구축 진입장벽이 크게 낮아진다.

### Vercel, 'AI Gateway v2' 공개 — 200+ 모델을 단일 엔드포인트로, 자동 폴백·비용 상한 내장

Vercel이 AI Gateway v2를 발표하며 Anthropic·OpenAI·Google·Groq·Together 등 200여 개 모델을 하나의 OpenAI 호환 엔드포인트로 통합했다. 팀 단위 월간 비용 상한, 모델별 latency SLO 위반 시 자동 폴백, 프롬프트 캐시 크로스-프로바이더 공유가 기본 활성화되며, `x-vercel-ai-model-override` 헤더로 A/B 테스트도 즉시 가능하다.

> 💡 **왜 중요한가**: 멀티 프로바이더 전략이 SDK 코드가 아닌 게이트웨이 계층으로 내려가면서, 애플리케이션은 모델 벤더 락인에서 자유로워진다.
