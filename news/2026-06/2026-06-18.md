오늘 2026-06-18 기준 백엔드/서버/클라우드/AI 관련 IT 뉴스 3가지입니다.

### 1. Google Gemini CLI, 오늘부로 서비스 종료 — 모든 개인 개발자 Antigravity CLI로 이관
오늘(6/18) Google이 무료·AI Pro·AI Ultra 사용자를 대상으로 한 Gemini CLI 및 Gemini Code Assist IDE 익스텐션을 정식 종료했다. 대체 플랫폼인 Go 기반 **Antigravity CLI**는 비동기 백그라운드 워크플로, 멀티에이전트 오케스트레이션을 지원하며 Agent Skills·Hooks·Subagents·Extensions(이제는 Antigravity 플러그인)를 그대로 유지한다. Gemini Code Assist Standard/Enterprise 라이선스 또는 유료 Gemini API 키 사용자는 영향을 받지 않는다.

> 💡 **왜 중요한가**: 터미널·IDE 기반 AI 코딩 도구 시장이 '단일 CLI'에서 '에이전트 하니스 + 비동기 멀티에이전트' 아키텍처로 이동했음을 보여주는 분수령이다.

### 2. Oracle, AWS 콘솔에서 'Autonomous AI Database Serverless' 정식 GA — AWS 약정 크레딧으로 결제 가능
6월 17일 Oracle은 Oracle AI Database@AWS의 일부로서 **Autonomous AI Database Serverless(ADB-S)**의 일반 공개(GA)를 발표했다. 고객은 AWS 콘솔에서 직접 완전 자율형 Oracle AI DB를 프로비저닝하고, 기존 AWS 예약 크레딧으로 사용량을 결제할 수 있다. 벡터 검색·임베딩·에이전트 상태 저장을 통합 처리하는 'AI 네이티브 DB' 포지션으로, Microsoft HorizonDB·Databricks Lakebase와의 정면 충돌이 본격화됐다.

> 💡 **왜 중요한가**: 'AWS 청구서 한 장으로 멀티벤더 AI DB 결제'가 가능해지면서, 하이퍼스케일러 락인보다 결제 통합·거버넌스가 새로운 차별화 축으로 떠올랐다.

### 3. Zilliz Vector Lakebase 퍼블릭 프리뷰 — 벡터 DB와 데이터 레이크 단일 기반 통합
6월 10일 Zilliz는 세계에서 가장 많이 채택된 벡터 DB Milvus의 클라우드 후속작인 **Vector Lakebase** 퍼블릭 프리뷰를 공개했다. 단일 데이터 기반 위에서 (1) 실시간 벡터 검색, (2) 대규모 배치 분석, (3) 외부 데이터 레이크 직접 검색을 동시에 지원하는 게 핵심으로, 별도 ETL 없이 에이전트가 라이브 RAG·이력 분석·외부 소스 검색을 한 엔진에서 처리할 수 있다.

> 💡 **왜 중요한가**: '벡터 DB는 별도 사일로' 시대가 끝나고, 레이크하우스에 직접 임베딩·검색·에이전트 상태가 흡수되는 통합 패턴이 표준이 되고 있다.
