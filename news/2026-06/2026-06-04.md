### Microsoft, 첫 자체 추론 모델 'MAI Thinking-1' 공개 — SWE Bench Pro에서 Claude Opus 4.6과 동급
Microsoft Build 2026에서 발표된 MAI Thinking-1은 자사 첫 추론 특화 모델로, 코딩 벤치마크 SWE Bench Pro에서 Anthropic Claude Opus 4.6과 동등한 성능을 기록했다. 함께 공개된 MAI-Code-1-Flash는 자연어 설명으로부터 앱·웹 소스코드를 생성하는 인하우스 모델이다.

> 💡 **왜 중요한가**: Microsoft가 OpenAI 의존도를 줄이며 자체 프런티어급 코딩·추론 모델을 확보했다는 것은, Azure 위에서 돌아가는 엔터프라이즈 AI 스택의 경제성과 협상력 지형이 다시 바뀐다는 신호다.

### OpenAI Codex, AWS Bedrock에서 정식 GA — 상용·GovCloud 리전 동시 지원
OpenAI의 프런티어 모델과 Codex 코딩 에이전트가 Amazon Bedrock을 통해 상용 리전과 GovCloud 리전에서 동시에 정식 출시됐다. AWS 네이티브 보안·거버넌스·조달·과금·컴플라이언스 통제 위에서 운영할 수 있어, 공공·규제 산업이 OpenAI 모델을 프로덕션에 투입하는 길이 열렸다.

> 💡 **왜 중요한가**: OpenAI 모델을 AWS의 IAM·VPC·KMS·BAA 안에서 호출할 수 있다는 건, 그동안 Azure로만 흐르던 엔터프라이즈 OpenAI 수요가 멀티클라우드로 분산되는 결정적 분기점이다.

### Microsoft 'Project Rayfin' 프리뷰 — GitHub 워크플로 기반 Fabric BaaS로 프로토타입→프로덕션 간극 해소
Project Rayfin은 Microsoft Fabric 위에 얹은 매니지드 백엔드(BaaS)로, GitHub에서 정의한 워크플로를 그대로 운영 환경에 배포하도록 설계됐다. 별도로 발표된 Microsoft IQ는 GitHub Copilot·Foundry·Copilot Studio용 컨텍스트 레이어이며, Work IQ는 6월 16일 GA로 M365 이메일·회의 데이터를 에이전트에 노출한다.

> 💡 **왜 중요한가**: 에이전트가 "코드만 짜는" 단계를 넘어 데이터·인증·트리거를 포함한 매니지드 백엔드 위에서 실행되는 구조로 이동하고 있어, 향후 BaaS와 에이전트 런타임의 경계가 사실상 사라질 전망이다.
