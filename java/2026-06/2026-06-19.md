### `Files.mismatch()`로 두 파일의 내용이 동일한지 빠르게 비교하기 (Java 12 정식)
두 파일이 바이트 단위로 같은지 확인할 때 직접 스트림을 열어 비교하는 대신 `Files.mismatch(Path, Path)` 한 줄로 끝낼 수 있습니다. 동일하면 `-1L`을, 다르면 처음으로 어긋난 바이트의 위치를 반환하므로 단순 동등 비교뿐 아니라 어디부터 달라졌는지 진단에도 활용 가능합니다.

```java
long pos = Files.mismatch(Path.of("a.bin"), Path.of("b.bin"));
if (pos == -1L) {
    System.out.println("두 파일은 동일합니다");
} else {
    System.out.println(pos + " 바이트 위치부터 다릅니다");
}
```

> 💡 **왜 중요한가**: 백업 검증·중복 파일 탐지·테스트 산출물 비교 같은 흔한 작업을 외부 라이브러리 없이 표준 API로 안전하게 처리할 수 있습니다.

### `String.formatted()`로 포맷 문자열을 자연스러운 메서드 체인으로 작성하기 (Java 15 정식)
`String.format("Hello, %s! You are %d.", name, age)` 처럼 정적 메서드를 호출하던 패턴을 `"Hello, %s! You are %d.".formatted(name, age)` 형태의 인스턴스 메서드로 바꿀 수 있습니다. 특히 텍스트 블록(`"""`)과 결합하면 멀티라인 템플릿을 그대로 두고 끝에 `.formatted(...)`만 붙이면 되어 가독성이 크게 좋아집니다.

```java
String sql = """
        SELECT id, name
          FROM users
         WHERE status = '%s'
           AND age >= %d
        """.formatted("ACTIVE", 18);
```

> 💡 **왜 중요한가**: 포맷 대상 문자열이 코드의 앞이 아닌 뒤에 자연스럽게 위치하게 되어, 긴 템플릿을 다룰 때 변수와 포맷 지정자를 한 흐름으로 읽을 수 있습니다.
