# 2026-06-24 백엔드/클라우드/AI 최신 뉴스

### AWS Lambda MicroVMs 공개 — AI 생성 코드 격리 실행용 서버리스 샌드박스
AWS가 6월 22일 Lambda MicroVMs를 정식 출시했다. Firecracker 기반 VM 수준 격리에 최대 8시간 런타임, 메모리·디스크 상태를 보존한 일시 중단/재개, 무중단 시 자동 슬립까지 지원하며 AI가 생성한 코드를 안전하게 실행하거나 강화학습 에이전트 환경으로 쓰도록 설계됐다. 현재 US East/West·도쿄·아일랜드 리전에서 Graviton(Arm) 인스턴스로만 제공된다.

> 💡 **왜 중요한가**: 프롬프트 인젝션·악성 출력 위험이 있는 LLM 생성 코드를 "쓰고 버리는 VM"으로 처리하는 표준 인프라가 생겼다는 의미다.

### Vercel Eve 출시 — 디렉터리 = 에이전트인 오픈소스 TypeScript 프레임워크
Vercel이 6월 17일 런던 Ship 26 컨퍼런스에서 오픈소스 에이전트 프레임워크 Eve를 공개했다. 에이전트 하나가 "파일 디렉터리"로 정의되고 빌드 시 Vercel Functions 위에 durable execution·샌드박스 컴퓨트·OpenTelemetry 관측이 기본 포함된 프로덕션 서비스로 컴파일된다. Vercel 자체 프로덕션 플릿에서 검증된 동일 런타임을 외부에 개방한 것이 특징이다.

> 💡 **왜 중요한가**: "에이전트 코드 = 일반 함수 배포"라는 단순화로, 별도 에이전트 오케스트레이션 인프라 없이 Next.js 팀이 그대로 에이전트를 운영할 수 있게 됐다.

### Snowflake CoCo, Claude Code·VS Code·Excel까지 확장 — 엔터프라이즈 코딩 에이전트 본격화
Snowflake Summit 26에서 발표된 CoCo(구 Cortex Code)가 6월 들어 데스크톱 네이티브 앱·모바일·Slack 봇은 물론 VS Code, Excel, Anthropic Claude Code 확장으로 출하 채널을 넓혔다. 자율 Cloud Agents가 워크플로 자동화·앱 배포까지 수행하며, dbt ADE-Bench에서 72.1%로 Claude Code·OpenAI Codex(65.1%)를 앞섰다고 자체 측정치를 공개했다. Fanatics·Thomson Reuters·WHOOP가 초기 도입사로 이름을 올렸다.

> 💡 **왜 중요한가**: 데이터 웨어하우스 벤더가 IDE·Slack까지 침투하면서, 엔터프라이즈 코딩 에이전트의 시작점이 "데이터가 사는 곳"으로 이동하고 있다.
