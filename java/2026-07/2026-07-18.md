### `Optional.stream()`으로 `Optional`을 스트림 파이프라인에 자연스럽게 흘려보내기 (Java 9 정식)
`Optional<T>`를 반환하는 메서드를 스트림에서 사용할 때 `filter(Optional::isPresent).map(Optional::get)` 패턴을 반복하게 되는데, `Optional.stream()`은 값이 있으면 원소 1개, 없으면 빈 스트림을 돌려주므로 `flatMap(Optional::stream)` 한 줄로 언팩과 필터링을 동시에 처리할 수 있습니다. `findFirst()`나 저장소 조회처럼 `Optional`을 반환하는 API를 여러 개 연쇄할 때 특히 깔끔해집니다.

```java
List<User> users = ids.stream()
    .map(repository::findById)   // Stream<Optional<User>>
    .flatMap(Optional::stream)   // Stream<User> — 존재하는 값만
    .toList();
```

> 💡 **왜 중요한가**: `isPresent`/`get` 이중 호출을 없애 `Optional` 남용의 대표적인 안티패턴을 표준 API 한 줄로 대체할 수 있습니다.

### `Pattern Matching for switch`로 타입 분기 로직을 표현식으로 압축하기 (Java 21 정식)
전통적인 `instanceof` 체인과 캐스팅을 반복하던 타입 분기 코드를 `switch` 표현식과 패턴, `when` 가드까지 결합해 단일 표현식으로 작성할 수 있습니다. `sealed` 인터페이스와 함께 쓰면 컴파일러가 모든 하위 타입 분기가 있는지 exhaustiveness까지 검사해 `default` 없이도 안전한 분기를 강제합니다.

```java
sealed interface Shape permits Circle, Rectangle, Triangle {}

double area(Shape shape) {
    return switch (shape) {
        case Circle c        -> Math.PI * c.radius() * c.radius();
        case Rectangle r when r.width() == r.height()
                             -> r.width() * r.width();
        case Rectangle r     -> r.width() * r.height();
        case Triangle t      -> 0.5 * t.base() * t.height();
    };
}
```

> 💡 **왜 중요한가**: 캐스팅 보일러플레이트를 없애면서도 컴파일 타임에 분기 누락을 잡아주어, 도메인 타입이 늘어날 때 발생하는 런타임 버그를 원천 차단합니다.
