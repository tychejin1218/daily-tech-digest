### `Files.mismatch()`로 두 파일의 내용 차이 위치를 표준 API로 찾기 (Java 12 정식)

두 파일을 바이트 단위로 비교해 처음으로 다른 지점의 인덱스를 반환하고, 완전히 동일하면 `-1L`을 돌려준다. 기존에는 스트림을 열어 직접 순회하거나 해시를 계산해야 했지만, 이제 한 줄로 대용량 파일 비교가 가능하다.

```java
long diffIndex = Files.mismatch(Path.of("a.bin"), Path.of("b.bin"));
if (diffIndex == -1L) {
    System.out.println("두 파일은 동일합니다");
} else {
    System.out.println(diffIndex + " 바이트 위치에서 최초 차이 발견");
}
```

> 💡 **왜 중요한가**: 파일 동일성 검증과 차이 지점 추적을 외부 라이브러리 없이 표준 NIO API로 처리할 수 있다.

### `Character.isEmoji()` 계열 메서드로 이모지 판별을 표준 API로 처리하기 (Java 21 정식)

문자열에서 이모지를 걸러내거나 카운팅할 때 유니코드 범위를 하드코딩하지 않고 `Character.isEmoji(int codePoint)`, `isEmojiPresentation()`, `isEmojiModifier()` 등을 사용할 수 있다. 코드 포인트 기반이므로 서로게이트 페어 이모지도 안전하게 처리된다.

```java
String text = "Hello 👋 World 🌍!";
long emojiCount = text.codePoints()
    .filter(Character::isEmoji)
    .count();
System.out.println("이모지 개수: " + emojiCount); // 2
```

> 💡 **왜 중요한가**: 채팅·SNS·리뷰 텍스트 처리에서 이모지 판별을 유니코드 표준(UTS #51)에 정확히 맞춘 API로 안전하게 수행할 수 있다.
