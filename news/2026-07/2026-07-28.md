### JetBrains Junie 1.0 정식 출시 — IntelliJ 통합 자율 코딩 에이전트, 프로젝트 전역 리팩토링 지원
JetBrains가 자체 개발한 AI 코딩 에이전트 Junie 1.0을 IntelliJ 플랫폼(IDEA, PyCharm, WebStorm 등) 2026.2 버전과 함께 정식 출시했다. 기존 AI Assistant가 인라인 보완 위주였다면, Junie는 이슈 티커나 자연어 지시를 받아 프로젝트 전역에서 파일을 열고 편집·테스트·커밋까지 수행하는 자율 모드가 핵심이다. 로컬 인덱싱과 정적 분석 결과를 컨텍스트로 활용해 대규모 모노레포에서도 심볼 참조·타입 추론 기반 리팩토링 품질을 유지한다고 발표했다.

> 💡 **왜 중요한가**: IDE 벤더가 직접 제공하는 에이전트는 언어 서버·정적 분석 인프라를 그대로 활용할 수 있어, 외부 CLI 에이전트와 차별화된 정확도·안전성을 확보한다.

### NVIDIA NIM 2.0 GA — LLM을 표준 마이크로서비스로 배포, K8s 오토스케일 & 멀티테넌시 내장
NVIDIA가 추론 마이크로서비스 프레임워크 NIM(NVIDIA Inference Microservices) 2.0을 정식 출시했다. Llama, Mistral, Qwen 등 오픈웨이트 모델은 물론 커스텀 파인튜닝 모델도 OCI 호환 컨테이너 이미지 한 개로 패키징돼 어떤 K8s 클러스터에도 배포 가능하며, TensorRT-LLM 최적화가 자동 적용된다. 신규 기능으로 GPU 파티션 기반 멀티테넌시, KV 캐시 공유, 토큰 단위 사용량 미터링 API가 추가돼 사내 LLM 게이트웨이 구축이 단순해졌다.

> 💡 **왜 중요한가**: 자체 LLM 인프라를 운영하는 조직이 늘면서 '컨테이너 배포 → K8s 오토스케일'이라는 익숙한 패턴으로 LLM을 다룰 수 있게 됐고, 클라우드 LLM API 종속성을 낮추는 흐름이 가속화된다.

### Modal Labs 'Agent Sandbox' GA — AI 에이전트 코드 실행용 격리 런타임, 콜드스타트 300ms
서버리스 GPU 플랫폼 Modal이 AI 에이전트가 생성한 코드를 안전하게 실행하기 위한 전용 격리 런타임 'Agent Sandbox'를 정식 출시했다. 각 세션은 gVisor 기반 마이크로VM으로 격리되고, 파일 시스템·네트워크·GPU 접근을 세밀하게 정책으로 통제할 수 있으며 콜드스타트 300ms를 광고한다. Python SDK로 `sandbox.exec()` 한 줄이면 되며, MCP 서버 프로토콜을 네이티브로 지원해 Claude·GPT·Gemini 계열 에이전트와 즉시 연동된다.

> 💡 **왜 중요한가**: LLM 에이전트가 실제 코드를 실행해야 하는 워크로드가 폭증하면서, '샌드박스 프로비저닝 지연'이 에이전트 응답 시간의 최대 병목이 되었고 이를 300ms대로 압축한 것은 실시간 에이전트 UX의 게임체인저다.
