### PostgreSQL `TABLESAMPLE` — 수억 행 테이블에서 통계·A/B 검증용 표본을 초 단위로 뽑기

`SELECT ... FROM orders TABLESAMPLE SYSTEM (1)`은 8KB 페이지 단위로 약 1%를 임의 추출해 전체 스캔 없이 즉시 결과를 돌려준다. 페이지 편향이 부담이면 `BERNOULLI (1)`로 행 단위 추출을 쓰고, `REPEATABLE (42)` 시드를 붙이면 동일한 표본을 재현할 수 있어 대시보드·리포트 캐싱에도 유용하다.

```sql
SELECT AVG(total_amount)
FROM orders TABLESAMPLE BERNOULLI (1) REPEATABLE (42)
WHERE created_at >= '2026-07-01';
```

> 💡 **왜 중요한가**: `LIMIT`과 달리 통계적으로 균등한 표본이라, 수억 행 테이블의 분포·평균을 초 단위로 근사할 수 있다.

### MySQL `Descending Index` — `ORDER BY a ASC, b DESC` 혼합 정렬을 인덱스로 끝내기

MySQL 8.0부터 인덱스 정의에 컬럼별 방향(`ASC`/`DESC`)을 지정할 수 있어, `ORDER BY a ASC, b DESC` 같은 혼합 정렬을 `filesort` 없이 인덱스 순회만으로 처리한다. 이전 버전에서는 방향 지정을 파싱은 했지만 무시했기 때문에, 반대 방향 정렬은 항상 정렬 연산이 추가로 발생했다.

```sql
CREATE INDEX idx_feed ON posts (user_id ASC, created_at DESC);
-- ORDER BY user_id ASC, created_at DESC LIMIT 20  → Using index, filesort 없음
```

> 💡 **왜 중요한가**: 피드·랭킹 화면처럼 정렬 방향이 섞이는 페이지네이션에서 `filesort`를 제거해 응답 시간을 한 자릿수 ms로 낮춘다.
