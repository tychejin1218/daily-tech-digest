### Anthropic 'Claude Platform on AWS' 정식 출시 — AWS IAM·CloudTrail·단일 청구로 네이티브 Claude 스택 흡수 (5/11)
Anthropic이 자사 네이티브 Claude Platform 전체(Managed Agents, Skills, Files API, MCP Connector, Code Execution, 프롬프트 캐싱, 배치 등)를 AWS 계정 내에서 별도 자격 증명·계약 없이 호출할 수 있는 'Claude Platform on AWS'를 GA로 공개했다. 인증은 AWS IAM, 감사는 CloudTrail, 결제는 단일 AWS 인보이스로 통합되며 기존 AWS Commitment를 그대로 차감한다 — Bedrock과 달리 서비스 운영 주체는 Anthropic 본사이고 데이터는 AWS 보안 경계 밖에서 처리된다는 점이 핵심 차별점이다.

> 💡 **왜 중요한가**: Bedrock의 'AWS-운영 Claude'와 본사 직결 'Anthropic-운영 Claude'가 한 AWS 청구서로 합쳐지면서, 엔터프라이즈는 거버넌스·재무 절차를 깨지 않고도 Claude의 최신 에이전트·Skills 스택을 곧바로 도입할 수 있게 됐다.

### OpenAI Realtime API GA — GPT-Realtime-2·Translate·Whisper 동시 출시, 컨텍스트 32K→128K로 확대 (5/7~8)
OpenAI가 Realtime API를 베타에서 GA로 승격하며 GPT-5급 추론을 음성에 이식한 'GPT-Realtime-2', 70개 입력·13개 출력 언어 실시간 통역의 'GPT-Realtime-Translate', 스트리밍 STT의 'GPT-Realtime-Whisper' 3종을 동시에 공개했다. GPT-Realtime-2의 컨텍스트가 32K → 128K 토큰으로 4배 늘어나면서 외부 상태 스티칭 없이 장시간 음성 에이전트 세션을 유지할 수 있게 됐고, Translate·Whisper는 분당 과금, Realtime-2는 토큰 과금으로 분리됐다.

> 💡 **왜 중요한가**: '음성 + 추론 + 다국어 통역'이 단일 Realtime 엔드포인트로 묶이면서, 별도 STT·MT·LLM 파이프라인을 운영하던 백엔드 팀은 인프라 3단을 하나의 스트리밍 API로 압축할 수 있게 됐다.

### Anthropic 'Dreaming' 리서치 프리뷰 — Claude Managed Agents가 잠든 사이 스스로 메모리를 정제 (5/6, Code with Claude 2026)
Anthropic이 Claude Managed Agents에 'Dreaming' 기능을 리서치 프리뷰로 도입했다. 모델 가중치를 건드리지 않고 스케줄링된 백그라운드 잡이 과거 세션·메모리 스토어를 훑어 반복 실수·합류된 워크플로·팀 단위 선호도를 패턴화한 뒤 메모리를 자동(또는 사람 검토 후) 갱신한다. 함께 'Outcomes(루브릭 기반 평가)'와 멀티 에이전트 오케스트레이션이 리서치 프리뷰 → 퍼블릭 베타로 승격됐고, Harvey는 작업 완료율 약 6배, Wisedocs는 문서 리뷰 시간 50% 단축, Netflix는 수백 빌드 로그를 멀티 에이전트로 동시 처리 중이라고 공개됐다.

> 💡 **왜 중요한가**: 파인튜닝 없이 운영 중인 에이전트가 자기 로그만으로 점진 개선되는 패턴이 표준화되면, '메모리 관리'가 에이전트 운영의 새로운 1급 책임 영역(=비용·감사 항목)이 된다.
