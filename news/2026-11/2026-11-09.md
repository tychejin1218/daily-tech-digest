### 1. Mistral 'Large 4 (Le Chonk)' 오픈 웨이트 Hugging Face 공개 — 1T 파라미터 프런티어 모델이 셀프호스팅 영토로 넘어왔다, '유럽發 오픈 코딩 에이전트'가 처음으로 GLM-5.3를 이겼다
프랑스 Mistral AI가 10월 29일 트릴리언 파라미터 'Mistral Large 4(코드명 Le Chonk)' 가중치를 FP8·NVFP4 체크포인트로 허깅페이스에 공개했고, 11월 9일 현재 Artificial Analysis Coding Agent Index에서 모든 오픈 모델 중 1위를 유지하고 있다. MoE 아키텍처로 활성 파라미터 49B만 돌려 서빙 비용을 억눌렀고, 중국 GLM-5.3 대비 토큰을 47% 적게 쓰면서 동률 48점을 찍었다. Terminal-Bench 4.0에서 41%를 기록해 사이버·터미널 에이전틱 코딩 영역에서도 상위권에 안착했다.

> 💡 **왜 중요한가**: '오픈 웨이트는 에이전틱 코딩을 못 한다'는 통념이 유럽發 모델에 의해 깨졌고, 사이버보안·주권 AI를 명분으로 셀프호스팅 프런티어 에이전트의 디폴트 옵션이 Qwen/DeepSeek 외에 하나 더 늘어났다.

### 2. Google 'Gemini Omni 1.2 Flash' GA — 비디오 생성 API가 15초·4K·오디오 동기 트랙까지 삼켰다, 'LLM API'가 '멀티모달 생성 API'로 사일런트 피봇했다
구글이 11월 5일 Gemini Omni 1.2 Flash를 Gemini API·Vertex AI에서 GA로 풀고, 720p 초당 $0.07로 전 세대 대비 가격을 30% 떨어뜨렸다. 비디오 생성 길이가 10초→15초로 늘었고 최대 4K 해상도를 지원하며, 동기화된 오디오 트랙과 SynthID 워터마크가 기본 삽입된다. 영상·음성·텍스트가 한 호출의 산출물로 묶이면서 백엔드가 비디오 생성을 단일 REST 콜로 처리할 수 있게 됐다.

> 💡 **왜 중요한가**: '텍스트/코드 LLM API'와 '영상 생성 모델'의 가격 곡선이 수렴하면서, 멀티모달 생성 API가 LLM API의 하위 집합으로 묶이는 전환점 — 백엔드가 MP4 파이프라인을 따로 짤 이유가 사라진다.

### 3. Hume 'Audio Decision API' 베타 공개 — 오디오를 '질문-답변 프로브'로 다루는 네이티브 모델이 등장했다, STT→LLM 2단 파이프라인이 통째로 1홉이 됐다
Hume AI가 11월 2일 오디오 네이티브 디시전 API를 웨이트리스트로 공개했다. 개발자가 오디오 클립과 질문(Yes/No·객관식·스케일·타임스탬프)을 던지면 모델이 확률 분포로 답하는 구조로, 초기 평가에서 인간 패널 평균 판단과 70.7% 일치(개별 평가자 기준 56.5%)를 기록했다. 톤·휴지·끼어들기 같은 비언어적 신호를 원시 오디오에서 직접 읽어내, 전사본으로는 구분이 안 되던 자신 있는 "sure"와 망설이는 "…sure"를 분리한다.

> 💡 **왜 중요한가**: 콜센터 QA·면접 분석·고객 감정 분류처럼 '음성 → STT → LLM → 분류'로 짜던 백엔드 파이프라인이 단일 API 호출로 접히면서, 전사 손실·레이턴시·2중 비용이 동시에 사라진다.
