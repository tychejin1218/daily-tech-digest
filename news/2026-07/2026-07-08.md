### xAI Grok 4.5 출시 — 1.5조 파라미터, 코딩 인터랙션 데이터 대량 학습

xAI가 7월 8일 Grok 4.5를 공개했다. 1.5조 파라미터 규모로 학습 데이터에 실제 코딩 상호작용 기록을 대량 포함시켜 리팩터링·디버깅 같은 반복 대화형 개발 작업에서 정확도를 끌어올렸으며, X 플랫폼과 xAI API 양쪽에서 즉시 접근 가능하다.

> 💡 **왜 중요한가**: 파라미터 스케일 경쟁이 코딩 특화 데이터 큐레이션 경쟁으로 이동하고 있음을 보여주는 신호탄이다.

### Anthropic Claude Cowork 정식 공개 — 오프라인에서도 지속되는 장기 실행 에이전트

7월 7일 Anthropic이 이메일·캘린더·파일 작업을 백엔드에서 대신 수행하는 Cowork를 공개했다. 사용자의 디바이스가 오프라인이거나 종료된 상태에서도 태스크가 서버 측에서 계속 실행되며, MCP 프로토콜을 통해 Gmail·Notion·Linear 등 외부 도구와 상태를 공유하는 지속형(persistent) 에이전트 런타임을 채택했다.

> 💡 **왜 중요한가**: LLM 에이전트가 세션 단위 요청-응답에서 벗어나 서버 사이드 워크플로우 실행자로 자리 잡는 전환점이다.

### Huawei CodeArts Agent 오픈 베타 — 프로젝트 레벨 자율 개발 겨냥

Huawei Cloud가 IDE 통합·프로젝트 단위 코드 생성·R&D 지식 Q&A를 결합한 CodeArts Agent 오픈 베타를 시작했다. 리포지토리 전체를 컨텍스트로 잡아 다중 파일 수정과 테스트 시나리오 자동 생성을 수행하며, HarmonyOS·Ascend NPU 배포 파이프라인과 사전 통합되어 있어 중국 클라우드 시장의 에이전트 IDE 경쟁이 본격화됐다.

> 💡 **왜 중요한가**: Cursor·Antigravity로 이어져 온 에이전트 IDE 시장에 아시아권 하이퍼스케일러가 자체 스택으로 정면 진입했다.
