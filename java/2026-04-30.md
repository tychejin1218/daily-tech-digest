### 1. Record Patterns로 중첩된 데이터 구조를 한 번에 분해(Deconstruct)하기 (Java 21 정식)

`record Point(int x, int y)`나 `record Line(Point from, Point to)` 같은 레코드를 `instanceof`나 `switch`에서 `case Line(Point(var x1, var y1), Point(var x2, var y2))`처럼 중첩 패턴으로 분해할 수 있습니다. 별도의 게터 호출이나 임시 변수 없이 필드를 바로 바인딩할 수 있어, DTO·AST·트리 구조를 다루는 코드가 함수형 언어처럼 간결해집니다. `var`를 함께 쓰면 타입 추론까지 적용되어 보일러플레이트가 더욱 줄어듭니다.

> 💡 **왜 중요한가**: Sealed 인터페이스 + 레코드 + 패턴 매칭 조합으로 ADT(대수적 데이터 타입) 스타일의 안전한 분기 로직을 Java에서도 본격적으로 표현할 수 있습니다.

### 2. JFR(Java Flight Recorder)로 운영 환경에서 저오버헤드 성능 프로파일링하기

JFR은 JDK에 내장된 프로파일러로, `-XX:StartFlightRecording=duration=60s,filename=app.jfr` 같은 옵션이나 `jcmd <pid> JFR.start` 명령으로 운영 중인 JVM의 GC, 스레드, 락 경합, 메모리 할당, I/O 이벤트를 1% 미만 오버헤드로 수집합니다. 결과 `.jfr` 파일은 JDK Mission Control(JMC)에서 시각화하거나, Java 16+의 `jdk.jfr.consumer.RecordingFile` API로 직접 파싱해 자동화된 분석 파이프라인에 연결할 수 있습니다.

> 💡 **왜 중요한가**: 별도 에이전트 없이 프로덕션에서 안전하게 켤 수 있어, 재현이 어려운 성능 이슈와 메모리 누수의 근본 원인을 사후에도 추적할 수 있습니다.
