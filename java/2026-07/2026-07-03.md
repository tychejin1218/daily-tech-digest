### `Records`로 불변 DTO의 보일러플레이트 제거하기 (Java 16 정식)
`record` 키워드 한 줄이면 필드·생성자·`equals`/`hashCode`/`toString`·접근자까지 컴파일러가 자동 생성한다. 값을 실어 나르는 용도의 클래스에서 수십 줄짜리 Lombok/getter 코드를 통째로 지울 수 있고, 컴팩트 생성자로 유효성 검증까지 붙일 수 있다.

```java
public record Money(BigDecimal amount, Currency currency) {
    public Money {
        Objects.requireNonNull(amount);
        if (amount.signum() < 0) throw new IllegalArgumentException("음수 금액 불가");
    }
}
```

> 💡 **왜 중요한가**: "값을 담기만 하는 클래스"의 실수 여지(가변 필드, 누락된 `equals`)를 언어 차원에서 봉쇄한다.

### `HttpClient`로 `HttpURLConnection`을 놓아주기 (Java 11 정식)
`java.net.http.HttpClient`는 HTTP/2·비동기·타임아웃·리다이렉트 정책을 표준 API로 제공한다. `HttpURLConnection`의 지저분한 스트림 처리나 서드파티 라이브러리(OkHttp, Apache HttpClient) 없이도 요청 한 방을 깔끔하게 표현할 수 있다.

```java
HttpClient client = HttpClient.newBuilder()
    .connectTimeout(Duration.ofSeconds(5))
    .followRedirects(HttpClient.Redirect.NORMAL)
    .build();

HttpResponse<String> res = client.send(
    HttpRequest.newBuilder(URI.create("https://api.example.com/users"))
        .timeout(Duration.ofSeconds(3))
        .header("Accept", "application/json")
        .GET()
        .build(),
    HttpResponse.BodyHandlers.ofString());
```

> 💡 **왜 중요한가**: 표준 라이브러리만으로 HTTP/2·비동기·타임아웃까지 처리되어, 외부 의존성과 커스텀 래퍼를 함께 걷어낼 수 있다.
