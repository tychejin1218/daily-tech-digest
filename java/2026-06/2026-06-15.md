### `StructuredTaskScope`로 여러 비동기 작업을 한 단위로 묶어 관리하기 (Java 21 프리뷰)

`StructuredTaskScope`는 여러 가상 스레드 작업을 하나의 구조화된 단위로 묶어 관리할 수 있게 해주는 구조적 동시성(Structured Concurrency) API입니다. `ShutdownOnFailure` 정책을 쓰면 하위 작업 중 하나라도 실패하면 나머지를 자동으로 취소해주고, `ShutdownOnSuccess`는 가장 빨리 성공한 결과를 반환합니다. try-with-resources로 스코프를 감싸면 부모 스코프가 닫힐 때까지 모든 자식 작업의 생명주기가 보장됩니다.

```java
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    Subtask<User> user = scope.fork(() -> findUser(userId));
    Subtask<Order> order = scope.fork(() -> findOrder(orderId));

    scope.join().throwIfFailed();
    return new Response(user.get(), order.get());
}
```

> 💡 **왜 중요한가**: 기존 `CompletableFuture` 조합은 한쪽이 실패해도 다른 쪽이 계속 실행되어 리소스가 새는 문제가 있었는데, 구조적 동시성은 작업의 시작과 종료를 코드 블록 범위와 일치시켜 누수와 좀비 스레드를 원천 차단합니다.

### `Stream.gatherers()`로 커스텀 중간 연산을 직접 정의하기 (Java 24 정식)

Java 22에서 프리뷰로 도입되어 Java 24에 정식 채택된 `Gatherer`는 스트림의 중간 연산을 사용자가 직접 정의할 수 있게 해주는 확장 포인트입니다. 기존에는 sliding window, scan, fold 같은 연산을 만들려면 외부 라이브러리에 의존하거나 `collect()` 이후 후처리를 해야 했는데, `Gatherers.windowFixed(n)`, `windowSliding(n)`, `scan()`, `fold()` 같은 내장 게더러로 깔끔하게 처리할 수 있습니다.

```java
// 3개씩 묶어 슬라이딩 윈도우로 이동 평균 계산
List<Double> movingAvg = Stream.of(1, 2, 3, 4, 5, 6)
    .gather(Gatherers.windowSliding(3))
    .map(window -> window.stream().mapToInt(Integer::intValue).average().orElse(0))
    .toList();
```

> 💡 **왜 중요한가**: `Collectors`가 종단 연산의 확장점이라면 `Gatherer`는 중간 연산의 확장점으로, 그동안 표현하기 어렵던 상태 기반 변환을 표준 API만으로 선언적으로 작성할 수 있게 되었습니다.
