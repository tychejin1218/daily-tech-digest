### OpenAI 'Codex for (Almost) Everything' 데스크톱 대규모 업데이트 — Computer Use·인앱 브라우저·SSH·90+ 플러그인 탑재

4월 16일 OpenAI가 Codex 데스크톱 앱을 풀 워크스페이스로 재편했다. macOS 화면을 직접 제어하는 Computer Use, 로컬 개발 서버를 열어 DOM 검사·스크린샷·패치 검증까지 수행하는 네이티브 인앱 브라우저, 클라우드 devbox용 SSH, Atlassian Rovo·CircleCI·CodeRabbit·GitLab Issues·Render 등 90여 개 신규 플러그인, gpt-image-1.5 기반 이미지 생성이 한꺼번에 들어갔다. 여러 에이전트를 병렬로 돌려도 포그라운드 작업을 침범하지 않도록 커서 격리를 적용한 점이 특징이다.

> 💡 **왜 중요한가**: 코딩 에이전트가 IDE 안이 아니라 OS 전체를 무대로 삼기 시작한 첫 상용 GA로, 백엔드 개발 워크플로가 "채팅 → 커밋"에서 "지시 → 자율 검증"으로 재편된다.

### Cursor 3 'Glass' 정식 출시 — Composer 폐기하고 병렬 에이전트·멀티레포 Agents Window 도입

Cursor 3(코드명 Glass)이 기존 Composer 패널을 걷어내고 Agents Window로 IDE를 재설계했다. 사이드바 하나에서 로컬·워크트리·클라우드 샌드박스·원격 SSH 위 에이전트 세션을 동시에 띄우고, 프론트엔드·백엔드·인프라 저장소를 넘나드는 크로스레포 변경을 단일 세션에서 처리한다. Design Mode로 시각적 UI 편집이 붙었고, 이어진 4월 24일 업데이트로 /multitask 명령이 서브에이전트를 비동기 분기시켜 요청을 병렬 처리한다.

> 💡 **왜 중요한가**: "에디터 옆에 있는 챗봇"이던 코딩 도구가 오케스트레이터로 승격되면서, 개발자가 IDE에서 실제로 하는 일이 코딩보다 에이전트 라우팅·리뷰에 더 가까워지는 전환점이다.

### Google Cloud, Gemini Code Assist 무료 티어 공개 — 개인 개발자 월 18만 회 자동완성 개방

Google Cloud가 Gemini Code Assist의 개인 개발자용 무료 플랜을 4월 중순에 공개하며 GitHub Copilot·Cursor 지형에 정면 진입했다. 월 최대 18만 회 코드 완성, 128K 컨텍스트 창, VS Code/JetBrains/Android Studio·CLI 지원, GitHub PR 리뷰 에이전트가 무료 티어에 포함되고, 유료 Enterprise 플랜과 동일한 Gemini 코드 모델을 그대로 노출한다.

> 💡 **왜 중요한가**: 유료 구독이 표준이던 AI 코딩 도구 시장에 무료 대량 쿼터가 투입되면서, 개인·스타트업 개발자의 도구 선택이 "가격"에서 "에이전트 능력"으로 다시 옮겨간다.
