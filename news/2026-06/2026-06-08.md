### 1. Anthropic Claude Opus 4.8 + 'Dynamic Workflows' 출시 — 수백 개 병렬 서브에이전트를 한 모델이 직접 오케스트레이션

Anthropic이 Opus 4.8과 함께 'Dynamic Workflows' 기능을 정식 도입했다. Opus 4.7 대비 코딩·에이전트·추론 능력이 강화됐고, Max·Team 플랜과 Claude Code API 사용자에게는 동적 워크플로가 기본 활성화되어 한 번의 작업으로 수백 개의 서브에이전트를 동시에 굴릴 수 있다. 함께 공개된 'Advisor 도구'는 빠른 실행 모델과 고지능 자문 모델을 페어링해 생성 중간에 전략적 가이드를 주입하고, 'Self-hosted Sandboxes'(퍼블릭 베타)는 Cloudflare·Daytona·Modal·Vercel 등 사용자가 지정한 환경에서 툴 실행을 격리한다.

> 💡 **왜 중요한가**: 단일 모델 호출에서 '플릿(fleet) 오케스트레이션'으로 LLM API 사용 패러다임이 이동하면서, 에이전트 인프라를 별도로 구축하던 팀들의 미들웨어 부담이 모델 쪽으로 흡수되고 있다.

### 2. SAP Joule Studio 2.0 1차 롤아웃 시작 — Claude를 기본 추론 엔진으로, LangChain·Pydantic AI·LlamaIndex까지 네이티브 지원

SAP가 Sapphire 2026에서 공개한 Joule Studio 2.0의 첫 번째 롤아웃이 이번 6월부터 시작됐다(GA는 26년 하반기). 제로 인프라 매니지드 에이전트 빌더로, Anthropic Claude가 'Autonomous Suite' 전반의 1차 추론 모델로 채택됐다. 더 주목할 부분은 멀티 프레임워크 전략 — Python·ABAP뿐 아니라 Claude Code, Cursor, LangChain, Pydantic AI, LlamaIndex를 네이티브 지원하고, 시각적 멀티에이전트 오케스트레이션을 위해 n8n까지 임베드했다. SAP 자체 데모에서는 기존 3~4일 걸리던 엔드투엔드 솔루션을 10~15분에 생성했다고 밝혔다.

> 💡 **왜 중요한가**: 'ERP 벤더가 자기 SDK를 강요하던 시대'가 끝나가는 신호 — 엔터프라이즈 SaaS가 오픈소스 에이전트 프레임워크를 기본값으로 수용하면서, 개발자는 기존 툴체인 그대로 비즈니스 데이터 위에서 에이전트를 만들 수 있게 됐다.

### 3. Microsoft Azure HorizonDB 발표 — 벡터·임베딩·에이전트 상태를 한 엔진에서 처리하는 'AI 시대 Postgres'

Microsoft가 Build 2026에서 공개한 Azure HorizonDB가 본격적인 프로덕션 워크로드 유치 단계에 들어갔다. 벡터, 임베딩, 에이전트 상태(agent-state) 워크로드를 위해 처음부터 재설계된 엔터프라이즈급 PostgreSQL 엔진으로, 별도의 벡터 DB를 두지 않고 RAG·에이전트 메모리·트랜잭션을 한 곳에서 처리하도록 설계됐다. 함께 공개된 Cobalt 200 VM은 에이전트 워크로드에 최적화된 차세대 Arm 기반 CPU 인스턴스로 전 세대 대비 50% 성능 향상을 표방한다.

> 💡 **왜 중요한가**: '에이전트마다 별도의 벡터 DB + 캐시 + 트랜잭션 DB'로 갈라지던 백엔드 스택이 다시 통합 Postgres로 수렴하는 흐름 — 운영 복잡도와 데이터 정합성 비용이 LLM 시대의 새로운 병목이 되었다는 인식을 반영한다.
