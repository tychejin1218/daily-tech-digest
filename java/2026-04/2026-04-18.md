### `Map.entry()`로 불변 `Map.Entry`를 즉석에서 만들기 (Java 9 정식)

`Map.entry(K, V)`는 null을 허용하지 않는 불변 `Map.Entry` 인스턴스를 한 줄로 생성한다. 스트림에서 `Collectors.toMap`으로 모으기 전 임시 튜플이 필요하거나, `Map.ofEntries(...)`로 대형 불변 맵을 초기화할 때 `new AbstractMap.SimpleImmutableEntry<>(k, v)` 상용구를 완전히 걷어낼 수 있다.

```java
Map<String, Integer> scores = Map.ofEntries(
    Map.entry("kim", 92),
    Map.entry("lee", 87),
    Map.entry("park", 78)
);

Map<String, Integer> upper = users.stream()
    .map(u -> Map.entry(u.name().toUpperCase(), u.age()))
    .collect(Collectors.toMap(Map.Entry::getKey, Map.Entry::getValue));
```

> 💡 **왜 중요한가**: 스트림 중간에 (키, 값) 쌍을 다룰 때 별도 DTO나 배열 트릭 없이 표준 API 한 줄로 표현할 수 있다.

### `List.copyOf()` / `Set.copyOf()` / `Map.copyOf()`로 방어적 복사를 불변으로 처리하기 (Java 10 정식)

생성자나 setter에서 외부 컬렉션을 그대로 저장하면 호출자가 나중에 원본을 수정해 내부 상태가 깨질 수 있다. `List.copyOf(source)`는 원본을 얕게 복사한 불변 리스트를 반환하며, 입력이 이미 같은 타입의 불변 컬렉션이면 새 인스턴스를 만들지 않고 그대로 재사용하는 최적화까지 포함한다.

```java
public final class Order {
    private final List<String> items;

    public Order(List<String> items) {
        this.items = List.copyOf(items); // 방어적 복사 + 불변화
    }

    public List<String> items() {
        return items; // 이미 불변이라 그대로 노출해도 안전
    }
}
```

> 💡 **왜 중요한가**: `new ArrayList<>(source)` + `Collections.unmodifiableList(...)` 두 단계 상용구를 한 호출로 압축하면서 불변 컬렉션 재복사까지 자동으로 회피한다.
