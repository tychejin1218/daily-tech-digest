### 1. Anthropic Claude Code, 'Subagent Marketplace' 정식 공개 — 커뮤니티 에이전트를 npm처럼 설치·버전 관리한다

Anthropic이 오늘 Claude Code v2.4에 'Subagent Marketplace'를 정식 탑재했다. 지금까지 `~/.claude/agents/` 폴더에 수동으로 넣던 서브에이전트 정의를 `claude agent install @vendor/reviewer@1.2` 형태로 설치·핀·업데이트할 수 있고, semver·의존성 그래프·서명 검증까지 지원한다. Vercel·Supabase·Datadog이 런치 파트너로 공식 에이전트를 등록했다.

> 💡 **왜 중요한가**: 서브에이전트가 드디어 '설정 파일'에서 '패키지'로 승격됐고, 팀 단위 에이전트 표준화·감사·롤백이 npm 수준의 워크플로우로 들어왔다.

### 2. AWS re:Invent 2026 프리뷰 — Lambda 'SnapStart for Containers' + Bedrock AgentCore 'Durable Execution' GA 발표

AWS가 re:Invent 2026(12월 개막) 사전 브리핑에서 두 개의 GA를 오늘 공개했다. Lambda SnapStart가 그동안 Java 전용이었는데, OCI 컨테이너 이미지까지 확장돼 Node·Python·Go 컨테이너 콜드 스타트가 최대 90% 단축된다. 동시에 Bedrock AgentCore에는 Temporal 스타일의 'Durable Execution' 런타임이 정식으로 붙어, 에이전트가 중단·재기동·수 시간짜리 툴 호출을 상태 손실 없이 이어받는다.

> 💡 **왜 중요한가**: '서버리스=콜드 스타트 세금'과 '에이전트=단명 프로세스'라는 두 개의 오래된 제약이 같은 날 무너졌고, 장시간 러닝 에이전트를 Lambda 하나로 굴리는 게 실제 아키텍처 선택지가 됐다.

### 3. PlanetScale, 'Vector + Vitess 20' 정식 GA — MySQL 샤딩 위에 pgvector-호환 벡터 인덱스가 얹혔다

PlanetScale이 오늘 Vitess 20 기반의 벡터 검색 기능을 정식 GA로 전환했다. HNSW·IVFFlat 인덱스를 MySQL 프로토콜 그대로 쓸 수 있고, 문법은 pgvector와 호환(`<->`, `<=>`)이라 기존 LangChain·LlamaIndex 리트리버가 코드 변경 없이 붙는다. 벡터 컬럼도 Vitess 샤딩 키에 포함돼 수평 확장되며, 별도 벡터 DB 운영 없이 RAG 백엔드를 하나의 MySQL 클러스터로 통합할 수 있다.

> 💡 **왜 중요한가**: 'OLTP + Vector를 한 DB에서'라는 흐름이 Postgres(pgvector)에서 MySQL 진영으로 넘어왔고, 별도 Pinecone·Weaviate 없이 RAG를 굴리려는 팀에게 실질적 대안이 하나 더 생겼다.
