### `Objects.checkIndex(int, int)`로 배열 인덱스 검증을 표준 API로 처리하기 (Java 9 정식)

수동으로 `if (index < 0 || index >= length) throw new IndexOutOfBoundsException()`을 작성하는 대신 `Objects.checkIndex(index, length)`를 사용하면 검증과 예외 발생을 한 줄로 처리하고, 검증 통과 시 인덱스 값을 그대로 반환한다. `checkFromToIndex(fromIndex, toIndex, length)`, `checkFromIndexSize(fromIndex, size, length)`도 함께 제공되어 슬라이싱 검증에도 쓸 수 있다.

```java
int[] arr = {10, 20, 30, 40, 50};

int i = Objects.checkIndex(3, arr.length); // 3 반환
System.out.println(arr[i]); // 40

Objects.checkFromToIndex(1, 4, arr.length); // OK
Objects.checkFromIndexSize(2, 3, arr.length); // OK

Objects.checkIndex(7, arr.length);
// IndexOutOfBoundsException: Index 7 out of bounds for length 5
```

> 💡 **왜 중요한가**: JDK 내부와 동일한 방식으로 인덱스를 검증해 에러 메시지 일관성과 코드 가독성을 동시에 확보한다.

### `Map.Entry.copyOf(Entry)`로 엔트리를 불변 스냅샷으로 복사하기 (Java 17 정식)

`Map.entrySet()`으로 얻은 엔트리는 원본 맵과 연결되어 변경에 영향을 받을 수 있는데, `Map.Entry.copyOf(entry)`를 사용하면 원본과 독립적인 불변 엔트리를 만들어 안전하게 보관하거나 전달할 수 있다. `setValue()` 호출은 `UnsupportedOperationException`을 던지며, `null` 키·값은 허용되지 않는다.

```java
Map<String, Integer> scores = new HashMap<>();
scores.put("Alice", 90);

Map.Entry<String, Integer> live = scores.entrySet().iterator().next();
Map.Entry<String, Integer> snapshot = Map.Entry.copyOf(live);

scores.put("Alice", 100);
System.out.println(live.getValue());     // 100 (원본에 연결됨)
System.out.println(snapshot.getValue()); // 90  (스냅샷 유지)

snapshot.setValue(50); // UnsupportedOperationException
```

> 💡 **왜 중요한가**: 맵 엔트리를 외부에 노출할 때 원본 변경에 의한 예상치 못한 side effect를 방지하고 불변성을 보장한다.
