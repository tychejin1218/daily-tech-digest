# 📰 오늘의 IT 뉴스 — 2026-05-05

### 1. Google Cloud Next '26 — 8세대 TPU 'Ironwood' 듀얼 칩(TPU 8t/8i)과 Gemini Enterprise Agent Platform 공개
구글이 처음으로 학습용 TPU 8t와 추론·강화학습용 TPU 8i를 분리 출시했다. TPU 8t는 단일 슈퍼팟에 9,600칩·121 EFLOPS·2PB 공유 메모리를 제공하고, TPU 8i는 이전 세대 대비 추론 성능/달러 80% 향상되어 에이전트·MoE 워크로드에 최적화됐다. 동시에 'Gemini Enterprise Agent Platform'이 발표되며 Agent Designer·Inbox·Long-running Agents·Skills를 통해 엔터프라이즈 에이전트 OS로 자리매김하려 한다.

> 💡 **왜 중요한가**: 클라우드 3강이 모두 '에이전트 컨트롤 플레인' 중심으로 인프라를 재설계하는 흐름에서, Google은 학습/추론 칩 분리라는 NVIDIA식 접근으로 에이전트 시대 인프라 표준 경쟁의 새로운 축을 그었다.

---

### 2. Cursor SDK 퍼블릭 베타 — 코딩 에이전트가 'TypeScript로 호출 가능한 인프라'가 되다 (4/29)
Cursor 데스크톱·CLI·웹앱을 구동하는 동일한 런타임·하니스·모델을 TypeScript 몇 줄로 호출할 수 있는 SDK가 공개됐다. CI/CD 파이프라인, 백엔드 서비스, 자체 제품 내부 임베드까지 가능하며 클라우드 샌드박스 VM·서브에이전트·훅·MCP 서버 연동·`.cursor/skills/` 자동 스킬 로딩을 지원한다. 과금은 토큰 기반 종량제이며, 셀프 호스팅 워커로 코드와 도구 실행을 사내 네트워크에 가둘 수도 있다.

> 💡 **왜 중요한가**: 코딩 에이전트가 'IDE 기능'에서 '백엔드 빌딩 블록'으로 이동하는 분기점이다. 앞으로는 Jira 티켓 → CI 트리거 → SDK 호출 → 머지 PR로 이어지는 자동화 파이프라인이 표준 백엔드 패턴이 될 가능성이 높다.

---

### 3. NVIDIA × Google Cloud, 'Vera Rubin A5X' 베어메탈 + Gemini-on-Distributed-Cloud로 'AI 팩토리' 본격화
양사는 Cloud Next '26에서 ▲NVIDIA Vera Rubin 기반 A5X 베어메탈 인스턴스(최대 ~100만 Rubin GPU 스케일) ▲NVIDIA Blackwell/Blackwell Ultra GPU에서 동작하는 Google Distributed Cloud용 Gemini 프리뷰 ▲Blackwell GPU 기반 Confidential VM ▲Gemini Enterprise Agent Platform + NVIDIA Nemotron 통합을 발표했다. Vera Rubin NVL72 랙 스케일 시스템은 2026년 하반기 중 Google Cloud AI Hypercomputer에 합류할 예정이다.

> 💡 **왜 중요한가**: '에이전틱·피지컬 AI'를 데이터센터(추론·오케스트레이션)와 공장 현장(로봇·디지털 트윈)이 같은 풀스택으로 연결되는 형태로 재정의하는 시도다. Confidential GPU + 사내 분산 클라우드 옵션은 규제 산업의 LLM/에이전트 도입 장벽을 크게 낮춘다.
