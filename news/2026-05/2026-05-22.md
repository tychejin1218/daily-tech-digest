### Confluent Cloud 'Tableflow 2.0' GA — Kafka 토픽을 Apache Iceberg 테이블로 실시간 미러링

Confluent가 Kafka 스트림을 Iceberg/Delta Lake 테이블로 무설정 변환해주는 Tableflow 2.0을 정식 출시했다. 스키마 레지스트리와 결합해 자동으로 파티셔닝·컴팩션을 수행하며, Snowflake·Databricks·Trino가 별도 ETL 없이 카프카 토픽을 곧바로 조회한다. 지연은 이전 프리뷰 대비 60% 줄어든 30초 이내다.

> 💡 **왜 중요한가**: 스트리밍-분석 파이프라인의 이중 저장(Kafka+웨어하우스)을 하나의 오픈 테이블 포맷으로 통합해 백엔드 데이터 아키텍처가 단순해진다.

### Datadog 'LLM Observability' GA — OpenTelemetry 세만틱 기반 에이전트 트레이싱 표준화

Datadog가 LangChain·LlamaIndex·OpenAI SDK 자동 계측을 지원하는 LLM Observability를 정식 출시했다. OpenTelemetry의 GenAI 세만틱 규약을 그대로 채택해 토큰·비용·프롬프트·툴 호출을 span 속성으로 노출하며, 프로덕션 트래픽에서 halluc·loop 감지 룰을 SLO 알람으로 걸 수 있다. 에이전트 워크플로의 부모-자식 span도 시각화된다.

> 💡 **왜 중요한가**: OTel 표준을 그대로 따르기 때문에 벤더 락인 없이 기존 APM 파이프라인에 LLM 트레이스를 흘려보낼 수 있게 됐다.

### NVIDIA Dynamo Inference Server 2.0 공개 — Prefill·Decode 분리와 KV 캐시 오프로딩 자동화

NVIDIA가 vLLM·TensorRT-LLM·SGLang을 단일 스케줄러 아래로 통합한 Dynamo 2.0을 GTC Spring 이벤트에서 공개했다. Prefill과 Decode를 서로 다른 GPU 풀에 배치하는 disaggregated serving을 기본값으로 켰고, KV 캐시를 CPU RAM·NVMe·다른 노드까지 자동 계층화해 400B 모델 처리량이 1.6배 개선됐다. 스케줄링은 SmartRouter가 KV 재사용률을 보고 라우팅한다.

> 💡 **왜 중요한가**: 추론 최적화가 단일 엔진 튜닝에서 다중 GPU 오케스트레이션 문제로 이동했음을 보여주는 사실상의 오픈 레퍼런스다.
