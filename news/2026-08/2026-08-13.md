### 1. Anthropic Claude Opus 5 정식 출시 + 'Fast Mode' 동시 도입 — 대화 중 툴 교체까지 프롬프트 캐시 유지
Claude Opus 5가 모든 플랫폼에 배포되면서 입력 100만 토큰당 $5, 출력 $25로 책정됐고, 기본 대비 약 2.5배 빠른 Fast Mode가 동시에 열렸다. 베타로 공개된 'Mid-Conversation Tool Changes'는 대화 중간에 사용 가능한 툴 세트를 바꿔도 프롬프트 캐시가 무효화되지 않으며, Claude Code는 팀·엔터프라이즈 플랜에 자체 인프라에서 세션을 돌리는 Self-Hosted Environments 퍼블릭 베타를 열었다.

> 💡 **왜 중요한가**: 에이전트가 '툴 유니버스'를 동적으로 스위칭해도 캐시가 살아있다는 건, 긴 세션의 비용 구조를 완전히 뒤집는다 — Fast Mode와 결합하면 '느리고 비싼 Opus' 통념이 무너진다.

### 2. DeepSeek-V4-Flash-0731 오픈웨이트 공개 — 284B MoE + 1M 컨텍스트가 MIT 라이선스로 풀렸다
DeepSeek이 프로덕션 버전 DeepSeek-V4-Flash-0731을 MIT 라이선스로 오픈소스화했다. MoE 구조에서 총 284B 파라미터 중 토큰당 13B만 활성화하며, 1M 컨텍스트·38.4만 최대 출력 토큰·DSpark 스펙큘러티브 디코딩 드래프트 모듈까지 함께 공개됐다. 공식 API 퍼블릭 베타는 Responses API 네이티브 지원과 Codex 호환을 얹어 상용 프론티어 모델 대비 60% 저렴하다.

> 💡 **왜 중요한가**: '오픈웨이트가 툴콜 · Responses API · 에이전트 벤치마크에서 프론티어를 따라잡았다'는 사건 — 이제 사내 파인튜닝과 프라이빗 배포에서 폐쇄형을 고를 명분이 절반은 사라졌다.

### 3. Cequence Security, 'AI Gateway' 4종 레지스트리 공개 — 조직 안 모든 에이전트·MCP 서버를 로그로 자동 발견
Cequence Security가 AI Discovery · API Registry · LLM Registry · Skill Registry 네 축의 AI Gateway 기능을 릴리스했다. AI Discovery는 기존 보안 로그만 파싱해 이미 사내에서 돌고 있는 에이전트·AI 프로바이더·MCP 서버를 전수 발굴하고, API Registry는 에이전트가 승인된 API를 호출하면서도 원본 크리덴셜을 직접 보유하지 않도록 프록시한다. EU AI Act 50조 투명성 의무(2026-08-02 발효)와 맞물리며 도입 압력이 커지고 있다.

> 💡 **왜 중요한가**: 'Shadow Agent'와 'Shadow MCP'가 이미 조직 내에서 자라고 있다는 걸 전제로 만든 첫 게이트웨이 — 크리덴셜을 에이전트에게 절대 넘기지 않는 브로커 패턴이 표준화되기 시작했다.
