### `HexFormat`으로 바이트 배열과 16진수 문자열을 표준 API로 변환하기 (Java 17 정식)

기존에는 바이트를 hex로 바꾸려고 `String.format("%02x", b)` 루프를 돌리거나 Apache Commons를 가져와야 했다. `HexFormat`은 구분자·접두사·대소문자를 조합해 양방향 변환을 한 줄로 처리한다.

```java
byte[] bytes = {0x2A, (byte) 0xFF, 0x10};
HexFormat hex = HexFormat.of();
String s = hex.formatHex(bytes);              // "2aff10"

HexFormat pretty = HexFormat.ofDelimiter(":").withUpperCase();
String colon = pretty.formatHex(bytes);       // "2A:FF:10"

byte[] parsed = HexFormat.of().parseHex("2aff10");
```

> 💡 **왜 중요한가**: 해시·시그니처·바이너리 디버깅에서 반복적으로 등장하는 hex 변환을 서드파티 의존성 없이 JDK 표준으로 끝낼 수 있다.

### `Stream.mapMulti()`로 flatMap보다 가볍게 요소를 확장·필터링하기 (Java 16 정식)

`flatMap`은 요소마다 새 스트림을 생성해 오버헤드가 크다. `mapMulti`는 소비자(`Consumer`)에 결과를 직접 밀어넣는 방식이라, 조건부로 0~N개의 값을 방출할 때 중간 스트림 없이 처리된다.

```java
List<Number> mixed = List.of(1, 2.5, 3, 4.5, 5);

List<Double> doubles = mixed.stream()
    .<Double>mapMulti((n, downstream) -> {
        if (n instanceof Double d) downstream.accept(d);
    })
    .toList();  // [2.5, 4.5]

List<Integer> expanded = Stream.of(1, 2, 3)
    .<Integer>mapMulti((i, out) -> {
        for (int k = 0; k < i; k++) out.accept(i);
    })
    .toList();  // [1, 2, 2, 3, 3, 3]
```

> 💡 **왜 중요한가**: filter+map을 한 단계로 합치면서 스트림 객체 할당이 줄어, 뜨거운 경로에서 `flatMap`의 명확한 대안이 된다.
