### `@ConfigurationProperties`로 바인딩한 클래스에 `@Setter`가 없으면 조용히 무시된다 — 생성자 바인딩이 아니면 리플렉션이 setter를 찾는다

`@ConfigurationProperties(prefix = "app")`로 외부 설정을 바인딩할 때, Spring은 기본적으로 **JavaBean 규약(setter)** 을 통해 값을 주입한다. Lombok의 `@Getter`만 붙이고 `@Setter`를 빠뜨리면 `application.yml`의 값이 클래스에 들어오지 않고 필드는 `null`이나 기본값으로 남는다. 에러도 경고도 없이 조용히 실패하는 것이 진짜 함정이다. 해결책은 두 가지 — `@Setter`를 추가하거나, 아예 `@ConstructorBinding`(Spring Boot 3.x부터는 생성자가 하나면 자동 적용)으로 불변 객체로 만드는 것이다.

```java
// ❌ 조용히 실패 — app.timeout 값이 절대 들어오지 않는다
@Getter
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private Duration timeout;
}

// ✅ 생성자 바인딩 — 불변 + 명시적
@Getter
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private final Duration timeout;
    public AppProperties(Duration timeout) { this.timeout = timeout; }
}
```

> 💡 **왜 중요한가**: 설정이 안 먹혀서 프로덕션에서 기본 타임아웃(무한대, 0 등)으로 동작하는데 로그엔 아무 흔적도 없다. 디버깅에 몇 시간이 날아간 뒤에야 setter 하나 빠진 걸 발견하게 된다.

### `Filter`에서 발생한 예외는 `@ControllerAdvice`가 잡지 못한다 — DispatcherServlet에 도달하기 전이기 때문

Spring의 `@ExceptionHandler`와 `@ControllerAdvice`는 **DispatcherServlet 내부**에서 발생한 예외만 처리한다. 하지만 `Filter`는 서블릿 컨테이너 레벨에서 실행되어 DispatcherServlet보다 먼저 동작하기 때문에, JWT 검증 필터 등에서 예외를 던지면 Spring이 아니라 톰캣의 기본 에러 페이지(하얀 화면 + 500)로 응답된다. 해결하려면 필터 내부에서 직접 `HttpServletResponse`에 JSON을 써주거나, `HandlerExceptionResolver`를 주입받아 위임해야 한다.

```java
// ✅ 필터 내부에서 HandlerExceptionResolver로 위임
public class JwtAuthFilter extends OncePerRequestFilter {
    @Qualifier("handlerExceptionResolver")
    private final HandlerExceptionResolver resolver;

    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain) {
        try {
            validateToken(req);
            chain.doFilter(req, res);
        } catch (JwtException e) {
            resolver.resolveException(req, res, null, e); // → @ControllerAdvice로 흐른다
        }
    }
}
```

> 💡 **왜 중요한가**: 인증 필터에서 예외를 던졌는데 클라이언트가 우리 예쁜 에러 응답 대신 톰캣의 하얀 화면을 받는다면, 프론트엔드는 파싱 에러로 죽고 사용자는 왜 로그인이 실패했는지 알 수 없다. 필터는 Spring의 영역 밖이라는 사실을 잊는 순간 API 계약이 무너진다.
