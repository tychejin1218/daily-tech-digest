### DigitalOcean, 'AI-Native Cloud' 정식 출시 — 인퍼런스 시대 겨냥한 통합 스택

DigitalOcean이 인퍼런스와 에이전틱 워크로드에 특화된 클라우드를 발표했다. 인프라·코어 클라우드·인퍼런스·데이터·매니지드 에이전트 5개 레이어를 하나의 스택으로 묶어, GPU/스토리지/벡터DB/에이전트 런타임을 이어붙이던 파편화된 파이프라인을 없애는 것이 핵심이다. Higgsfield AI, Hippocratic AI, Bright Data 등이 이미 프로덕션에서 사용 중이며, 초기 유닛 이코노믹스가 하이퍼스케일러 대비 개선됐다고 밝혔다.

> 💡 **왜 중요한가**: AI 서비스 인프라를 GPU 하이퍼스케일러 대신 "AI 전용 중형 클라우드"로 옮기는 선택지가 실제 프로덕션 규모에서 검증되기 시작했다.

### NVIDIA, Cosmos 3 Edge 공개 — 온디바이스 물리 AI용 4B 파라미터 월드 모델

NVIDIA가 로보틱스·엣지 시뮬레이션용으로 튜닝된 4B 파라미터 월드 모델 Cosmos 3 Edge를 릴리스했다. 클라우드 왕복 없이 로봇·드론·산업 카메라 위에서 물리 상호작용을 직접 예측하도록 설계됐고, MCP를 통해 창작·시뮬레이션 툴(Omniverse, Isaac Sim 등)과 양방향 연결된다. 온디바이스 추론을 위해 FP4 양자화 프리셋과 Jetson Thor용 커널을 기본 제공한다.

```python
from cosmos_edge import WorldModel
wm = WorldModel.from_pretrained("cosmos-3-edge-4b", quant="fp4")
next_frame = wm.predict(observation=cam_feed, action=motor_cmd, horizon=8)
```

> 💡 **왜 중요한가**: 서버 GPU 없이도 에이전트가 물리 세계를 시뮬레이션하고 다음 상태를 예측할 수 있게 되면서, 로보틱스와 IoT 백엔드의 설계 지점이 클라우드에서 디바이스로 다시 이동한다.

### KEDA 3.0 릴리스 — 80+ 이벤트 소스 & Kubernetes v1.37 대응 스케일-투-제로 강화

Kubernetes Event-Driven Autoscaling 프로젝트가 3.0 메이저 버전을 공개했다. Kafka, RabbitMQ, NATS JetStream, AWS SQS는 물론 벡터DB 큐 깊이·LLM 인퍼런스 대기열까지 포함해 80개 이상의 이벤트 소스를 지원하며, 스케일-투-제로 지연을 이전 세대 대비 60% 이상 줄였다. 같은 주 발표된 etcd v3.7의 RangeStream API와 결합돼 Kubernetes v1.37에서 대규모 스케일러 팜의 워치 부하가 크게 감소한다.

```yaml
apiVersion: keda.sh/v1alpha1
kind: ScaledObject
spec:
  minReplicaCount: 0
  triggers:
    - type: vllm-queue
      metadata:
        endpoint: http://vllm:8000/metrics
        threshold: "5"
```

> 💡 **왜 중요한가**: LLM 인퍼런스처럼 요청이 튀는 워크로드에서 "0 → N 파드"를 초 단위로 조절할 수 있게 되면, 서버리스와 GPU 스팟 인스턴스 조합이 실전 백엔드 설계의 기본값이 된다.
