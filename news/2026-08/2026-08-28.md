### 1. Kubernetes v1.37 "Garhwal" 정식 릴리스 — 20년 묵은 kube-dns·IPVS·cgroup v1을 통째로 뽑아버린 '대청소 릴리스'
2026년 8월 26일 릴리스된 Kubernetes v1.37에서는 16개 기능이 GA로 승격되고 23개 베타, 27개 알파가 함께 들어왔지만 진짜 헤드라인은 '정리'다. kube-dns 코드 잔재, kube-proxy의 IPVS 모드, cgroup v1 지원이 다단 폐기 절차에 들어갔고, static Pod가 Secret/ConfigMap을 참조할 수 없게 되며 GPU/DRA 디바이스 taint·toleration이 GA로 확정됐다. Pod 레벨 체크포인트/복원(KEP 5823)이 알파로 처음 들어왔는데, 컨테이너 한 개가 아니라 파드 전체를 스냅샷 떠서 다른 노드에서 되살릴 수 있다.

> 💡 **왜 중요한가**: cgroup v1 위에 눌러앉아 있던 레거시 워크로드는 이제 "다음 릴리스 못 넘는다"는 명시적 시한을 받았고, DRA GA로 GPU 스케줄링이 드디어 벤더 사이드카 없이 표준으로 굴러간다.

### 2. MongoDB Atlas, Voyage AI 자동 임베딩 + Managed MCP Server 정식 공개 — 코딩 에이전트가 운영 DB를 '실시간으로' 읽고 쓴다
MongoDB.local Build Fest(8월 13일)에서 공개된 이번 업데이트의 핵심은 두 가지다. 첫째, Atlas가 Voyage AI를 내장해 **쓰기 시점에 텍스트→벡터 변환**을 자동으로 처리 — pgvector 진영이 여전히 유지하는 별도 임베딩 파이프라인이 통째로 사라진다. 둘째, Managed MCP Server가 GA로 풀리며 Claude Code·Codex·Grok Build·Devin이 하나의 인증된 엔드포인트로 라이브 오퍼레이셔널 데이터에 직접 붙는다 — 스키마 조회, 인덱스 진단, Atlas Stream Processing의 실시간 컨텍스트까지 에이전트가 툴 콜 한 번으로 꺼내 쓴다.

> 💡 **왜 중요한가**: RAG용 사이드카 벡터DB + 별도 임베딩 워커 조합이 "AI 앱은 이렇게 만드는 것"이라는 관성을 오퍼레이셔널 DB 본체가 흡수하기 시작했다 — 데이터 이동 없이 에이전트가 원본에 붙는 구조가 표준화되는 신호.

### 3. Microsoft Defender for Cloud, AWS·GCP 리소스 타입 90종 일괄 편입 — 멀티클라우드 보안 태세가 '싱글 콘솔'로 뭉친다
8월 18일 롤아웃에서 Defender for Cloud는 AWS·GCP 쪽 리소스 타입을 한 번에 약 90종 추가로 흡수했다. Aurora Serverless v2, Bedrock 에이전트 엔드포인트, Vertex AI Agent Platform, Cloud Run jobs 같은 최근 GA 서비스들까지 CSPM(구성 오디트)·CWPP(런타임 위협 탐지)·IAM 그래프 안으로 들어왔고, "Azure에서만 관리 잘 되던" MDC의 한계선이 실질적으로 사라졌다. 흥미로운 건 정책·경보를 Azure Sentinel과 상관 분석해 **크로스 클라우드 공격 체인**을 단일 인시던트로 묶어준다는 점.

> 💡 **왜 중요한가**: "AWS는 GuardDuty, GCP는 SCC, Azure는 Defender"로 갈라져 있던 SecOps 파편화가 벤더 로직 관점에서는 처음으로 하나의 대시보드에 강제 통합됐다 — 다른 하이퍼스케일러들도 곧 반격을 내놓을 수밖에 없는 구조 변화.
