### Cursor 2.1, 'Background Agents' 유료 플랜 확장 — 병렬 에이전트 최대 20개 실행

Cursor가 2.1 업데이트에서 백그라운드 에이전트 병렬 실행 한도를 기존 5개에서 20개로 상향하고, 원격 컨테이너에서 돌아가는 에이전트 세션을 IDE 사이드바에서 실시간 스트리밍 감독할 수 있도록 개편했다. 각 에이전트는 독립된 브랜치와 샌드박스 워크스페이스에서 동작하며, PR 초안까지 자동 푸시하는 워크플로우가 Pro Plus($60/월) 티어에 기본 포함됐다.

> 💡 **왜 중요한가**: 페어 프로그래밍 시대에서 '에이전트 함대 관리' 시대로 넘어가는 UX 전환점이다.

### Cloudflare Workers AI, 'Durable Agents' GA — 상태 지속형 LLM 워크플로우가 엣지 리전에서 재시작

Cloudflare가 Durable Objects와 Workers AI를 결합한 Durable Agents를 정식 출시했다. 하나의 에이전트 인스턴스가 특정 엣지 리전에 고정되어 대화 상태·툴 콜 히스토리·중간 결과를 자동 체크포인팅하고, 노드 장애 시 마지막 스텝부터 재개된다. Vectorize·Queues·R2와의 바인딩이 zero-config으로 연결되어 SQS/Redis 조합 없이 에이전트 백엔드를 구성할 수 있다.

> 💡 **왜 중요한가**: 서버리스에서 그동안 취약했던 '수 시간짜리 에이전트 태스크'의 복구·재개 문제를 인프라 레벨에서 해결한다.

### Bun 1.3 정식 릴리스 — 네이티브 MCP 서버 런타임 & Node 24 호환 100% 달성

Oven이 Bun 1.3을 공개하며 `bun mcp` 서브커맨드로 MCP 서버를 Node 의존성 없이 단일 바이너리 실행하는 기능을 도입했다. Node.js 24의 `node:sqlite`, `node:http2` 신규 API까지 커버해 호환률 100%를 발표했고, `Bun.serve()`가 HTTP/3(QUIC)를 실험 플래그 없이 지원한다. `bun install`은 리모트 캐시 프로토콜을 표준화해 팀 단위 CI에서 재설치를 스킵할 수 있다.

> 💡 **왜 중요한가**: MCP 서버가 로컬 Node 스택의 무게를 벗고 저의존 CLI로 배포되는 흐름을 런타임 벤더가 공식 지원하기 시작했다.
