### Anthropic 'Claude Code Workspaces' GA — IDE가 아니라 '브라우저 탭'이 코딩 에이전트의 새 집이 됐다

Anthropic이 오늘 Claude Code의 웹 기반 멀티-세션 환경 'Workspaces'를 정식 출시했다. 한 조직이 수십 개의 Claude Code 세션을 브라우저에서 병렬로 띄우고, GitHub 리포지토리·시크릿·장기 메모리를 조직 단위로 공유하며, 각 세션이 격리된 샌드박스 VM에서 돈다. 로컬 터미널이나 VS Code 플러그인 없이도 "Claude에게 리포 전체를 맡기는" 워크플로우가 처음으로 공식 제품이 됐다.

> 💡 **왜 중요한가**: 코딩 에이전트의 '실행 위치'가 개발자 노트북에서 벤더가 운영하는 클라우드 샌드박스로 넘어가는 신호 — 보안·거버넌스·라이선스 비용 모델이 전부 재설계된다.

### Supabase 'Edge Functions on Deno 3' + 'Background Tasks' 동시 GA — 서버리스 함수가 '비동기 큐'를 자기 안으로 삼켰다

Supabase가 Deno 3 런타임 기반 Edge Functions를 GA하면서 '150초 제한' 대신 최대 400초 비동기 백그라운드 태스크를 기본 내장했다. `EdgeRuntime.waitUntil()` 한 줄로 응답을 먼저 보내고 LLM 호출·웹훅 fan-out·이미지 생성 같은 긴 작업을 함수 안에서 끝낸다. 별도 큐(SQS·BullMQ·Trigger.dev)를 붙이지 않고도 'HTTP 응답 후 처리' 패턴이 PaaS 1급 기능이 됐다.

> 💡 **왜 중요한가**: AI 앱의 가장 흔한 아키텍처(동기 응답 + 비동기 LLM 작업)에서 '큐 미들웨어 한 겹'이 사라진다 — 스타트업의 서버 구성이 또 한 단계 얇아졌다.

### LangChain 'LangGraph Platform 1.0' GA — 에이전트 상태 머신이 'DB가 딸린 PaaS'로 올라갔다

LangChain이 오늘 LangGraph Platform 1.0을 정식 발표하며, 그래프 기반 에이전트 워크플로우를 Postgres 체크포인터·Human-in-the-Loop 큐·장기 메모리 스토어와 함께 매니지드로 돌리는 서비스를 열었다. 셀프호스팅 Helm 차트도 같이 공개돼, 'LangChain은 라이브러리'라는 포지셔닝이 '에이전트 런타임 플랫폼'으로 공식 이동했다. Temporal·Inngest가 차지하던 '내구성 있는 워크플로우' 영토를 LLM 쪽에서 직접 밀고 들어온다.

> 💡 **왜 중요한가**: 에이전트 상태 관리·재시도·사람 개입 같은 '배경 인프라'가 벤더 매니지드 쪽으로 쏠리면서, 자체 Temporal 클러스터를 세울지 LangGraph를 그냥 쓸지가 2026년 백엔드팀의 실전 결정이 됐다.
