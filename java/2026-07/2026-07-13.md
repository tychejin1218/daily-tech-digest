### `Text Blocks`로 여러 줄 문자열의 이스케이프 지옥에서 벗어나기 (Java 15 정식)
JSON, SQL, HTML처럼 개행과 따옴표가 많은 문자열을 `"""..."""`로 감싸면 이스케이프 없이 원본 그대로 작성할 수 있습니다. 컴파일러가 공통 들여쓰기(incidental whitespace)를 자동으로 제거해주므로 코드 정렬을 유지하면서도 실제 문자열에는 불필요한 공백이 남지 않습니다. 줄 끝에 `\`를 두면 줄바꿈을 억제할 수 있어 긴 SQL 한 줄도 소스에서는 여러 줄로 나눠 쓸 수 있습니다.

```java
String query = """
        SELECT id, name
        FROM   users
        WHERE  status = 'ACTIVE'
        """;
```

> 💡 **왜 중요한가**: `"\"SELECT id...\\n\" + \"FROM...\\n\"` 같은 연결·이스케이프 코드는 오타 한 번으로 SQL 인젝션이나 파싱 오류를 부르며, 리뷰 시에도 실제 문자열이 무엇인지 즉시 알 수 없다.

### `Sealed Classes`로 상속 계층을 명시적으로 봉인하고 패턴 매칭과 결합하기 (Java 17 정식)
`sealed` 키워드와 `permits` 절로 어떤 하위 타입만 상속을 허용할지 컴파일러에 선언할 수 있습니다. 하위 타입은 `final`, `sealed`, 또는 `non-sealed` 중 하나로 명시해야 하며, `switch` 패턴 매칭과 함께 쓰면 컴파일러가 모든 케이스를 커버했는지 검증해줘서 `default` 없이도 완전성(exhaustiveness)이 보장됩니다.

```java
sealed interface Shape permits Circle, Square, Triangle {}
record Circle(double r) implements Shape {}
record Square(double side) implements Shape {}
record Triangle(double b, double h) implements Shape {}

double area(Shape s) {
    return switch (s) {
        case Circle c   -> Math.PI * c.r() * c.r();
        case Square sq  -> sq.side() * sq.side();
        case Triangle t -> 0.5 * t.b() * t.h();
    };
}
```

> 💡 **왜 중요한가**: 대수적 자료형(ADT)을 자바로 표현할 수 있게 되어, 새 하위 타입이 추가되면 `switch`가 컴파일 에러로 알려주므로 처리 누락 버그를 런타임이 아닌 빌드 시점에 잡을 수 있다.
