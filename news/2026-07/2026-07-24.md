### Mistral AI, 'Codestral 3' 정식 공개 — 220B 파라미터 오픈웨이트 코딩 모델

프랑스 Mistral AI가 220B 파라미터의 Codestral 3를 Apache 2.0 라이선스로 공개했다. Fill-in-the-middle 성능이 이전 세대 대비 42% 향상되었고, 80개 이상 프로그래밍 언어와 128K 토큰 컨텍스트를 지원하며, HumanEval++ 벤치마크에서 87.4점을 기록해 GPT-4o 수준의 코드 완성 품질을 오픈웨이트로 제공한다.

> 💡 **왜 중요한가**: 유럽산 오픈웨이트 모델이 상용 SaaS 없이도 실무 수준 코딩 성능을 달성하며 자체 호스팅 코딩 어시스턴트의 경제성이 급변했다.

### Databricks, 'Mosaic Agent Framework 2.0' GA — Unity Catalog에 에이전트 계보 추적 통합

Databricks가 Mosaic Agent Framework 2.0을 정식 출시하며 Unity Catalog에 에이전트 실행 계보(lineage)를 완전 통합했다. 각 도구 호출과 LLM 프롬프트, 검색된 문서 청크가 데이터셋 수준의 감사 로그와 함께 저장되어 SOX·HIPAA 컴플라이언스 요구를 충족하며, MLflow 3의 트레이스 UI와도 양방향 링크된다.

> 💡 **왜 중요한가**: 금융·헬스케어에서 에이전트 프로덕션 도입의 최대 걸림돌이었던 감사 추적 문제가 데이터 웨어하우스 레벨에서 해결됐다.

### LangChain, 'LangGraph Cloud' 자체 호스팅 옵션 정식 출시 — 폐쇄망 배포 지원

LangChain이 LangGraph Cloud의 self-hosted 배포판을 정식 공개했다. Helm 차트 한 번으로 Kubernetes 클러스터에 체크포인터·태스크 큐·스트리밍 API 서버를 배치할 수 있으며, Postgres/Redis만 준비되면 에어갭 환경에서도 SaaS와 100% 프로토콜 호환으로 동작한다. 기존 SaaS 그래프 정의는 수정 없이 그대로 이식된다.

> 💡 **왜 중요한가**: 데이터 반출이 불가능한 금융·공공·의료 폐쇄망에서도 상용 에이전트 오케스트레이션 스택을 표준 방식으로 배포할 수 있게 됐다.
