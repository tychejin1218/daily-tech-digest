### `String.formatted(Object...)`로 인스턴스 메서드처럼 문자열 포맷팅하기 (Java 15 정식)

기존 `String.format("Hello %s", name)`은 정적 메서드 호출이라 체이닝이 어색했는데, Java 15부터는 `"Hello %s".formatted(name)`처럼 인스턴스 메서드로 호출할 수 있다. 텍스트 블록(`"""..."""`)과 결합하면 여러 줄 템플릿의 가독성이 크게 향상된다.

```java
String json = """
    {
      "name": "%s",
      "age": %d
    }
    """.formatted("Alice", 30);
```

> 💡 **왜 중요한가**: 텍스트 블록 기반 템플릿을 자연스러운 메서드 체이닝으로 채워 넣어 로그·JSON·SQL 문자열 조립 코드의 시각적 흐름을 지킬 수 있다.

### `Stream.toList()`로 불변 리스트를 간결하게 수집하기 (Java 16 정식)

기존 `stream.collect(Collectors.toList())`는 반환 타입이 가변 리스트라는 점이 명세되지 않아 오해가 잦았는데, Java 16부터 도입된 `Stream.toList()`는 **불변 리스트**를 반환하며 `null` 요소도 그대로 허용한다. 짧은 호출 형태 덕분에 스트림 종단 연산의 노이즈가 크게 줄어든다.

```java
List<String> names = users.stream()
    .filter(User::isActive)
    .map(User::name)
    .toList();
// names.add("x"); → UnsupportedOperationException
```

> 💡 **왜 중요한가**: 방어적 복사를 별도로 하지 않아도 반환값의 불변성이 보장되므로 API 경계에서 실수로 상태가 오염되는 사고를 원천 차단할 수 있다.
