### GitHub Copilot Code Review, Agent Skills & MCP 정식 GA — "PR 자동 리뷰가 조직 지식을 마시기 시작했다" (2026-07-29)
Copilot 코드 리뷰가 Agent Skills와 MCP 서버 연동을 정식 지원한다. 조직 내부 문서·티켓·규칙을 MCP 서버로 노출하기만 하면, PR 리뷰 코멘트가 팀 컨벤션과 도메인 지식까지 반영해 남는다. Pro/Pro+/Business/Enterprise 전 티어에 동시 개방됐다.

> 💡 **왜 중요한가**: 코드 리뷰 자동화가 "린트 수준"에서 벗어나 조직 컨텍스트를 학습해야 한다는 관점이 표준이 됐다 — MCP가 코드 리뷰 파이프라인의 확장 슬롯으로 굳어지는 신호.

### Apple Foundation Models Framework 확장 — "온디바이스 모델과 Claude·Gemini를 같은 Swift API로 호출" (WWDC 2026)
Apple이 Foundation Models를 Private Cloud Compute 위에서 무료로 개방(연 200만 다운로드 미만 앱 대상)했고, 이미지 입력·서버측 Claude/Gemini 호출·Dynamic Profiles(멀티 에이전트 워크플로우)를 한 프레임워크에 통합했다. iOS 앱은 이제 "온디바이스 → PCC → 외부 프론티어 모델" 3단 fallback을 Swift 한 줄로 표현할 수 있다.

> 💡 **왜 중요한가**: 하이브리드 AI 배치(온디바이스/전용 클라우드/외부 API)가 애플 생태계에서 사실상 기본 아키텍처가 됐다 — 모바일 백엔드 팀은 이제 "어느 계층에서 추론할 것인가"를 라우팅 문제로 다뤄야 한다.

### Google Antigravity 2.0 — "IDE, CLI(agy), SDK, Managed Agents API를 같은 날 던졌다" (2026-05-19, I/O 2026)
Google이 Antigravity를 에이전트 퍼스트 플랫폼으로 재출시했다. 데스크톱 앱은 에디터가 아니라 서브에이전트 오케스트레이션 콘솔이고, `agy` CLI·SDK·Gemini API 안의 Managed Agents 티어가 동시에 열렸다. 엔진은 Gemini 3.5 Flash, 백그라운드 스케줄링과 음성 명령까지 포함된다.

> 💡 **왜 중요한가**: 코드 편집기 중심의 AI 도구(Cursor/Copilot) vs. 에이전트 관리 콘솔 중심의 플랫폼(Antigravity)이라는 두 진영으로 시장이 갈라졌다 — 개발자 도구 경쟁 축이 "자동완성 품질"에서 "에이전트 오케스트레이션 UX"로 이동.
