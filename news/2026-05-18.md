### 1. Anthropic, SpaceX의 220,000 GPU 'Colossus 1' 슈퍼클러스터 전량 임대 — Claude API 레이트리밋 대폭 완화
Anthropic이 SpaceX(xAI 인수 후)와 계약을 체결해 멤피스에 위치한 Colossus 1 데이터센터의 전체 컴퓨트 용량(220,000+ NVIDIA H100/H200/GB200, 300MW)을 한 달 내 확보했습니다. xAI가 Colossus 2(550,000 GB200/GB300)로 Grok 학습을 옮기면서 남은 자산을 Anthropic이 인수한 형태로, 이 컴퓨트는 즉시 Claude Pro/Max 한도 확대(5시간 리밋 2배, 피크아워 제한 해제)와 Claude Opus API 레이트리밋 상향에 투입됐습니다. 양사는 향후 '궤도(orbital) AI 데이터센터' 협력도 명시했습니다.

> 💡 **왜 중요한가**: 그동안 Claude Opus 호출에서 발생하던 레이트리밋 병목이 단기간에 해소돼, 백엔드에서 Claude를 본격 운영 워크로드로 끌어올릴 수 있는 헤드룸이 처음으로 열렸습니다.

### 2. Cloudflare, Rust 기반 LLM 추론 엔진 'Infire' 공개 — vLLM 0.10.0 대비 +7% 속도·+20% 처리량
Cloudflare가 자체 개발한 추론 엔진 **Infire**를 글로벌 엣지망에 배포했습니다. 입력(프리필)과 출력(디코드)을 서로 다른 머신으로 분리하고, Granular CUDA Graphs + JIT 컴파일로 배치 사이즈별 그래프를 즉석에서 만들어 CPU 오버헤드를 82% 줄였습니다. 그 결과 H100 NVL 단일 노드에서 vLLM 0.10.0 대비 추론 7% 가속·처리량 20% 향상을 보였고, Llama 4 Scout를 H200 2장으로, Kimi K2.5를 H100 8장으로 KV 캐시까지 확보한 채 구동합니다.

> 💡 **왜 중요한가**: LLM 자체호스팅(self-hosting) 백엔드를 짤 때 vLLM이 사실상 표준이었는데, 이제 동일 GPU 비용으로 더 큰 모델/더 긴 컨텍스트를 돌릴 수 있는 대안이 등장해 인퍼런스 인프라 설계 재검토가 필요해졌습니다.

### 3. OpenAI 'Work with Codex from anywhere' — Codex 코딩 에이전트를 ChatGPT 모바일에서 감독·승인 (5/14)
OpenAI가 5월 14일 Codex 코딩 에이전트의 모바일 감독 기능을 정식 공개했습니다. Mac/devbox/원격 환경에서 돌아가는 Codex 세션을 iOS·Android ChatGPT 앱에서 이어 받아 로그 확인, 코드 diff 검토, 모델 전환, 민감 명령(approve/deny)을 수행할 수 있습니다. Mac 앱의 'Codex mobile' 섹션에서 QR을 스캔하면 즉시 페어링되고, 백그라운드로 도는 에이전트가 판단을 요청할 때만 푸시로 끼어듭니다.

> 💡 **왜 중요한가**: 코딩 에이전트가 '데스크에 묶인 도구'에서 '비동기 백그라운드 작업자'로 본격 이행하는 신호로, 출근길/회의 중에도 PR을 굴리는 인간-에이전트 협업 리듬이 표준화되기 시작했습니다.
