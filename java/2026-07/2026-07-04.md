### `Optional.or(Supplier)`로 빈 Optional에 대체 Optional을 지연 평가로 연결하기 (Java 9 정식)

`Optional.orElse()`는 값을 반환하지만, `or()`는 빈 경우 다른 `Optional`을 반환하도록 체이닝할 수 있다. `Supplier`를 받기 때문에 대체 경로가 지연 평가되어, 여러 소스에서 순차적으로 값을 조회하는 fallback 체인을 간결하게 표현할 수 있다.

```java
Optional<User> user = findInCache(id)
    .or(() -> findInDb(id))
    .or(() -> findInRemote(id));
```

> 💡 **왜 중요한가**: `orElseGet`으로 값만 꺼내지 않고 Optional 상태를 유지한 채 fallback을 이어붙일 수 있어 다단계 조회 로직이 깔끔해진다.

### `List.copyOf(Collection)`로 방어적 복사와 불변화를 한 번에 처리하기 (Java 10 정식)

기존에는 `Collections.unmodifiableList(new ArrayList<>(source))`처럼 두 단계를 거쳐야 방어적 복사와 불변화를 동시에 얻을 수 있었다. `List.copyOf()`는 입력을 복사한 불변 리스트를 반환하며, 입력이 이미 불변 리스트라면 새 복사본을 만들지 않고 그대로 반환해 오버헤드까지 최적화한다. `Set.copyOf()`, `Map.copyOf()`도 동일한 규약을 따른다.

```java
public record Order(String id, List<String> items) {
    public Order {
        items = List.copyOf(items);
    }
}
```

> 💡 **왜 중요한가**: record나 생성자에서 컬렉션 필드를 안전하게 봉인할 때 표준 API 한 줄로 방어적 복사와 불변성을 함께 확보할 수 있다.
