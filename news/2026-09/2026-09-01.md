### 1. OpenAI, 'Codex Cloud' 정식 GA — 브라우저·CLI·GitHub Actions에서 동시에 도는 '병렬 백그라운드 에이전트' 티어 공개

OpenAI가 2026-09-01자로 Codex Cloud를 정식 GA로 전환하며, 단일 리포에 대해 최대 16개의 백그라운드 에이전트를 병렬 실행하는 'Fleet Mode'와 GitHub Actions 네이티브 러너를 함께 공개했다. Team/Enterprise 플랜에는 월 3,000 태스크가 기본 포함되고, 각 태스크는 격리된 마이크로 VM에서 도구·인터넷 접근 정책을 리포별로 상속받는다. Anthropic Claude Code, Cursor Composer, Cognition Devin에 이어 '병렬 서브에이전트'가 상용 티어의 기본 사양으로 굳어지는 모양새다.

> 💡 **왜 중요한가**: 코딩 에이전트의 경쟁축이 '얼마나 똑똑한가'에서 '얼마나 많이 동시에 돌릴 수 있는가(fleet throughput)'로 완전히 이동했다는 신호다.

### 2. Redis 9.0 정식 릴리스 — Vector Sets 정식 GA + 'Query Engine 2' + BSL/AGPL 듀얼 라이선스 유지

Redis Labs가 2026-09-01 Redis 9.0을 정식 공개하면서 8.x에서 프리뷰였던 Vector Sets 자료구조를 GA로 승격하고, HNSW·IVF·SVS 인덱스를 코어 엔진에 내장한 'Query Engine 2'를 표준 배포에 포함시켰다. 특히 RESP3 위에서 도는 새 `FT.HYBRID` 명령이 벡터·전문·태그 검색을 단일 왕복(round-trip)으로 처리해, 별도 벡터 DB 없이 RAG 캐시·세션 스토어·검색을 한 노드에서 끝낼 수 있게 됐다. 지난해 논란이었던 라이선스는 BSL 1.1 + AGPLv3 듀얼로 유지되며, Valkey 진영과의 기능 격차가 다시 벌어졌다.

> 💡 **왜 중요한가**: 캐시 계층과 벡터 DB를 분리해 운영하던 '이중 스택 RAG 아키텍처'가 Redis 한 통으로 접히면서, 소규모~중간 규모 서비스의 인프라 SKU가 통째로 재편될 수 있다.

### 3. JetBrains 'Junie 2' + AI Assistant 통합판 정식 출시 — IDE 안에서 'Local-first 코딩 에이전트'가 LLM 라우팅까지 담당

JetBrains가 오늘 IntelliJ 2026.2 및 전 IDE 라인에 Junie 2를 기본 탑재하고, 별도로 팔던 AI Assistant를 하나의 구독으로 통합했다. Junie 2는 로컬에서 도는 컨텍스트 인덱서(`.junie/index`)와 프로젝트별 정책 파일(`junie.yaml`)을 기반으로, Claude Opus 4.7 / GPT-5.4 / Gemini 3 / 로컬 Qwen3-Coder-Air 사이에서 태스크별로 모델을 자동 라우팅한다. 특히 'Offline Mode'에서는 사내 vLLM 엔드포인트만으로 리팩터링·테스트 생성·PR 리뷰가 가능해, 규제 산업의 IDE 에이전트 도입 장벽을 크게 낮췄다.

> 💡 **왜 중요한가**: 코딩 에이전트의 컨트롤 포인트가 클라우드 SaaS에서 IDE 벤더로 이동 중이라는 신호이자, 엔터프라이즈에서 '어느 모델을 쓰느냐'보다 '어디서 인덱싱·라우팅하느냐'가 도입 결정을 좌우하기 시작했다.
