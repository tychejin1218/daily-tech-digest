### Alibaba, 오픈웨이트 'Qwen3.8-Max' 공개 — 2.4조 파라미터 MoE가 100만 토큰 컨텍스트로 돌아왔다
알리바바가 8월 4일 자사 최대 규모의 AI 모델 Qwen3.8-Max를 발표하며 Alibaba Cloud Model Studio API로 즉시 개방했다. Sparse MoE 구조로 총 2.4T 파라미터 중 추론 시 95B만 활성화되고, 컨텍스트 윈도우는 1M 토큰(약 75만 단어)에 달한다. Text Arena 5위·Vision Arena 2위를 기록했으며, 다음 주 오픈웨이트로 공개되는 첫 Max 클래스 모델이 된다.

> 💡 **왜 중요한가**: "폐쇄 플래그십 vs. 오픈웨이트 롱컨텍스트"의 균형추가 다시 오픈 쪽으로 기울었다 — 사내 코드베이스 전체를 통째로 넣고 추론하는 게 API 호출 한 번으로 가능해진다는 뜻이다.

### Cloudflare, Agents Week 2026 — 에이전트에게 '지갑'과 '컴퓨터'를 쥐여주다
8월 2일 시작된 Cloudflare Agents Week에서 `@cloudflare/computer`(isolate와 Linux 컨테이너를 동적으로 오케스트레이션하는 에이전트 런타임)와 `cloudflare.pay`·Cloudflare Wallets(에이전트에 안정적 신원과 결제 능력 부여)가 공개됐다. Browser Rendering은 'Browser Run'으로 리브랜딩되며 Live View·Human-in-the-Loop·CDP 접근·4배 높은 동시성 한계를 갖췄고, Outbound Workers for Sandboxes는 신뢰할 수 없는 에이전트 코드에 자격증명을 노출하지 않고 dynamic security policy를 강제하는 zero-trust egress 프록시를 제공한다.

> 💡 **왜 중요한가**: "에이전트가 자율적으로 결제하는 웹"이 인프라 레벨에서 실체를 갖기 시작했다 — 사람 브라우저 기준으로 설계된 CDN·보안 스택이 에이전트 기준으로 재설계되고 있다.

### LiteLLM, MCP Gateway 프론트도어 통합 — Rust axum 기반으로 프록시 계층이 다시 태어났다
8월 1일 LiteLLM이 Claude Opus 5(1M 컨텍스트)에 대한 Anthropic·Bedrock·Vertex AI·Azure AI Foundry Day-0 지원을 발표하며, MCP Gateway를 정식 프론트도어로 통합했다. 네이티브 Anthropic `/v1/messages` 라우팅이 Rust axum 게이트웨이를 통과하도록 재구축됐고, Responses API용 WebSockets 포트와 litellm-core의 SigV4 서명이 함께 들어갔다. Gemini 3.6 Flash와 Gemini 3.5 Flash Lite 지원도 같은 릴리스에 포함됐다.

> 💡 **왜 중요한가**: LLM 프록시가 Python 성능 병목을 벗고 "MCP 통합 관문"으로 진화하고 있다는 신호다 — 조직의 여러 MCP 서버·다중 프로바이더를 하나의 게이트웨이로 라우팅하는 아키텍처가 사실상 표준이 되어간다.
