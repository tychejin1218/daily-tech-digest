### 1. OpenRouter, $113M 시리즈 B 마감 — 주간 25조 토큰 처리하는 'AI 모델 라우팅' 표준 자리잡다

OpenRouter가 CapitalG 리드로 $113M 시리즈 B를 완료하며 NVentures·ServiceNow·MongoDB·Snowflake·Databricks Ventures를 합류시켰다. 단일 API로 OpenAI·Anthropic·Google 등 400+ 모델을 라우팅·페일오버·거버넌스하는 플랫폼은 6개월 만에 처리량이 5배로 뛰어 주간 25조 토큰·이용자 800만 명을 돌파했다.

> 💡 **왜 중요한가**: "단일 모델 선택의 시대는 끝났다" — 멀티모델 인퍼런스 게이트웨이가 엔터프라이즈 AI 인프라의 신규 표준 레이어로 굳어지고 있다는 신호다.

### 2. NVIDIA × ServiceNow, 자율 데스크톱 에이전트 'Project Arc' 공개 — 'OpenShell' 샌드박스 런타임 동시 오픈소스화

ServiceNow Knowledge 2026에서 젠슨 황과 빌 맥더모트가 함께 발표한 Project Arc는 지식 근로자용 장기 실행·자기진화형 데스크톱 에이전트다. 모든 행위는 NVIDIA OpenShell(정책 기반 샌드박스 오픈소스 런타임) 내부에서 실행되며, ServiceNow AI Control Tower가 읽은 파일·실행 명령·호출 API를 전수 로깅해 거버넌스한다. NVIDIA Nemotron 패밀리가 추론 엔진으로 탑재됐다.

> 💡 **왜 중요한가**: 데스크톱·데이터센터 전 구간에 걸친 '감사 가능한 에이전트 실행 환경'을 오픈소스 런타임으로 푸시한 사례로, 엔터프라이즈 에이전트 채택의 마지막 장벽이던 감사·거버넌스 요건을 정조준한다.

### 3. Google Cloud Apigee, MCP 서버까지 거버넌스하는 'AI 게이트웨이' 기능 6/18 공개

6월 18일 Google Cloud가 공개한 Apigee 신기능은 기존 30+ 인증·인가·시큐리티 정책을 그대로 MCP 서버에 적용해, 사내 API들을 거버넌스된 MCP 도구로 자동 변환한다. API Hub에 전체 MCP 툴 카탈로그가 통합되며, 에이전트가 호출한 모든 인터랙션은 Apigee 디버깅 UI·애널리틱스에서 종단 간 트레이싱된다.

> 💡 **왜 중요한가**: 헬스케어·금융·정부같이 규제 워크로드를 다루는 조직이 기존 API 자산을 코드 변경 없이 즉시 'MCP 호환 도구'로 승격할 수 있어, 엔터프라이즈 MCP 도입의 가장 큰 마찰 — 보안·컴플라이언스 — 을 단번에 해소한다.
