### `Predicate.not()`로 람다 부정을 가독성 있게 표현하기 (Java 11 정식)

기존에는 `filter(s -> !s.isEmpty())`처럼 람다 안에 `!`를 박아 부정 조건을 표현해야 했지만, `Predicate.not()` 정적 메서드를 쓰면 메서드 레퍼런스 그대로 부정 처리가 가능하다. 의도가 명확해지고 IDE의 메서드 레퍼런스 인라이닝과도 잘 어울린다.

```java
import java.util.function.Predicate;
import static java.util.function.Predicate.not;

List<String> names = List.of("Alice", "", "Bob", "  ", "Charlie");

// Before
names.stream()
      .filter(s -> !s.isBlank())
      .toList();

// After
names.stream()
      .filter(not(String::isBlank))
      .toList();
```

> 💡 **왜 중요한가**: 람다 본문에 숨어 있던 `!` 연산자를 호출부로 끌어올려, 부정 조건도 메서드 레퍼런스로 깔끔하게 작성할 수 있다.

### `Record Patterns`로 `switch`에서 중첩 레코드를 한 번에 분해하기 (Java 21 정식)

`record`와 `sealed` 계층을 `switch` 패턴 매칭과 결합하면, 타입 분기와 동시에 내부 필드까지 깊게 분해할 수 있다. 별도의 게터 호출이나 임시 변수 없이 데이터 구조를 한 줄로 풀어 가독성과 안전성을 모두 챙긴다.

```java
sealed interface Shape permits Circle, Rectangle {}
record Point(int x, int y) {}
record Circle(Point center, int radius) implements Shape {}
record Rectangle(Point topLeft, int width, int height) implements Shape {}

static String describe(Shape s) {
    return switch (s) {
        case Circle(Point(int x, int y), int r) ->
            "원: 중심(%d,%d), 반지름 %d".formatted(x, y, r);
        case Rectangle(Point(int x, int y), int w, int h) ->
            "사각형: (%d,%d)에서 %dx%d".formatted(x, y, w, h);
    };
}
```

> 💡 **왜 중요한가**: `instanceof` 캐스팅과 게터 체인을 없애 도메인 모델을 데이터 그 자체로 다루게 해 주며, `sealed` 타입과 합쳐지면 컴파일러가 분기 누락까지 잡아낸다.
