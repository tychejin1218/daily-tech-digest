### 1. `@DynamicPropertySource`로 Testcontainers 컨테이너 정보를 Spring 컨텍스트에 동적 주입하기

테스트 클래스에 `static` 메서드를 만들고 `@DynamicPropertySource`를 붙이면, Testcontainers가 띄운 임시 컨테이너의 동적 포트·URL을 `DynamicPropertyRegistry`를 통해 Spring 환경 프로퍼티로 등록할 수 있습니다. `@TestPropertySource`나 시스템 프로퍼티 하드코딩과 달리 컨테이너 기동 후 결정되는 값을 안전하게 바인딩할 수 있어, JDBC URL·Redis 호스트·Kafka 부트스트랩 서버 같이 런타임에야 알 수 있는 값을 깔끔하게 처리합니다.

```java
@SpringBootTest
@Testcontainers
class OrderRepositoryTest {
    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:16");

    @DynamicPropertySource
    static void registerProps(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", postgres::getJdbcUrl);
        registry.add("spring.datasource.username", postgres::getUsername);
        registry.add("spring.datasource.password", postgres::getPassword);
    }
}
```

> 💡 **왜 중요한가**: 컨테이너 기동 이후에만 알 수 있는 동적 값을 Spring 프로퍼티 시스템에 자연스럽게 흘려보내, 인프라 의존 통합 테스트를 안정적이고 재현 가능하게 만들 수 있습니다.

### 2. `HandlerMethodArgumentResolver`로 컨트롤러 파라미터 바인딩 직접 정의하기

`HandlerMethodArgumentResolver`를 구현하고 `WebMvcConfigurer.addArgumentResolvers()`로 등록하면, 컨트롤러 메서드 시그니처에서 인증 컨텍스트·요청 메타데이터·테넌트 ID 같은 공통 값을 커스텀 어노테이션 한 줄로 자동 주입할 수 있습니다. 매 메서드마다 `SecurityContextHolder`를 호출하거나 `HttpServletRequest`에서 헤더를 꺼내는 보일러플레이트를 제거하면서, 컨트롤러 시그니처를 의도가 명확한 도메인 타입으로 유지할 수 있습니다.

```java
@Target(ElementType.PARAMETER)
@Retention(RetentionPolicy.RUNTIME)
public @interface CurrentUser {}

@Component
public class CurrentUserArgumentResolver implements HandlerMethodArgumentResolver {
    @Override
    public boolean supportsParameter(MethodParameter parameter) {
        return parameter.hasParameterAnnotation(CurrentUser.class)
            && parameter.getParameterType().equals(LoginUser.class);
    }

    @Override
    public Object resolveArgument(MethodParameter parameter, ModelAndViewContainer mavContainer,
                                  NativeWebRequest webRequest, WebDataBinderFactory binderFactory) {
        Authentication auth = SecurityContextHolder.getContext().getAuthentication();
        return LoginUser.from(auth);
    }
}

@GetMapping("/me")
public ProfileResponse me(@CurrentUser LoginUser user) {
    return profileService.findBy(user.id());
}
```

> 💡 **왜 중요한가**: 인증 정보 같은 횡단 관심사를 컨트롤러 시그니처에서 선언적으로 표현해, 테스트 용이성과 가독성을 동시에 끌어올릴 수 있습니다.
