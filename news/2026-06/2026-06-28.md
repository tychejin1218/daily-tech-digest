### Vercel AI SDK 5.0 정식 출시 — React Server Components 네이티브 통합 & 통합 스트리밍 프로토콜

Vercel이 AI SDK 5.0을 정식 출시하며 React Server Components(RSC)에 대한 네이티브 통합을 완성했다. `streamUI`와 `useChat` API가 통합 스트리밍 프로토콜(UMSP) 위로 재구성되어 OpenAI·Anthropic·Google·Groq 등 서로 다른 프로바이더 간에도 툴 콜·리즌잉·아티팩트가 동일한 이벤트 시퀀스로 전달된다. 특히 `experimental_useObject`가 안정화되어 Zod 스키마로 스트리밍 중인 부분 객체를 타입 안전하게 렌더링할 수 있다.

```ts
const { object } = useObject({
  api: '/api/generate',
  schema: z.object({ items: z.array(z.string()) }),
});
```

> 💡 **왜 중요한가**: 프로바이더 스위칭 비용이 사실상 사라지며, Next.js 앱에서 AI 기능이 별도 백엔드 없이 서버 컴포넌트만으로 완성된다.

### Docker Desktop 5.0, 'Agent Runtime' 기본 탑재 — MCP 서버 원클릭 실행 & 로컬 샌드박스 격리

Docker Desktop 5.0이 정식 릴리스되며 Anthropic MCP 스펙 1.0 기반 'Agent Runtime'을 기본 컴포넌트로 통합했다. `docker mcp run <server>` 한 줄로 파일시스템·DB·브라우저 툴을 격리된 컨테이너 샌드박스에서 구동하고, Docker Hub에 정식 오픈된 `mcp/*` 네임스페이스에서 검증된 커뮤니티 서버를 pull해서 즉시 붙일 수 있다. Compose 파일에도 `mcp:` 최상위 키가 추가되어 에이전트 스택 전체를 코드로 관리한다.

```yaml
mcp:
  servers:
    filesystem: { image: mcp/filesystem, mounts: ["./workspace"] }
    postgres:   { image: mcp/postgres, env: [DSN] }
```

> 💡 **왜 중요한가**: 에이전트가 로컬 개발자 머신을 임의로 만지는 위험을 컨테이너 경계로 봉인하면서, MCP 배포·공유의 표준 패키징이 사실상 컨테이너 이미지로 굳어진다.

### LangChain, 'LangGraph Platform' GA — 상태 지속형 에이전트 서버리스 배포 & 인간 개입 큐 표준화

LangChain이 LangGraph Platform을 정식 출시했다. 그래프 정의만 `langgraph.json`으로 제출하면 체크포인터(Postgres·Redis)와 큐(SQS 호환)가 자동 프로비저닝되고, 장기 실행 에이전트가 도중에 중단되어도 스레드 단위로 상태가 지속된다. 특히 `interrupt()` 프리미티브가 안정화되어 사람의 승인이 필요한 지점에서 그래프를 일시 정지·직렬화하고, 외부 대시보드나 Slack에서 재개(resume) 신호만 던져도 원래 컨텍스트로 되돌아온다.

```py
value = interrupt({"question": "이 트랜잭션을 승인할까요?", "amount": 1200})
```

> 💡 **왜 중요한가**: '오래 살아있는 에이전트'가 재시작·롤링 배포·사람 승인 대기를 넘어서 지속되는 인프라 계층이 마련되어, 프로덕션 에이전트가 데모 수준을 벗어나 워크플로 엔진 자리로 진입한다.
