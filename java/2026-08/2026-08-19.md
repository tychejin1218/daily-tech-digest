### 1. `String.repeat(int count)`로 문자열 반복 연산을 표준 API로 처리하기 (Java 11 정식)

구분선이나 들여쓰기용 공백처럼 같은 문자열을 여러 번 이어 붙일 때, 예전에는 `StringBuilder` 루프나 `Collections.nCopies(n, s).stream().collect(joining())` 같은 우회 방법을 써야 했습니다. Java 11부터는 `"-".repeat(50)`처럼 `String` 인스턴스 메서드로 곧바로 반복 문자열을 만들 수 있고, 내부적으로 `Arrays.copyOf` 기반으로 최적화되어 있어 수동 루프보다 빠릅니다. `count`가 0이면 빈 문자열, 음수면 `IllegalArgumentException`을 던지므로 경계값 처리도 명확합니다.

```java
// Before: StringBuilder 루프
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 50; i++) sb.append("-");
String line = sb.toString();

// After: String.repeat
String line = "-".repeat(50);
String indent = " ".repeat(depth * 2);
String csv = ",".repeat(columns - 1); // placeholder 생성 등
```

> 💡 **왜 중요한가**: 로그 구분선, SQL IN절 placeholder, 트리 들여쓰기처럼 흔한 패턴을 임시 `StringBuilder` 없이 한 줄로 표현하면 의도가 즉시 드러납니다.

### 2. `List.copyOf(Collection)`로 방어적 복사와 불변화를 한 번에 처리하기 (Java 10 정식)

외부에서 받은 컬렉션을 필드에 저장할 때, `new ArrayList<>(input)`로 방어적 복사만 하면 여전히 필드 자체는 가변이라 후속 코드가 실수로 원소를 추가할 수 있습니다. `List.copyOf(input)`을 쓰면 방어적 복사와 불변화가 동시에 이뤄지고, 입력이 이미 `List.copyOf`나 `List.of`로 만들어진 불변 리스트라면 복사 없이 그대로 반환해 최적화까지 됩니다. `Set.copyOf`, `Map.copyOf`도 같은 계약을 따릅니다.

```java
// Before: 가변 필드 + 방어적 복사만
public final class Order {
    private final List<Item> items;
    public Order(List<Item> items) {
        this.items = new ArrayList<>(items); // 여전히 mutable
    }
}

// After: 방어적 복사 + 불변화
public final class Order {
    private final List<Item> items;
    public Order(List<Item> items) {
        this.items = List.copyOf(items); // add/remove 시 UnsupportedOperationException
    }
}
```

주의: `copyOf`는 `null` 원소를 허용하지 않으므로, null이 섞일 수 있다면 사전에 걸러야 합니다.

> 💡 **왜 중요한가**: 도메인 객체의 컬렉션 필드가 외부 참조 공유나 내부 실수 수정으로 오염되는 두 가지 위험을 한 줄로 동시에 차단합니다.
