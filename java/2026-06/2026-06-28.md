### `Thread.onSpinWait()`로 짧은 대기 루프에서 CPU 자원을 힌트로 양보하기 (Java 9 정식)

락이 곧 풀릴 것을 기대하며 짧게 폴링하는 busy-wait 루프에서 `Thread.onSpinWait()`를 호출하면 JVM이 CPU에 스핀 힌트를 전달해 파이프라인·전력·인접 하이퍼스레드 성능을 개선한다. `Thread.sleep()`처럼 컨텍스트 스위칭 비용을 지불하지 않으면서도 순수 스핀보다 훨씬 나은 코어 활용률을 얻을 수 있다.

```java
while (!lock.tryAcquire()) {
    Thread.onSpinWait(); // x86의 PAUSE 명령 등으로 매핑됨
}
```

> 💡 **왜 중요한가**: lock-free 자료구조와 초저지연 폴링에서 표준 API 한 줄로 CPU 낭비와 지연을 동시에 줄일 수 있다.

### `ArrayList.removeIf(Predicate)`로 순회 중 안전하게 요소를 제거하기 (Java 8 정식)

`Iterator.remove()`를 수동으로 호출하거나 새 리스트를 만들어 필터링하는 대신 `Collection.removeIf()`는 조건에 맞는 요소를 안전하고 효율적으로 제거하며, `ArrayList`는 이를 오버라이드해 O(n) 단일 패스로 처리한다. `ConcurrentModificationException` 걱정 없이 원자적 제거를 표현할 수 있다.

```java
List<Order> orders = new ArrayList<>(loadOrders());
orders.removeIf(o -> o.status() == CANCELED); // 인덱스 밀림 없이 단일 패스
```

> 💡 **왜 중요한가**: 반복문 + `iterator.remove()` 보일러플레이트를 표준 API 한 줄로 대체하면서 성능까지 챙길 수 있다.
