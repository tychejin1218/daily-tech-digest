### 1. Perplexity 'Orchestrator API' 정식 출시 — '멀티 프로바이더 라우팅'이 애플리케이션 코드 밖으로 완전히 증발했다, OpenAI SDK 호출 한 줄로 Opus·GPT-6·Llama 5를 런타임에 섞어 쓴다

Perplexity가 오픈 가중치와 상용 폐쇄형 모델을 한 엔드포인트 뒤에 묶은 Orchestrator를 공개했다. OpenAI·Anthropic SDK 요청을 그대로 받아 가용성·용량·레이턴시 기준으로 자동 페일오버하며, 통합 빌링까지 제공한다. 'LLM 게이트웨이'가 LiteLLM 같은 라이브러리 계층에서 'SaaS 인프라'로 올라선 결정적 순간이다.

> 💡 **왜 중요한가**: 모델 선택이 더 이상 애플리케이션 코드의 결정 사항이 아니다 — '어떤 모델을 쓸지'는 네트워크 계층의 런타임 라우팅 문제로 내려갔고, 벤더 락인이 처음으로 '복붙 가능한 상수'로 바뀌었다.

### 2. Cognition 'Devin Bots' 공개 — AI 에이전트가 '다른 코딩 에이전트들의 매니저'가 됐다, '사람 테크리드' 자리를 LLM이 먹기 시작했다

Cognition이 여러 개의 Devin을 감독하는 'Devin Bots'를 선보였다. 지금까지 에이전트는 '프롬프트 하나를 완성하는 단위'였다면, Devin Bots는 작업 분배·리뷰·롤백·우선순위 조정을 맡는 '2차 에이전트'로 올라선다. 조직도에서 '테크리드' 위치에 사람이 아니라 LLM이 앉는 첫 공개 레퍼런스다.

> 💡 **왜 중요한가**: 에이전트 수가 '한 명 당 수십 개'로 늘어나면 사람 테크리드가 병목이 된다 — 'AI가 AI를 관리하는 2계층 구조'가 디폴트가 되면, 1인 조직의 처리량 상한이 한 번 더 올라간다.

### 3. Microsoft Ignite 2026 'Agent 365' + Azure Autopilot 공개 — 엔터프라이즈 에이전트가 'Active Directory 스택'으로 흡수됐다, LLM 호출에 '사용자 ID·감사 로그·권한 경계'가 1급 필드로 꽂혔다

Microsoft가 Ignite에서 Agent 365(에이전트 전용 ID·보안·관측 제어 평면), Microsoft IQ(조직 컨텍스트 재사용 레이어), Azure Autopilot(장기 상주 에이전트)을 한 번에 공개했다. 핵심은 '에이전트도 사원처럼 로그인하고, 감사받고, 권한 범위를 받는다'는 모델이다. 지금까지 에이전트 보안이 'API 키 한 장'이었다면, 이제 'Entra ID + Purview + Defender' 스택 전체를 끌어온다.

> 💡 **왜 중요한가**: 엔터프라이즈에서 에이전트 도입을 막던 벽은 성능이 아니라 '누가·무엇을·언제 했는가'의 감사 공백이었다 — Agent 365는 그 공백을 OS 레벨 ID 스택으로 메우면서, '에이전트 거버넌스'를 Startup들이 아니라 하이퍼스케일러가 쥐는 구도를 굳혔다.
