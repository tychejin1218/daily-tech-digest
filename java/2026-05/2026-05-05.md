### 1. Stream Gatherers(`Stream.gather()`)로 윈도우·스캔 같은 커스텀 중간 연산을 직접 정의하기 (Java 24 정식)

`Collector`가 종단(terminal) 연산의 확장 포인트였다면, `Gatherer`는 **중간(intermediate) 연산의 확장 포인트**입니다. `Gatherers.windowFixed(n)`, `windowSliding(n)`, `scan(...)`, `fold(...)` 같은 빌트인 외에도, `integrator`/`finisher`/`combiner`를 조합해 상태를 갖는 1:N, N:M 변환을 직접 정의할 수 있고, 병렬 스트림에서도 안전하게 동작합니다.

```java
// 3개씩 묶어 슬라이딩 윈도우 처리
List<List<Integer>> windows = Stream.of(1,2,3,4,5)
    .gather(Gatherers.windowSliding(3))
    .toList(); // [[1,2,3], [2,3,4], [3,4,5]]

// 누적 합(scan)
List<Integer> running = Stream.of(1,2,3,4)
    .gather(Gatherers.scan(() -> 0, Integer::sum))
    .toList(); // [1, 3, 6, 10]
```

> 💡 **왜 중요한가**: 그동안 `flatMap`이나 외부 상태 변수로 우회하던 윈도우/누적/중복 제거 같은 패턴을 표준 API로 깔끔하게 표현하고 재사용할 수 있습니다.

### 2. `SequencedCollection`/`SequencedMap`으로 컬렉션의 첫/마지막 원소에 일관된 API로 접근하기 (Java 21 정식)

기존에는 `List`는 `get(0)`/`get(size()-1)`, `Deque`는 `peekFirst()`/`peekLast()`, `LinkedHashSet`은 첫/마지막 원소 접근 API가 아예 없는 등 컬렉션마다 방식이 제각각이었습니다. Java 21에서는 `SequencedCollection`, `SequencedSet`, `SequencedMap` 인터페이스가 도입되어 **`getFirst()`, `getLast()`, `addFirst()`, `addLast()`, `reversed()`** 가 통일된 메서드로 제공됩니다.

```java
List<String> list = List.of("a", "b", "c");
String first = list.getFirst();          // "a"
String last  = list.getLast();           // "c"
List<String> rev = list.reversed();      // [c, b, a]

LinkedHashSet<Integer> set = new LinkedHashSet<>(List.of(1, 2, 3));
set.addFirst(0);                         // [0, 1, 2, 3]

LinkedHashMap<String, Integer> map = new LinkedHashMap<>();
map.put("x", 1); map.put("y", 2);
var firstEntry = map.firstEntry();       // x=1
var reversedView = map.reversed();       // 역순 뷰
```

> 💡 **왜 중요한가**: 순서가 있는 컬렉션이라면 어떤 구현체든 동일한 API로 다룰 수 있어, 인덱스 계산 실수나 컬렉션별 분기 코드를 제거하고 의도를 분명히 드러낼 수 있습니다.
