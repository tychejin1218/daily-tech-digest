### 1. `Pattern Matching for switch`로 타입별 분기를 간결하게 표현하기 (Java 21 정식)

`switch` 표현식에서 타입 패턴과 `when` 가드 절을 사용하여 `instanceof` 체인과 캐스팅 코드를 제거할 수 있습니다. `null` 케이스도 별도 패턴으로 처리할 수 있어 NPE 방지와 분기 처리를 한 곳에서 일관되게 작성할 수 있으며, 컴파일러가 sealed 타입에 대해 누락된 케이스를 검증해 줍니다.

```java
sealed interface Shape permits Circle, Square, Triangle {}

double area = switch (shape) {
    case Circle c           -> Math.PI * c.radius() * c.radius();
    case Square s when s.side() > 0 -> s.side() * s.side();
    case Triangle t         -> 0.5 * t.base() * t.height();
    case null               -> 0.0;
};
```

> 💡 **왜 중요한가**: 다형성 분기 로직의 가독성과 안전성을 동시에 높이며, sealed 타입과 결합하면 컴파일 타임에 누락된 케이스를 검출할 수 있습니다.

### 2. `ZGC` Generational 모드로 대용량 힙에서 일시정지 시간을 ms 미만으로 유지하기 (Java 21 정식)

ZGC의 Generational 모드는 약한 세대 가설(weak generational hypothesis)을 활용해 짧게 살다 죽는 객체를 별도 영역에서 빠르게 회수합니다. `-XX:+UseZGC -XX:+ZGenerational` 옵션으로 활성화하며, TB급 힙에서도 GC 일시정지 시간이 1ms 미만으로 유지되어 지연 민감 서비스에 적합합니다.

```bash
java -XX:+UseZGC -XX:+ZGenerational \
     -Xmx16g -Xlog:gc* \
     -jar app.jar
```

> 💡 **왜 중요한가**: 처리량 손실 없이 거대 힙에서도 예측 가능한 초저지연 GC를 제공하여, 대규모 트래픽 환경의 tail latency를 안정화합니다.
