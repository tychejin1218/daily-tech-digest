### `String.formatted()`로 `String.format()`을 메서드 체인 안에서 자연스럽게 사용하기 (Java 15 정식)
`String.format("Hello %s, age %d", name, age)` 대신 `"Hello %s, age %d".formatted(name, age)`로 인스턴스 메서드처럼 호출할 수 있습니다. Text Block과 결합하면 여러 줄 SQL이나 JSON 템플릿에 값을 주입할 때 특히 가독성이 좋아지고, 스트림 파이프라인 내부의 `.map()` 안에서도 자연스럽게 체이닝됩니다.

> 💡 **왜 중요한가**: 정적 메서드 호출로 흐름이 끊기던 문자열 포맷팅을 fluent한 스타일로 바꿔, 특히 Text Block 기반 템플릿과 궁합이 좋아 실무 가독성이 눈에 띄게 개선됩니다.

### `Objects.requireNonNullElse()`로 null 기본값 대체를 한 줄로 표현하기 (Java 9 정식)
`value != null ? value : defaultValue` 삼항 연산자나 `Optional.ofNullable(v).orElse(d)` 우회 대신 `Objects.requireNonNullElse(value, defaultValue)`로 null 대체 로직을 표현합니다. 기본값 계산이 비싼 경우엔 `requireNonNullElseGet(value, () -> heavyCompute())`을 써서 지연 평가할 수 있어, `Optional`을 남용하지 않고도 의도를 명확히 드러낼 수 있습니다.

> 💡 **왜 중요한가**: null 방어 로직을 위해 `Optional`을 잠깐 감쌌다 푸는 관용구는 오버헤드와 가독성 저하를 동시에 유발하는데, 표준 API로 의도를 직접 표현할 수 있어 더 깔끔합니다.
