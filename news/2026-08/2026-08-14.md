### 1. OpenAI, 'Daybreak Blue/Red' 이원화 + GPT-5.6-Cyber 공개 — 사이버보안 전용 LLM이 처음으로 API 티어가 됐다

OpenAI가 사이버 방어자 대상 프로그램 Daybreak를 Blue(방어)·Red(공격 리서치) 두 티어로 분리하고, Red 전용 모델 **GPT-5.6-Cyber**를 함께 공개했다. 내부 벤치에서 일반 GPT-5.6 Sol이 사이버 요청 완수율 1.5%에 그친 반면, Cyber는 95.0%를 달성했고 제로데이 발굴·익스플로잇 체인 개발까지 손댈 수 있다. 그동안 "AI 안전 정책" 뒤에 가려져 있던 dual-use 시나리오를 OpenAI가 스스로 API 상품으로 꺼내들었다는 점이 사건이다.

> 💡 **왜 중요한가**: 사이버보안 팀이 LLM API를 쓰는 방식이 "안전 필터 우회를 어떻게 뚫나"에서 "어떤 티어로 계약할 것인가"로 바뀌었다.

### 2. Google I/O 2026 (8월 13일) — Gemini 3.5 시리즈 + Antigravity 대규모 업그레이드로 '서브에이전트 계층' 표준화

Google이 어제(8/13) Gemini 3.5 시리즈(3.6 Flash·3.5 Flash-Lite 포함)와 함께 에이전트 개발 플랫폼 Antigravity를 재차 개편했다. 특히 **3.5 Flash-Lite를 "저지연·초저가 서브에이전트 전용" 옵션**으로 명시 포지셔닝하고, 3.6 Flash에는 코드/에이전트 플래닝 능력을 강화했다. Antigravity는 여러 에이전트를 오케스트레이션하는 기능이 더해져, 상위 오케스트레이터 + 하위 서브에이전트 조합을 Google이 공식 스택으로 밀기 시작했다.

> 💡 **왜 중요한가**: "메인 모델 하나로 다 해결"에서 "메인 + 대량의 저가 서브에이전트" 아키텍처로 프론티어 랩들의 기본 설계가 이동하고 있다는 신호다.

### 3. Anthropic, 리만 제타 함수 하한 개선을 Claude Code + 서브에이전트 60개로 해결 — 31M 아웃풋 토큰짜리 '연구용 에이전틱 워크로드'의 첫 실측치

Anthropic이 미공개 Claude 리서치 빌드를 **Claude Code 안에서 약 60개의 서브에이전트로 오케스트레이션**해 리만 제타 함수 영점의 알려진 하한을 개선했다고 공개했다. 실행 과정에서 소비한 아웃풋 토큰은 약 3,100만 개. 지금까지 "코딩 에이전트가 얼마나 큰 문제까지 갈 수 있나"는 벤치마크로만 논의됐는데, 이번엔 실제 미해결 수학 문제에 붙여 결과와 비용을 함께 노출했다.

> 💡 **왜 중요한가**: 서브에이전트 팬아웃 + 수천만 토큰 규모의 실행이 "연구 워크로드의 새 단위"로 굳어지고 있다 — 비용 산정과 관측성(observability) 도구가 다음 병목이다.
