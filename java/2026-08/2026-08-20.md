### 1. `Collectors.teeing(down1, down2, merger)`로 스트림을 두 번 도는 대신 한 번에 두 결과 얻기 (Java 12 정식)

평균을 구하려고 합계와 개수를 각각 두 번의 스트림으로 계산하거나, 최댓값과 최솟값을 별도로 뽑아 조합하는 코드에서 유용하다. `teeing`은 두 개의 다운스트림 수집기에 각 원소를 동시에 흘려보낸 뒤 마지막에 병합 함수로 하나의 결과로 합쳐준다. 스트림을 여러 번 순회할 필요가 없어 시간·메모리 모두 아낄 수 있다.

```java
record Range(int min, int max) {}

Range range = Stream.of(3, 1, 4, 1, 5, 9, 2, 6)
    .collect(Collectors.teeing(
        Collectors.minBy(Integer::compareTo),
        Collectors.maxBy(Integer::compareTo),
        (min, max) -> new Range(min.orElseThrow(), max.orElseThrow())
    ));
// Range[min=1, max=9]
```

> 💡 **왜 중요한가**: 서로 다른 집계 두 개를 한 번의 순회로 끝내면 대용량 스트림에서 성능이 두 배 가까이 개선되고, "합계와 개수", "최소와 최대", "성공 카운트와 실패 카운트" 같은 쌍 집계 코드가 훨씬 선언적이 된다.

### 2. `LocalDate.datesUntil(endExclusive)`로 날짜 반복문 대신 스트림으로 기간 순회하기 (Java 9 정식)

`for (LocalDate d = start; d.isBefore(end); d = d.plusDays(1)) {...}` 같은 명령형 반복문을 `datesUntil`이 스트림으로 대체한다. 오버로드로 `Period` 간격까지 지정할 수 있어 "매주 월요일" 같은 주기 순회도 표현 가능하다. 스트림이므로 필터·매핑·수집 API와 자연스럽게 결합된다.

```java
LocalDate start = LocalDate.of(2026, 8, 1);
LocalDate end   = LocalDate.of(2026, 9, 1);

// 8월의 모든 평일 목록
List<LocalDate> weekdays = start.datesUntil(end)
    .filter(d -> d.getDayOfWeek().getValue() < 6)
    .toList();

// 매주 월요일만 (Period로 간격 지정)
List<LocalDate> mondays = start.with(java.time.DayOfWeek.MONDAY)
    .datesUntil(end, java.time.Period.ofWeeks(1))
    .toList();
```

> 💡 **왜 중요한가**: 배치·리포트·통계에서 "특정 기간을 하루/일주일 단위로 순회"는 흔한 요구인데, 명령형 반복문은 종료 조건 실수(`isBefore` vs `isEqual`)나 무한 루프 위험이 있다. 스트림 기반 API는 종료 반개방 구간이 명확하고 함수형 파이프라인과 그대로 이어져 실수 여지를 줄인다.
