### Google Cloud Run 샌드박스, 퍼블릭 프리뷰 진입 — AI 생성 코드 격리 실행 표준화
Google Cloud가 7월 10일 Cloud Run 서비스 인스턴스 내부에 밀리초 단위로 시작되는 격리 실행 환경을 만드는 Cloud Run 샌드박스를 퍼블릭 프리뷰로 공개했다. AI가 생성한 코드, 사용자 제출 스크립트, 신뢰할 수 없는 바이너리를 호스트 앱·저장 데이터·클라우드 자격증명 노출 없이 실행할 수 있으며, 코드 인터프리터·헤드리스 브라우저·서드파티 플러그인 실행 시나리오를 겨냥한다. 별도 컨테이너 클러스터나 microVM 서비스 없이 표준 subprocess 호출로 샌드박스를 띄울 수 있는 CLI가 실행 환경에 자동 마운트된다.

> 💡 **왜 중요한가**: LLM이 생성한 코드를 프로덕션 서버리스 위에서 안전하게 돌리는 표준 프리미티브가 자리 잡으면서, 백엔드 팀이 자체 샌드박싱 인프라를 굴릴 필요가 사라진다.

### Feyn AI, 'SQRL' 오픈소스 공개 — DB를 먼저 조사하고 쿼리를 쓰는 Text-to-SQL 모델
Feyn Labs가 7월 19일 데이터베이스를 읽기 전용 프로브로 먼저 조사한 뒤 SQL을 작성하는 텍스트-투-SQL 모델 계열 SQRL을 Hugging Face에 공개했다. SQRL-4B·9B·35B-A3B 세 체크포인트 중 플래그십 35B-A3B는 BIRD Dev 실행 정확도 70.6%로 Claude Opus 4.6(68.77%)을 웃돌았고, 4B는 온프렘에서 돌아가면서도 Opus 4.6과 동급 성능을 낸다. Qwen3.5·3.6 기반에 CISPO 강화학습으로 훈련됐다.

> 💡 **왜 중요한가**: '스키마를 프롬프트에 우겨넣고 한 방에 쿼리 생성'하던 관행이 '에이전트가 DB를 먼저 탐색 후 작성'하는 패턴으로 전환되는 신호탄이다.

### OpenAI 'Secure MCP Tunnel' 도입 — 프라이빗 MCP 서버를 공용 인터넷 노출 없이 연동
OpenAI가 7월 업데이트에서 Secure MCP Tunnel을 정식 지원 대상에 추가했다. 고객이 운영하는 터널 클라이언트를 통해 ChatGPT 웹, Codex, Responses API, AgentKit이 사내 방화벽 안쪽의 프라이빗·온프렘 MCP 서버에 붙을 수 있게 됐으며, 서버를 퍼블릭 인터넷에 노출하지 않아도 된다. 함께 배포된 Codex 업데이트는 GPT-5.6 Sol/Terra/Luna 컨텍스트 창을 272K로 정정하고 `rm` 계열 위험 명령 감지를 강화했다.

> 💡 **왜 중요한가**: 규제 산업에서 MCP 도입의 가장 큰 걸림돌이던 '내부 툴 서버를 어떻게 안전하게 노출할 것인가' 문제에 벤더 공식 해법이 처음 등장했다.
