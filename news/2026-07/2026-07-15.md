### Vercel, 'AI SDK 6.0' 정식 릴리스 — 스트리밍 툴 호출 & 에이전트 상태 영속화 표준화

Vercel이 AI SDK 6.0을 정식 공개하며 스트리밍 도중에도 툴 호출 결과를 부분적으로 반환하는 `partialToolCall` API와 서버 측 대화 상태 영속화 레이어를 도입했다. 이전 버전에서 별도 스토리지 어댑터를 붙여야 했던 멀티턴 에이전트 세션이 SDK 내장 `PersistedAgent` 인터페이스 한 줄로 유지되며, OpenAI·Anthropic·Google 3사 SDK를 넘어 20종 이상 프로바이더의 툴 호출 스키마가 통일됐다.

```ts
import { streamText, PersistedAgent } from 'ai';
const agent = new PersistedAgent({ sessionId: 'user-42', store: 'kv' });
const result = await streamText({ model: agent.model('claude-opus-4-7'), tools });
```

> 💡 **왜 중요한가**: 프레임워크 종속성을 낮추면서도 서버 저장·툴 호출 스트리밍이라는 두 축을 표준화해 프로덕션 에이전트 코드의 이식성이 크게 올라간다.

### Datadog, 'LLM Observability 2.0' 공개 — 토큰 단가 실시간 추적 & 에이전트 추적 UI 통합

Datadog이 LLM Observability 제품군을 대대적으로 개편해 요청·응답 트레이스에 토큰 단가와 프로바이더별 요율 변동을 자동 반영하는 코스트 애트리뷰션 기능을 추가했다. 특히 다중 에이전트 워크플로우를 단일 타임라인으로 시각화하는 'Agent Graph View'가 붙어 툴 호출 실패·재시도 루프·중복 컨텍스트 로딩 같은 낭비 지점을 클릭 한 번에 드릴다운할 수 있으며, OpenTelemetry GenAI 세만틱 컨벤션에도 완전 준수한다.

> 💡 **왜 중요한가**: 에이전트가 늘어날수록 실질 비용의 70% 이상이 재시도·중복 호출에서 발생하는데, 이제 관측 없이는 운영이 사실상 불가능하다는 신호다.

### Kubernetes 1.34 정식 릴리스 — 'Dynamic Resource Allocation' GA와 사이드카 컨테이너 안정화

CNCF가 Kubernetes 1.34를 정식 배포하며 GPU·FPGA·특수 가속기 스케줄링을 표준화하는 DRA(Dynamic Resource Allocation)를 GA로 승격했다. 동시에 오랫동안 알파에 머물던 네이티브 사이드카 컨테이너 기능도 stable로 이동해 Istio·Envoy 프록시 라이프사이클을 pre-stop hook 트릭 없이 관리할 수 있게 됐고, ImageVolumeSource로 OCI 이미지를 볼륨처럼 마운트하는 기능도 베타에서 GA로 올라왔다.

> 💡 **왜 중요한가**: AI 워크로드용 GPU 스케줄링과 서비스 메시가 벤더별 커스텀 리소스에서 벗어나 Kubernetes 표준 위에서 동작하게 되며 플랫폼 팀의 유지보수 부담이 크게 줄어든다.
